# Granit 0.4.0 Core C ABI 快照

这是 Granit 0.4.0 Core 的完整公共 C 符号基线。它记录新增的 Renderer 后端选择与信息查询接口，
不修改 `0.1.0` 历史快照。可选 RenderPipeline、Window 与 Input component 尚未发生基线变化，
继续使用各自的 `0.1.0` 快照。

平台、架构、编译器范围和更新规则与
[0.1.0 ABI 快照](../0.1.0/README.md)一致。后续 Core 公共 ABI 变化应建立对应版本基线，不得覆盖
已经发布的历史快照。
