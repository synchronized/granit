# Lighting 分 Pass 首份 GPU 性能基线

## 环境与方法

- 提交：`eefb0d8`（基准代码基于该提交的工作区构建）
- 系统：Windows AMD64
- CPU：Intel Core i5-8600K 3.60 GHz
- 显示设备：系统报告 Intel UHD Graphics 630（驱动 31.0.101.2140）及 Oray 虚拟显示设备；当前
  Renderer 尚未输出 Vulkan 适配器名称，因此不把系统枚举结果声明为已确认的运行适配器。
- 编译器：Clang 22.1.8
- 构建：Release，共享库
- 参数：5 个预热样本，20 个正式样本，每个样本 20 帧
- 范围：256×256 离屏 Forward PBR；一盏固定方向光、指定数量点光、IBL、单级阴影和 Tone Mapping
- 计时：GPU timestamp query；不包含命令录制、提交等待、输出复制和 CPU 像素回读

## 结论

Shadow 与 Tone Mapping 基本不随点光数量变化，PBR HDR 则从 1 到 128 点光近似线性增长，符合当前
Forward Shader 逐像素遍历可见点光数组的设计。该机器上的 128 点光 P99 渲染链约为 2.33 ms，尚无
充分证据立即增加分块或聚簇光照的复杂度。后续应在目标独立显卡、目标分辨率和典型材质复杂度下
使用相同参数复测；只有帧预算或增长曲线达到 H-05 的重新评估条件时，才启动对应设计任务。
