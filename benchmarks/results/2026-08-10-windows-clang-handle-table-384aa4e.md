# Windows Clang 句柄表基线

## 环境

- Granit：`384aa4e`
- 构建：Windows Clang 22.1.8、Release、共享库配置
- 系统：Windows AMD64
- CPU：Intel Core i5-8600K，6 个逻辑处理器
- runner：`steady_clock`
- 参数：1 线程，每个样本 1,000,000 次操作，5 次预热，30 个样本，表大小 10,000
- 重复：完整运行 3 次

## 结果

下表的 `ns/op` 是三次完整运行各自平均值的均值；范围用于观察重复运行波动，不表示置信区间。

| 用例 | 平均 ns/op | 三次运行范围 ns/op | 吞吐量约值 |
| --- | ---: | ---: | ---: |
| 命中查询 | 6.208 | 6.181～6.228 | 1.61 亿 ops/s |
| 错误资源类型 | 4.910 | 4.865～4.937 | 2.04 亿 ops/s |
| 错误 domain | 6.304 | 6.236～6.346 | 1.59 亿 ops/s |
| 旧 generation | 2.820 | 2.803～2.833 | 3.55 亿 ops/s |
| 插入/删除槽位复用 | 7.769 | 7.748～7.785 | 1.29 亿 ops/s |

## 结论

- 三次运行的平均值范围均小于约 2%，可作为当前机器后续同条件比较的初始基线。
- 错误类型和旧 generation 会在较早校验阶段返回，因此快于完整命中查询，符合实现结构。
- 本结果只覆盖单线程纯 CPU 路径，不代表 Registry 锁竞争或真实 Renderer 工作负载；这些由 P-02B
  及后续任务测量。
- 当前没有数据支持调整句柄编码或查找结构，P-03 不应仅根据这组微基准提前优化。
