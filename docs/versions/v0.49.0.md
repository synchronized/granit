# v0.49.0：异步回读契约与诊断

## 状态

**已完成，2026-10-07 发布。** 详细范围由 [S-85](../plans/S-85-0.49.0-readback-contract-and-diagnostics.md)
定义。本版本收敛现有回读能力的契约、验证和诊断，没有新增公共 API。

## 固定范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| [S-85 异步回读契约与诊断](../plans/S-85-0.49.0-readback-contract-and-diagnostics.md) | 回读契约、跨后端验收、结构化诊断、最小示例 | 默认不新增公共 ABI |

## 不进入本版本

- SVT、纹理驻留预算、回收调度和 Gneiss 专用资源系统；
- Vulkan SDK、厂商驱动、ICD 或新的 Vulkan 原生公共接口；
- 没有跨后端证据支持的平行 `map_async` 公共接口。
