# v0.51.0：RenderPipeline 契约与真实 Consumer

## 状态

**已发布，2026-10-07。** 详细范围由 [S-87](../plans/S-87-0.51.0-render-pipeline-contract-and-consumer.md) 定义；S-87A Consumer 基线和 S-87B 契约验收已完成。
本版本先验证 RenderPipeline 的真实复用边界，不以新增大型渲染功能为目标。

## 固定范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| [S-87 RenderPipeline 契约与真实 Consumer](../plans/S-87-0.51.0-render-pipeline-contract-and-consumer.md) | Consumer、生命周期门禁、跨后端验收、稳定等级决策 | 默认不新增公共 ABI |

## 不进入本版本

- Bindless、Clustered Forward、Cascaded Shadow Maps 和 GPU-driven 新 API；
- SVT、纹理驻留预算、VFS、任务调度和 Gneiss 专用资源系统；
- Vulkan 原生公共接口或 Vulkan SDK/驱动分发。
