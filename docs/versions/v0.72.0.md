# v0.72.0：CMake IDE 目标组织

## 状态

**实现完成，待发布候选验收，2026-11-17。** 本版本聚焦父项目通过 `add_subdirectory` 引入 Granit 时的 IDE 目标分组体验。

## 固定范围

- 新增可选缓存变量 `GRANIT_CMAKE_TARGET_FOLDER`；
- 将该变量作为 Granit `granit_*` 目标的 IDE 文件夹父路径；
- 保留现有 `Modules`、`Tests`、`Examples`、`Benchmarks` 等相对分类；
- 对没有现有 `FOLDER` 的 Granit 目标使用父目录；
- 保持非 Granit 目标、构建输出路径、安装导出和公共 API 不变；
- 增加 CMake fixture、文档和配置验收。

## 不在范围内

- 不重命名或删除现有 CMake target；
- 不统一覆盖父项目和第三方依赖的 IDE 分组；
- 不改变 CMake component、链接依赖、ABI 或运行时行为；
- 不新增渲染功能。
