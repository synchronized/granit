# v0.39.0：统一示例基础与动态 GPU 工作流

## 状态

**已于 2026-09-28 发布。** 安装包、校验文件和发布说明见
[v0.39.0 Release](https://github.com/synchronized/granit/releases/tag/v0.39.0)，用户可见变化以
[Changelog](../../CHANGELOG.md) 为准。

## 最终范围

| 任务 | 最终结果 | 公共 SDK 影响 |
|---|---|---|
| [S-72 Asset Manager 与任务系统](../plans/S-72-0.39.0-asset-manager-and-task-system.md) | 示例私有异步 Task System、单一 Asset Manager、Source/Loader 注册及现有调用方迁移 | 无；保留在 `examples/common` |
| [S-73 统一交互式 Tutorial](../plans/S-73-0.39.0-unified-interactive-tutorials.md) | 五个已有 Tutorial 统一 ImGui Runtime、Orbit Camera、参数面板和 Instancing 对照 | 调整实验性 Mesh Draw，使实例范围可逐次指定 |
| [S-74 GPU Marching Cubes](../plans/S-74-0.39.0-gpu-marching-cubes.md) | 公共 Indirect 命令、Frame Transient Buffer 和 `06_marching_cubes` | 新增跨后端 Indirect 与 Transient Buffer 契约 |

Asset Manager、Task System、Tutorial Runtime 与 Orbit Camera 仍是示例基础设施；本版本没有将其提升为
公共 SDK，也没有引入公共 VFS、Render Graph、Async Compute 或多 Queue 契约。
