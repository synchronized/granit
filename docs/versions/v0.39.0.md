# v0.39.0：统一示例基础与动态 GPU 工作流

## 状态

**实施中，S-72、S-73 与 S-74 功能实现已完成，正在执行发布验收。** 当前开发分支为
`feature/0.39-asset-manager-task-system`。本版本按 S-72 → S-73 → S-74 顺序实施；接下来进入 S-74，
三个任务全部通过后统一发布，不创建中间版本。

## 版本目标

本版本先统一示例资产、任务和交互运行基础，再通过现有教程迁移与 GPU Marching Cubes 验证动态
实例数据、Compute 生成几何、跨阶段同步、Transient Buffer 和 Indirect Draw。最终应形成六个在
Desktop Vulkan 与浏览器 WebGPU 使用相同主体代码和交互方式的 Tutorial。

## 固定范围

| 顺序 | 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|---|
| 1 | [S-72 Asset Manager 与任务系统](../plans/S-72-0.39.0-asset-manager-and-task-system.md) | 示例私有异步 Task System、单一 Asset Manager、Source/Loader 注册及现有调用方迁移 | 无；保持在 `examples/common` |
| 2 | [S-73 统一交互式 Tutorial](../plans/S-73-0.39.0-unified-interactive-tutorials.md) | 统一五个现有 Tutorial 的 ImGui Runtime、Orbit Camera、参数面板和 Instancing 对照 | 调整实验性 Mesh Draw，使实例范围可逐次指定 |
| 3 | [S-74 GPU Marching Cubes](../plans/S-74-0.39.0-gpu-marching-cubes.md) | 公共 Indirect 命令、Frame Transient Buffer、第六个 Marching Cubes Tutorial | 新增跨后端 Indirect 与 Transient Buffer 契约 |

S-72 先消除 Tutorial 和 Model Viewer 的资产加载分歧。S-73 随后只迁移五个已经存在的 Tutorial，
并产出 S-74 可直接复用的交互运行时。S-74 最后新增 `06_marching_cubes`，同时作为公共 GPU 能力和
整个版本的最终验收阶段。

## 不进入本版本

- 不把 Asset Manager、Task System、Tutorial Runtime 或 Orbit Camera 安装为公共 SDK；
- 不实现公共 VFS、热重载、资产写入、Web Worker 或磁盘资产缓存；
- 不实现 Async Compute、多 Queue、Mesh Shader、GPU Driven 场景系统或多 Draw Indirect；
- 不冻结整个 Granit API/ABI，也不为 0.x 已替换接口保留兼容转发；
- 不新增 S-72、S-73、S-74 之外的 Tutorial 或 Sample 重构。
