# v0.67.0：AssetTools Consumer 与资产验证闭环

## 状态

**待发布候选。** 版本聚焦实验性 AssetTools 的真实 Consumer 和资产归档验证，不承诺提升公共 ABI 稳定等级。

## 固定范围

- Shader Library、Material、Texture、Environment 的最小资产样例；
- 安装 SDK Consumer 的构建、检查、加载和失败诊断；
- Windows/Linux shared/static 与 Emscripten 可表达边界验证；
- 资产格式、生命周期、路径隔离和许可证文档收口。

## 发布门槛

- [x] 资产构建和 inspect 的成功/失败路径通过；
- [x] 安装 SDK Consumer 不依赖源码树或 Vulkan 公共头；
- [x] Windows/Linux shared/static 和 Emscripten 边界已记录；
- [x] AssetTools 继续标记为实验性；
- [ ] 版本文档、验收记录、CHANGELOG 和公开制品复核完成。
