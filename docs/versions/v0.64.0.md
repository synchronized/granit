# v0.64.0：ImGui 输入适配与 Window 解耦

## 状态

**本地实施完成，待发布收口。** 当前版本由 [S-100](../plans/S-100-0.64.0-imgui-input-integration.md)
承担，承接 `v0.63.0` 的 Vertex Streams 与 PBR 顶点属性验证。详细证据见
[S-100 验收记录](../records/2026-10-16-v0.64.0-s100-acceptance.md)。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| ImGui 核心帧接口 | Window 无关的帧尺寸、DPI、Delta Time 和新帧入口 | 扩展 `granit::integration_imgui` C++ API，不新增 C ABI |
| Window→ImGui 输入适配 | 键盘、修饰键、文本、鼠标、滚轮、焦点事件转换 | 新增可选 `granit::integration_imgui_window` 组件 |
| 示例迁移 | Tutorial Runtime 复用公共适配；SDL 外部宿主保持独立 | 删除示例重复输入映射，不改变 SDL3 集成边界 |
| Consumer 与跨平台验收 | 核心/Window 适配独立安装验证，Windows/Linux/Emscripten Smoke | 补齐导出、安装和静态/共享使用证明 |
| 文档与回归 | Reference、教程、能力矩阵、CHANGELOG 和验收记录 | 不改变现有 Draw Data API 语义 |

## 固定边界

- 不使用 `granit::window` 的 ImGui 应用仍可只链接核心 ImGui Integration；
- 使用 `granit::window` 的应用通过可选适配组件注入 Window/Input 事件；
- Granit 不拥有 ImGui Context、字体、Texture ID 或外部 SDL Window；
- 不新增 SDL/GLFW 类型、Vulkan 公共类型、C ABI、触控/手柄/IME 扩展或自动事件订阅器；
- `08_sdl_imgui` 继续验证外部 SDL Window 和 SDL 官方 ImGui Backend，不迁移到 Granit Window 适配层。

## 阶段出口

1. 核心组件在无 Window 依赖的 Consumer 中通过；
2. Window 适配组件的事件映射、帧生命周期和 ImGui 捕获行为通过单元测试与示例 Smoke；
3. Windows Vulkan、Linux Vulkan、Emscripten/WebGPU 以及共享/静态安装验证通过；
4. 公共头、CMake 导出、Reference、教程、CHANGELOG 和验收记录一致；
5. 发布前版本文档、计划、验收记录和 Changelog 完成收口。
