# v0.71.0：公共 Render Graph API

## 状态

**发布准备中，2026-10-31。** 本版本新增面向外部引擎的实验性公共 Render Graph component，
不冻结公共 ABI，也不要求接入 Granit 参考 RenderPipeline。

## 固定范围

- 独立的 `RenderGraph` CMake component，可只依赖核心 Renderer；
- C11 ABI 与 C++20 RAII API，按 `graph.*` 与 `types.*` 分离公共头文件；
- 外部 Buffer、Texture View 导入和图内临时 Buffer、Texture；
- Pass 命名、资源读写/用途声明、显式依赖和拓扑编译；
- 录制回调中的资源查询、Renderer/Recorder 访问和阶段错误诊断；
- 离屏执行以及与 Renderer Frame 配合的窗口输出；
- 临时资源延迟回收、失败清理、重复执行和尺寸更新测试；
- 只使用安装 SDK 的 Shadow → Scene → Tone Mapping 外部 Consumer 示例。

## 不在范围内

- 并行录制、多队列异步计算和显存别名复用；
- 自动 Subpass 合并或 Vulkan input attachment 模拟；
- PBR、Scene、Material、Shadow、Particle、UI 和 Tone Mapping 的业务实现；
- 为 toy-engine 重写现有 Shader 或 Vulkan Pass；
- 将公共 Graph ABI 标记为稳定接口。

## 兼容性说明

本版本新增实验性组件。公共 Render Graph 头文件路径和 C++ 名称属于 0.x 阶段接口，后续版本
可能继续调整；使用者应通过 `find_package(granit CONFIG REQUIRED COMPONENTS RenderGraph)`
和 `granit::render_graph` target 接入，不依赖 `src/` 私有头文件。
