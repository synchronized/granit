# v0.61.0：Resource Table 实际 Shader 采样与多材质场景

## 状态

**已确认，待实施。** 详细设计和验收条件见 [S-97](../plans/S-97-0.61.0-resource-table-shader-and-multimaterial-scene.md)。

## 版本目标

承接 v0.60.0 的 Resource Table 材质契约，让 Vulkan Shader 实际通过 Resource Table 索引和采样多张
纹理，并用真实模型与可控材质网格验证多材质、多 Draw 场景。Bind Group 仍是默认路径，WebGPU 继续
使用 Bind Group 回退。

## 计划交付

| 任务 | 交付内容 | 公共 SDK 影响 |
|---|---|---|
| S-97A Shader 采样 | Resource Table 纹理/采样器数组、后端生成和反射校验 | 实验性 Shader/Material 绑定模型扩展 |
| S-97B 绘制接线 | Vulkan 实际 Resource Table 绑定、索引传递和回退 | 不引入 Vulkan 公共类型 |
| S-97C Tutorial 12 | 轻量多材质 glTF、4×4 材质网格和 16～32 张纹理 | 示例和测试资产变化 |
| S-97D 压力对照 | Bind Group/Resource Table 的 CPU、GPU、容量和变体数据 | 不改变默认路径 |
| S-97E 跨平台收口 | Windows Vulkan、Linux Lavapipe、Chrome WebGPU 和不支持设备验证 | 固化能力与失败语义 |

## 版本边界

- Resource Table 必须显式选择，Bind Group 仍为默认绑定路径；
- Vulkan 验证真实 Resource Table Shader 采样；
- WebGPU 使用合法 Bind Group 回退，不宣称 bindless；
- Tutorial 12 使用“中等复杂真实模型 + 可控多材质网格”，不依赖大型外部场景；
- 不实现 SVT、纹理驻留、预算、虚拟地址、自动流送或 Model Viewer 全量迁移；
- 不把每个材质功能扩展成独立绑定模型变体。

## 发布门槛

- Tutorial 12 至少显示 16 个不同纹理材质；
- Vulkan Resource Table Shader 实际读取纹理数组，槽位切换产生可见且确定的变化；
- Bind Group 与 Resource Table 结果一致；
- WebGPU 回退和不支持设备路径合法；
- Vulkan 校验层无绑定布局、阶段可见性和数组索引错误；
- Windows、Linux/Lavapipe、Chrome WebGPU 和默认 Bind Group 回归证据齐全；
- 版本文档、实施计划、验收记录和 CHANGELOG 完成收口后，才允许创建 tag 和 Release。
