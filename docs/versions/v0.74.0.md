# v0.74.0：对象 ID 输出与异步像素拾取

## 状态

**发布候选验收完成，待正式发布，2026-11-21。**

## 固定范围

- 由 [S-119](../plans/S-119-0.74.0-object-picking.md) 提供可选对象 ID 输出。
- 增加跨后端公共 `R32_UINT` 纹理格式，用于 ID attachment 和原始整数回读。
- 为公共 `ReadbackBatch` 增加 Texture View 异步回读入口。
- 支持标准 Opaque/MASK 路径、离屏输出和窗口 Frame 输出；背景与不可拾取像素为 0。
- 补充资源所有权、异步完成、尺寸变化、失败诊断和 C/C++ Consumer 验证。

## 明确不纳入

MSAA resolve、透明物体拾取策略、UI/debug ID、自定义 record 自动注入、通用射线拾取、并行录制和
Vulkan 公共类型。
