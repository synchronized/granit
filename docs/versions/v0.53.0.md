# v0.53.0：Bindless 能力探针与 Resource Table 原型

## 状态

**已发布（2026-10-07）。** 详细范围由 [S-89](../plans/S-89-0.53.0-bindless-probe-and-resource-table.md) 定义。

发布地址：[v0.53.0 Release](https://github.com/synchronized/granit/releases/tag/v0.53.0)

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| S-89 Bindless 能力探针与 Resource Table 原型 | CPU 索引契约、能力探针、Vulkan 实验准入设计、传统回退 | 增加后端无关能力位，不新增资源表 ABI |

S-89A、S-89B 和发布验收已完成。真实 Vulkan Descriptor 数组采样因资源索引写入、Shader/Pipeline
变体及 GPU 生命周期契约尚未稳定而延期；传统 Bind Group 仍是默认路径。

验收记录：[Resource Table](../records/2026-10-07-s89a-resource-table-acceptance.md)、
[Bindless 探针](../records/2026-10-07-s89b-bindless-probe-acceptance.md)、
[实验边界](../records/2026-10-07-s89c-bindless-experiment-deferral.md)。

## 不进入本版本

- 默认 Bindless 材质路径和稳定公共 Resource Table API；
- Descriptor Buffer、Ray Tracing、Mesh Shader、SVT/纹理驻留和 VFS；
- Gneiss 资源生命周期、预算管理和任务调度；
- Vulkan 原生公共接口或 Vulkan SDK/驱动分发。
