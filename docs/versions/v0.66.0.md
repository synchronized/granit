# v0.66.0：发布收口与 Runtime 缓存验证

## 状态

**已发布，2026-10-18。** 本版本聚焦发布工程质量和已有 ImGui 输入适配的 Consumer 回归，不新增大型
渲染功能或公共 C ABI。

## 计划范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| 发布文档收口 | 统一 Roadmap、Version、Plan、Record、README 和 Changelog 的当前状态 | 不改变 API/ABI |
| Runtime 缓存验证 | 验证 Vulkan Runtime 缓存命中时跳过源码编译，依赖提交变化时自动失效 | 不改变 Runtime 内容 |
| ImGui Consumer 验收 | 覆盖 Granit Window、外部 SDL Window、Windows/Linux/Emscripten 和 shared/static | 不新增 C ABI |
| CI 证据 | 记录缓存未命中、命中和依赖升级后的重新构建结果 | 不改变安装内容 |

## 固定边界

- 不重新发布或修改 `v0.65.0` 制品；
- 不引入 Render Graph、Bindless 公共 API 或新的第三方包管理器；
- Runtime 缓存必须以平台和三套 Khronos 源码提交哈希为身份，禁止跨版本复用；
- 缓存命中只能跳过可复现的构建步骤，Release 仍必须执行制品清单、SHA-256 和公开下载复核。

## 阶段出口

1. `v0.65.0` 的发布状态文档全部与 GitHub tag、Release 和验收记录一致；
2. Release 首次运行能够完整构建 Runtime，后续相同依赖版本运行能够命中缓存；
3. 任一 Vulkan 源码提交变化都能触发对应平台 Runtime 重建；
4. ImGui Consumer 在 Windows/Linux/Emscripten 和 shared/static 目标中通过编译或 Smoke 验收；
5. 发布流程继续通过 Runtime 内容校验、SHA-256 和公开 Release 下载复验。
