# v0.57.0：诊断硬化与跨后端回归

## 状态

**已发布（2026-10-09）。** 详细范围由 [S-93](../plans/S-93-0.57.0-diagnostics-hardening-and-regression.md) 定义，
验收证据见 [v0.57.0 发布验收](../records/2026-10-09-v0.57.0-release-acceptance.md)。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| S-93 诊断硬化与跨后端回归 | Frame Trace 语义、后端命令回归、统一 CI 附件、RenderDoc 手动验收指南 | 不新增公共 ABI 或第三方运行时依赖 |

## 版本边界

- Frame Trace 继续默认关闭，并保持内部开发期 JSONL；
- Vulkan/WebGPU 诊断只增强回归和错误保留，不改变正常录制语义；
- RenderDoc 仅作为用户安装的可选开发工具，不随 SDK 或 Runtime Bundle 发布；
- Bind Group 继续是默认资源绑定模型，Bindless、SVT 和纹理驻留不进入本版本；
- 不新增公共 GPU Profiler、Frame Trace、RenderDoc、Vulkan 或 Dawn 接口。

## 发布门槛

- Windows/Linux/Emscripten 相关构建、Consumer 和浏览器验证通过；
- tutorial-06、Model Viewer、PBR/压力测试和现有像素测试通过；
- Frame Trace 校验器覆盖正常、截断、丢事件和写入失败路径；
- RenderDoc 存在/不存在路径和公共 SDK 依赖审计通过；
- 默认关闭诊断时 ABI、性能基线和默认渲染路径无回归。
