# v0.40.0：Deferred 与多 Pass 渲染验证

## 状态

**功能实现与本地验收完成，正在执行远端发布门禁。** 当前开发分支为
`feature/0.40-deferred-rendering`。

## 版本目标

本版本通过一个跨后端 Deferred Tutorial 验证 v0.38.0 已补齐但尚未形成完整示例的 MRT，以及
G-buffer 创建与采样、多 Pass 资源依赖、窗口 Resize 和统一交互运行时。实现结果将为后续是否需要
公共 Transient Texture 或 Render Graph 提供证据，但本版本不预设这些公共抽象。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| [S-75 Deferred 与多 Pass 渲染](../plans/S-75-0.40.0-deferred-rendering.md) | `07_deferred`、MRT G-buffer、全屏光照、调试视图、跨后端自动验收 | 默认无；优先使用现有 API，发现公共能力缺口时另立计划 |

## 不进入本版本

- 不实现公共 Render Graph、Transient Texture、Async Compute 或多 Queue；
- 不实现 Bindless、Clustered/Forward+ Lighting、透明 Deferred 或完整 Deferred PBR；
- 不把 Tutorial Runtime、Orbit Camera 或示例资源管理提升为公共 SDK；
- 不同时重构现有 RenderPipeline 或替换 Forward PBR 路径；
- 不为尚未稳定的 0.x 历史接口保留兼容入口。

## 发布门槛

- `07_deferred` 在桌面 Vulkan 与浏览器 WebGPU 使用相同 C++ 主体和 HLSL-first Shader Library；
- Geometry、Lighting、G-buffer 调试模式和 Resize 通过自动行为测试；
- Vulkan/WebGPU Validation、Windows/Linux、Emscripten 与浏览器测试通过；
- 公共头、安装 Consumer、文档检查和共享 SDK 发布工作流通过；
- 用户可见变化写入 Changelog，实施证据写入独立 Record 后再发布 `v0.40.0`。
