# v0.50.0：公共 API/ABI 稳定候选审计

## 状态

**已完成，2026-10-07 发布。** 详细范围由 [S-86](../plans/S-86-0.50.0-api-abi-stability-candidate.md) 定义。本版本
收敛稳定边界和兼容证据，不冻结整个 0.x ABI，也未新增大型渲染功能。

## 固定范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| [S-86 公共 API/ABI 稳定候选审计](../plans/S-86-0.50.0-api-abi-stability-candidate.md) | component 稳定等级、布局/符号门禁、Consumer 与兼容文档 | 默认不新增公共 ABI |

## 不进入本版本

- Bindless、Clustered Forward、Cascaded Shadow Maps 和 Android；
- SVT、纹理驻留预算、回收调度和 Gneiss 专用资源系统；
- Vulkan 原生公共接口或 Vulkan SDK/驱动分发。
