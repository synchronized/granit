# v0.65.0：示例第三方依赖缓存收敛

## 状态

**实施中。** 本版本由 [S-101](../plans/S-101-0.65.0-example-dependency-cache.md) 承担，承接
v0.64.0 的 ImGui 输入适配，重点解决全新静态或离线配置时示例依赖下载不稳定的问题。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| glTF 依赖缓存 | 将 cgltf 与 stb_image 接入 `vendor/cache` 共享源码缓存 | 不进入安装包或公共 ABI |
| 获取策略一致性 | 统一 `system / auto / download` 行为，并保留 SHA-256 校验 | 不改变运行时 API |
| 构建复用 | 让不同平台、静态/共享和不同 preset 复用同一份只读源码 | 不共享编译产物 |
| CI 与离线验证 | 增加缓存命中、缓存缺失和 system 策略验证 | 不新增传递依赖 |
| 文档与许可证 | 更新构建指南、第三方通知和版本验收记录 | 不改变安装内容 |

## 固定边界

- 只缓存可重新生成的第三方源码归档和解压源码，不提交第三方源码到 Git；
- Vulkan SDK、编译器、Threads、XCB/Wayland 等系统工具链不纳入项目源码缓存；
- cgltf 与 stb_image 仍是示例 glTF 支持的私有依赖，不成为 Granit 核心库或安装 SDK 的依赖；
- 不修改公共 C/C++ API、ABI、资产格式或渲染行为。

## 阶段出口

1. cgltf 与 stb_image 在 `vendor/cache/archives` 和 `vendor/cache/sources` 中使用锁定版本与校验和；
2. Model Viewer 和依赖 glTF 支持的示例不再直接在各自构建目录下载源码；
3. Windows 静态配置能够越过示例依赖准备阶段，或在离线 `system` 模式下给出明确诊断；
4. 共享/静态构建、相关 glTF 测试和文档检查通过；
5. 本版本计划、CHANGELOG 和验收记录完成发布收口。
