# v0.60.0：Resource Table Shader 集成与真实压力

## 状态

**规划中。** 详细实施方案见 [S-96](../plans/S-96-0.60.0-resource-table-shader-and-pressure.md)。

## 版本目标

让 v0.59.0 的 Resource Table 公共契约进入真实 Shader/Material 采样路径，并用可见教程和跨平台
压力数据判断实验 API 是否值得继续保留。

## 计划交付

| 任务 | 交付内容 | 公共 SDK 影响 |
|---|---|---|
| S-96A Shader 绑定模型 | 两种绑定模型变体、反射和 Pipeline 布局校验 | 扩展实验性描述，不改变默认路径 |

| S-96E 跨平台收口 | Windows/Linux Vulkan、Lavapipe、Chrome WebGPU 验收 | 决定实验 API 保留、收缩或删除 |

## 版本边界

- Bind Group 仍是默认路径；Resource Table 必须显式选择；
- WebGPU 不支持原生 Resource Table 时使用 Bind Group 回退，不宣称 bindless；
- 不实现 SVT、纹理驻留、预算、VFS、Model Viewer 全量迁移或全量 PBR 变体迁移；
- 不把每个渲染功能扩展成独立变体维度，绑定模型必须与其他功能正交管理；
- 失败时优先保持安全和可诊断，不以绕过 GPU 完成点换取实验性能。

## 发布门槛

- Shader/Material 变体、生命周期、ABI、负向测试和压力数据通过；
- 版本文档、计划、验收记录和 CHANGELOG 完成收口后，才允许创建 tag 和 Release。
