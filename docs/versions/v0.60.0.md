# v0.60.0：Resource Table 材质契约与真实压力

## 状态

**已发布（2026-10-12）。** 详细范围和验收结果见 [S-96](../plans/S-96-0.60.0-resource-table-shader-and-pressure.md)
及 [v0.60.0 验收记录](../records/2026-10-12-v0.60.0-resource-table-acceptance.md)。

## 版本目标

让 v0.59.0 的 Resource Table 公共契约进入 Material 的生命周期和绘制绑定路径，并用可见教程、
压力入口和跨后端回退契约验证实验 API 的安全性。默认 Bind Group 路径保持不变。

## 版本边界

- Bind Group 仍是默认路径；Resource Table 必须显式选择；
- WebGPU 不支持原生 Resource Table 时使用 Bind Group 回退，不宣称 bindless；
- 不实现 SVT、纹理驻留、预算、VFS、Model Viewer 全量迁移或全量 PBR 变体迁移；
- 不把每个渲染功能扩展成独立变体维度，绑定模型必须与其他功能正交管理；
- 失败时优先保持安全和可诊断，不以绕过 GPU 完成点换取实验性能。
