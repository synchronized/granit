# v0.68.1：独立 Consumer 与测试依赖构建修复

## 状态

**发布范围已收口，2026-10-20。** 本补丁版本修复 v0.68.0 发布后的独立 Web Consumer 配置问题，
不新增公共 API/ABI，不改变运行时渲染行为。

## 固定范围

- 统一 Catch2、Unity 测试依赖的 CMake 集成入口；
- 移除 `3rd/` 中已经迁移到 `vendor/cache` 的测试框架源码副本；
- 修复独立 Emscripten Web Consumer 未继承依赖策略和源码缓存目录的问题；
- 验证完全缓存、离线模式和浏览器独立 Consumer；
- 收口版本计划、路线图和实施记录状态。

## 非目标

- 不新增公共 C/C++ API、ABI 或 Vulkan 互操作接口；
- 不改变生产库的运行时依赖边界；
- 不升级 Catch2、Unity 或其他第三方锁定版本；
- 不提供新的图形能力或渲染行为变化。
