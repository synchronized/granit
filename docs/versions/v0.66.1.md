# v0.66.1：Linux Runtime 缓存恢复修复

## 状态

**已发布，2026-10-19。** 本版本是 v0.66.0 的 CI 修复版本，不改变公共 API、ABI、Runtime 内容或安装布局。

## 范围

- 将 Linux Runtime 构建移到标准 Ubuntu Runner，修复容器缓存恢复不稳定导致的重复编译；
- 保留缓存未命中时的完整 Khronos Runtime 构建和现有制品校验；
- 通过 Windows/Linux 重复 Release 验证缓存命中路径。
