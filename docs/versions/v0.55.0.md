# v0.55.0：Bindless 真实压力与边界复评

## 状态

**规划中。** 详细范围由 [S-91](../plans/S-91-0.55.0-bindless-pressure-and-boundary.md) 定义。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| S-91 Bindless 真实压力与边界复评 | 多材质/多纹理 A/B、跨平台能力矩阵、GPU/资源占用数据和准入结论 | 不预设新增公共 Bindless ABI |

## 版本边界

- 传统 Bind Group 继续是默认路径；
- Vulkan Bindless 只作为内部显式实验变体；
- WebGPU/Emscripten 继续使用 Bind Group，不模拟 Vulkan Bindless；
- 不进入 Descriptor Buffer、SVT/纹理驻留或 Vulkan 公共接口；
- 是否进入后续公共 API，只由 S-91 的真实数据决定。

## 发布门槛

- Windows Vulkan 硬件和 Linux/Lavapipe 有可复现 A/B 结果；
- 不支持设备保持完整传统路径；
- CPU 录制、GPU 时间、Descriptor/显存占用和容量耗尽有证据；
- Vulkan Validation、资源 generation 和 GPU 延迟回收测试通过；
- C11/C++20 Consumer、WebGPU 回退和文档链接回归通过。
