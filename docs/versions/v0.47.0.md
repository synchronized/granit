# v0.47.0：Vulkan Runtime Bundle 与验证层交付

## 状态

**候选发布中。** 本版本范围由 [S-83](../plans/S-83-0.47.0-vulkan-runtime-bundle.md) 定义，
重点是让应用在缺少系统 Vulkan Loader 时可以选择使用随应用分发的 Loader，同时保持 Vulkan SDK、
驱动和公共 ABI 边界不变。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| [S-83 Vulkan Runtime Bundle](../plans/S-83-0.47.0-vulkan-runtime-bundle.md) | Windows/Linux Loader Bundle、`auto` 选择、Debug Validation Layer Bundle | 不新增公共 ABI；增加构建/打包选项 |

## 不进入本版本

- NVIDIA、AMD、Intel 等厂商驱动或 ICD；
- Vulkan SDK、Headers、Validation Layer 进入普通 Granit SDK；
- macOS 完整 MoltenVK Runtime Bundle；
- 新的 Vulkan 原生公共接口；
- 将 Loader 静态合入 Granit 共享库。

## 发布门槛

- Windows/Linux Runtime Bundle 的来源、许可证、manifest 和 SHA-256 可复验；
- system、bundled、auto、Loader 缺失和 ICD 缺失场景有明确结果；
- Debug Validation Layer 的 `auto/on/off` 行为通过验证；
- Release 默认关闭验证层；
- 安装 Consumer、共享/静态构建、Linux/Windows CI 和现有 Vulkan/WebGPU 回归全部通过；
- 公开下载的 Runtime/Validation 归档与发布 manifest 一致。
