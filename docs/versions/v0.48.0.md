# v0.48.0：Runtime Consumer 与图形能力验证

## 状态

**已完成，2026-10-07 发布。** 详细范围由 [S-84](../plans/S-84-0.48.0-runtime-consumer-and-capability-verification.md)
定义。本版本承接 v0.47.0 的 Runtime Bundle，完成真实应用接入和跨平台能力证据，不新增公共 ABI
或大型图形功能。

## 固定范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| [S-84 Runtime Consumer 与图形能力验证](../plans/S-84-0.48.0-runtime-consumer-and-capability-verification.md) | 安装 Consumer、Bundle 部署指南、Loader/Validation 诊断、Tutorial 能力矩阵收口 | 默认不新增公共 ABI |

## 不进入本版本

- Vulkan 厂商驱动、ICD、Vulkan SDK 或 Headers 的分发；
- SVT/虚拟纹理、纹理驻留预算和回收调度；
- OIT、GPU-driven 多批次、Bindless 和专用 Particle 公共 API；
- 新的 Vulkan 原生公共接口；
- macOS MoltenVK Runtime Bundle。

## 发布门槛

- Windows/Linux 安装 Consumer 和 Runtime Bundle 部署验证通过；
- Loader、Validation Layer、驱动/ICD 缺失均有明确结果和诊断；
- Tutorial 能力矩阵和 Vulkan/WebGPU Smoke 验收通过；
- 共享/静态 SDK、文档、现有 Vulkan/WebGPU 回归和公开制品校验通过。
