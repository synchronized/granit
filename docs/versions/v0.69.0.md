# v0.69.0：跨工具链验收与本地长测

## 状态

**实施中，2026-10-24。** 本版本建立按成本分层的验证体系。实现已提交，正在补齐平台与长测验收；
未执行的组合不计为通过。工程版本号仍为 0.68.1。

## 固定范围与依赖

| 顺序 | 计划 | 阶段出口 |
|---|---|---|
| 1 | [S-108：验证入口与报告](../plans/S-108-0.69.0-validation-entrypoints.md) | CTest、脚本和产物职责统一 |
| 2 | [S-109：手动兼容矩阵](../plans/S-109-0.69.0-manual-compatibility-matrix.md) | 关键版本可手动验收多工具链 |
| 3 | [S-110：本地长测](../plans/S-110-0.69.0-local-soak-tests.md) | 真实硬件长测可运行、可复现、可归档 |

三个阶段在同一个特性分支连续开发，按阶段验证并提交，完整任务使用一个 Pull Request。
S-109 与 S-110 依赖 S-108 的入口和报告约定；本版本全部阶段验收后再收口发布。

## 执行策略

- PR 保留 Quick Check 与适用的文档检查；完整 Windows、Linux、Emscripten 验收改为手动触发。
- 扩展兼容矩阵只允许手动触发，不绑定 PR、push、定时任务或 tag。
- 公共 API/ABI、编译器或依赖升级、安装导出、平台生命周期变化，以及稳定候选里程碑，
  在候选提交上执行受影响的兼容验收；普通补丁按范围选择，不要求每个版本全量运行。
- 长测由开发者在本地显式启动；本版本至少完成可获得的 Windows/Linux 各一套真实 GPU 验收。
  未获得的显卡厂商与驱动组合必须列为未覆盖项。
- 验收绑定提交号。后续改动使受影响证据失效，需要重新验证；跳过、缺少设备与通过分别记录。

## 非目标

- 不冻结 0.x API/ABI，不以测试矩阵代替兼容性承诺。
- 不新增渲染功能、生产依赖或公共 Vulkan 接口。
- macOS、ARM64、多 Linux 发行版和多浏览器覆盖留待后续版本明确后端与环境后规划。
- 不将全部系统、工具链、构建模式和 GPU 做笛卡尔积，也不建立云端长测基础设施。

## 验收中发现的修复

本版本同时修复长 Shader 名称的缓存路径膨胀、静态教程退出时的资源释放、
MSVC 测试变量遮蔽、Unlit 测试的量化边界输入，以及 generation 回绕复活旧句柄的问题；
公共 API/ABI 未改变。
