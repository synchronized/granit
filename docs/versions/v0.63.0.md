# v0.63.0：Vertex Streams 与 PBR 顶点属性验证

## 状态

**规划中。** 详细实施方案见 [S-99](../plans/S-99-0.63.0-vertex-streams-and-pbr-attributes.md)。

## 版本目标

用两个小型、可复现的示例验证 Granit 现有多 Vertex Buffer 和标准 PBR 顶点属性能力，明确
Buffer 绑定时序、UV/Tangent 要求和纯色 PBR 的无纹理路径。

## 计划交付

| 任务 | 交付内容 | 公共 SDK 影响 |
|---|---|---|
| S-99A Multiple Vertex Streams | 交错/拆分 Vertex Buffer、Index Buffer、Instance Stream 对照 | 无 |
| S-99B PBR Vertex Attributes | UV0、Tangent、Normal Map、纯色/纹理 PBR 变体矩阵 | 无 |
| S-99C 跨平台与文档 | Windows、Linux、Chrome WebGPU、安装 Consumer 和验收记录 | 无 |

## 资源边界

- 多流示例使用仓库程序化几何，不引入外部模型；
- PBR 示例复用现有 CC0 Suzanne 和两张 PBR 纹理；
- Normal Map 优先使用运行时生成的确定性小纹理，不复制 bgfx 资产；
- 如确实需要新增图片，必须补充来源、许可证、摘要和固定校验值。

## 发布门槛

- 两个示例均有固定 Smoke 和交互路径；
- PBR 变体明确区分无 UV、UV0 和 UV0 + Tangent；
- 多 Vertex Buffer 的绑定顺序和 Rendering 内限制有文档与回归覆盖；
- Windows Vulkan、Linux Lavapipe、Chrome WebGPU 和安装 Consumer 验收通过；
- 文档、CHANGELOG、验收记录和发布脚本门禁全部收口。
