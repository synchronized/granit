# v0.68.0：测试依赖获取与父项目兼容性收敛

## 状态

**已发布，2026-10-20。** [GitHub Release v0.68.0](https://github.com/synchronized/granit/releases/tag/v0.68.0)。
本版本统一 Catch2、Unity 与现有下载型依赖的获取策略，改善 Granit 作为父项目
子目录接入时的 target 复用、版本兼容和离线构建行为。不新增公共 C ABI，不改变生产库的运行时
依赖边界。

## 固定范围

- Catch2、Unity 纳入 `system/auto/download` 依赖策略；
- 使用 `vendor/cache` 统一缓存源码、校验哈希和锁定版本元数据；
- 父项目已提供兼容 target 时优先复用，避免重复下载和重复编译；
- 对可识别版本执行最低版本和主版本兼容检查；
- 对无法取得版本信息但 target 存在的父项目依赖给出明确警告；
- 保持测试依赖私有，不进入 Granit 安装导出和生产库传递依赖；
- 增加父项目 target、系统包、自动下载、强制下载和离线缓存的配置验证。

## 非目标

- 不强制父项目使用 Granit 的精确依赖版本；
- 不把测试框架作为 Granit 公共 API 或安装 SDK 依赖；
- 不新增公共 C/C++ API、Vulkan 互操作接口或渲染功能；
- 不在没有兼容性证据时删除已有父项目 target 复用路径。

## 发布门槛

- [x] 依赖目录、锁定版本、URL、SHA-256 和许可证信息完整；
- [x] Catch2、Unity 的 `system/auto/download` 路径均可配置；
- [x] 父项目兼容 target 不重复下载或编译；
- [x] 源码缓存支持并发锁、完成收据和离线模式；
- [x] Windows Clang Release 的缓存回归、文档检查和完全缓存配置通过；
- [x] 明确不兼容版本配置失败，未知版本配置产生警告；
- [x] Windows/Linux shared/static 构建、测试和打包通过；
- [x] 文档、CHANGELOG、验收记录和公开制品复核完成。
