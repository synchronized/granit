# v0.70.0：Window 原生句柄与 Surface 解耦

## 状态

**发布准备中，2026-10-28。** 本版本包含 Window 公共 API/ABI 破坏性调整，目标是移除 Window 对
Renderer 的直接依赖，并统一由上层组织原生窗口句柄与 Surface 创建。

## 固定范围

- Window 返回带后端标签的原生窗口快照；
- SDL3 提供独立的原生窗口查询和 Surface 集成入口；
- 删除 Window 直接创建 Surface 的 C/C++ 接口及 presentation 头文件；
- 迁移示例、测试、安装 Consumer，并补充 ABI 和文档门禁。
