# v0.43.0：Gneiss PBR 兼容性审计

## 状态

**规划中。** 本版本先核对 Gneiss `UPSTREAM-043` 与 Granit v0.42.0 的已发布 PBR 契约，
不重复实现 v0.41.0 已完成的五项基础能力。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| [S-80 Gneiss PBR 兼容性审计](../plans/S-80-0.43.0-gneiss-pbr-compatibility.md) | 逐项核对透明、镂空/双面、UV/Sampler、负缩放和顶点色的实现、测试与接入边界 | 默认不新增公共 API；只修复确认属于 Granit 的通用缺口 |

## 不进入本版本

- 重复实现 v0.41.0 已发布的五项标准 PBR 能力；
- Gneiss 的导入器、资产格式、RID、缓存、调度器和场景系统；
- 折射、透射、体积材质、透明阴影、OIT 和 `KHR_texture_transform`；
- 没有独立复现和通用验收证据的上游问题。

## 发布门槛

- 五项 PBR 契约的 Granit 现有 CPU/GPU 回归通过；
- Granit 文档统一描述当前行为和明确限制；
- Gneiss 接入问题与 Granit 公共契约问题完成责任分类；
- 若没有 Granit 侧缺口，形成审计记录后再决定是否发布维护性版本。
