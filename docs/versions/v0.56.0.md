## 版本边界

- RenderDoc 只作为开发期可选工具，不随 Granit SDK 或 Runtime Bundle 发布；
- Frame Trace 默认关闭，首版为内部开发诊断格式；
- 可通过 `GRANIT_FRAME_TRACE` 输出诊断 JSONL，并通过 `GRANIT_FRAME_TRACE_MAX_EVENTS` 限制缓冲区容量；
- Vulkan 使用 Debug Label、Timestamp 和资源生命周期数据，WebGPU 输出可用的跨后端字段；
- WebGPU 使用 Label、Debug Group、错误作用域和可选 Timestamp Query；浏览器工具仅作为外部辅助；
- 不新增公共 GPU Profiler ABI，不实现 RenderDoc 替代品；
- Bindless 继续是 Vulkan 内部实验，传统 Bind Group 和 WebGPU 回退保持不变。

## 发布门槛

- RenderDoc 存在和不存在两种环境均可运行；
- Windows Vulkan capture 至少完成一帧稳定对象/事件标记验收；
- Linux Vulkan 和 Emscripten/WebGPU 的 Trace/no-op 路径通过；
- Emscripten/WebGPU 在缺少 Debug Group 或 Timestamp Query 时正确记录能力缺失，不阻塞渲染；
- Model Viewer、PBR 压测和 CI 失败附件可以关联 CPU/GPU/资源事件；
- 默认关闭诊断时现有跨平台、像素、ABI 和 Consumer 测试继续通过。
