# v0.73.0：Renderable 阴影控制

## 状态

**规划中，2026-11-20。** 本版本聚焦 RenderPipeline 中 Renderable 实例的阴影投射和接收语义，
不改变默认渲染结果。

## 固定范围

- 为 `granit_scene_renderable` 增加投射/接收阴影控制标志；
- 默认零值保持投射和接收均开启；
- 关闭投射的实例仍进入主视图，但不进入 Shadow Caster 集合；
- 关闭接收的实例仍参与主视图和非阴影光照，但跳过阴影采样；
- 补齐 C/C++ API、PBR Shader、Scene Snapshot、RenderPipeline 和回归测试。

## 不在范围内

- 每灯光阴影策略、阴影质量和阴影算法调整；
- Spot/Point Light 阴影；
- 材质级或全局阴影开关；
- 公共 Render Graph API 改造。
