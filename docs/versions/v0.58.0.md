## 版本边界

- Frame Trace 继续默认关闭并保持内部 JSONL；
- RenderDoc 继续是外部可选开发工具，不进入 SDK 或 Runtime Bundle；
- Bind Group 继续是默认资源绑定模型，Bindless、SVT 和纹理驻留不进入本版本；
- 不新增公共 GPU Profiler、Frame Trace、RenderDoc、Vulkan 或 Dawn 接口。

- Windows Vulkan 硬件生成 `.rdc`，Linux/no-op 和 Emscripten 边界有证据；
- Windows/Linux/Emscripten 相关构建、Consumer、文档和现有像素测试通过。
