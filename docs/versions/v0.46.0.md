# v0.46.0：WebGPU 浏览器生命周期与跨平台可靠性

## 状态

**已于 2026-10-06 发布。**
[GitHub Release v0.46.0](https://github.com/synchronized/granit/releases/tag/v0.46.0) 已包含本版本范围。
本版本收敛了 Emscripten WebGPU 初始化、Pipeline 预热、异步 Readback 和浏览器验收环境的生命周期处理。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| WebGPU 生命周期可靠性 | 保持初始化、Pipeline、Readback 的 Instance/Buffer 生命周期，并补充诊断 | 不新增公共 ABI |
| 浏览器 WebGPU 验收 | 统一 Linux CI 的 SwiftShader Vulkan/ANGLE 配置，覆盖 Model Viewer、ImGui 和 Tutorials | 不改变桌面 Vulkan API |
| 浏览器测试收敛 | 区分正式 Model Viewer 与 runtime 控制页的验收条件 | 仅测试与内部实现 |

## 发布验收

- Linux、Windows、Emscripten、共享/静态 Consumer 和 WebGPU 编译检查通过；
- Browser Platform Smoke、Model Viewer、Model Viewer Runtime、ImGui 和 Tutorial 01–07 全部通过；
- Release 打包、SHA-256 和公开下载复验通过。
