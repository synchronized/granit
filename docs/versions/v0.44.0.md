# v0.44.0：独立纹理变体上传

## 状态

**规划中。** 本版本承接 Gneiss `UPSTREAM-044` 的 U44-01，补齐 Texture Asset Manifest
后续变体以局部 Payload 上传的公共接口，不把 Gneiss 的驻留预算和调度模型下沉到 Granit。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| [S-81 独立纹理变体上传](../plans/S-81-0.44.0-texture-variant-upload.md) | 以所选变体起点为基址上传完整变体，保留旧完整 Payload 入口 | 新增 C/C++ 上传入口；旧入口语义不变 |

## 不进入本版本

- Gneiss 的 VFS、Manifest 文件读取、资源预算、任务调度和 RID 生命周期；
- 视距驱动 Mip 流送、虚拟纹理、纹理 LOD 和通用全引擎内存管理器；
- 只上传部分 Mip 的局部摘要协议；
- 新压缩格式家族、公共 glTF/Scene SDK 和后端专用接口。

## 发布门槛

- 独立首个/后续变体、RGBA8 回退和完整 Payload 兼容路径的 CPU/GPU 回归通过；
- 校验失败、预算不足、取消、销毁和调用方释放缓冲的生命周期测试通过；
- Vulkan、WebGPU、共享/静态安装 Consumer 和文档检查通过；
- Gneiss 可直接复用新入口，但其驻留预算与加载事务仍保持在 Gneiss。
