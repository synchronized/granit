# 版本规划

本目录记录当前版本的固定范围和发布门槛，并为最近发布版本保留最终范围索引。详细实现方案位于
[`docs/plans`](../plans/README.md)，用户可见变化以 [Changelog](../../CHANGELOG.md) 为准，实际验收
证据位于 [`docs/records`](../records/README.md)。

版本文档不复制各任务的设计和步骤。版本发布后只保留最终范围、Release 和验收记录链接，不继续
承担当前行为参考。
