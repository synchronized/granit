# v0.54.0：Vulkan Bindless 准入验证

## 状态

**已发布（2026-10-08）。** 详细范围由 [S-90](../plans/S-90-0.54.0-vulkan-bindless-admission.md)
定义。发布入口：[GitHub Release v0.54.0](https://github.com/synchronized/granit/releases/tag/v0.54.0)。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| S-90 Vulkan Bindless 准入验证 | 内部 Descriptor Indexing 对照、生命周期契约、A/B 数据和回退验收 | 不新增公共 Bindless ABI |

## 版本边界

- Vulkan 仅验证 sampled texture/sampler 的内部实验路径；
- 传统 Bind Group 仍是默认路径，Bindless 不自动启用；
- Emscripten/WebGPU 继续使用 Bind Group，不模拟 Vulkan Bindless；
- 不进入 Descriptor Buffer、SVT/纹理驻留、VFS、Gneiss 资源调度或 Vulkan 公共接口；
- 是否进入后续公共 API，由真实 A/B 数据和生命周期验收决定。

## 发布门槛

- Vulkan Validation 无相关错误，实验绘制和像素回读正确；
- Windows、不支持设备回退和 Emscripten 不引入 Vulkan Bindless 的边界有证据；Linux/Lavapipe
  的重复运行列入后续版本；
- 传统 Bind Group、C11/C++20 Consumer 和文档链接回归通过；
- 若性能收益不稳定，明确保留 Bind Group 默认路径，不以实验成功冒充产品能力。
