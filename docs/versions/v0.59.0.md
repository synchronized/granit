# v0.59.0：Resource Table 实验性 API

## 状态

**已完成，待发布。** 详细范围和延期项由 [S-95](../plans/S-95-0.59.0-resource-table-experimental-api.md) 定义。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| S-95 Resource Table 实验性 API | Resource Table C/C++ API、Vulkan descriptor 更新、Pipeline Layout/Command Recorder 绑定、逻辑回退和 Tutorial 12 | 新增明确标记为 Experimental 的可选 API；不改变 Bind Group 默认路径 |

## 版本边界

- Resource Table 是实验性跨后端抽象，不等同于所有设备都支持 Vulkan Bindless；
- Vulkan 使用现有 Bindless 原型，WebGPU 按能力选择受限实现或 Bind Group/Buffer Table 回退；
- 不新增 Vulkan 公共类型，不实现 SVT、纹理驻留、预算、VFS 或任务调度；
- Tutorial 01～11 和 Model Viewer 保持 Bind Group 默认路径，Tutorial 12 验证实验 API；
- Shader/Material 绑定模型变体和真实跨平台压力延期到 v0.60.0，不把未完成能力宣称为本版本交付。

## 发布门槛

- 公共 API/ABI、安装 SDK、句柄生命周期和负向行为测试通过；
- Vulkan Validation、Resource Table/Bind Group 像素一致性和真实压力对照通过；
- WebGPU 自动模式逻辑回退和显式不支持错误路径已有契约测试；Chrome Shader 变体验证延期到 v0.60.0；
- Tutorial 12 Windows Vulkan smoke 通过，Tutorial 01～11 和 Model Viewer 默认路径不变；
- 变体数量、构建时间、资产大小和真实 CPU/GPU 数据延期到 v0.60.0；
- 实验性 API 的删除、回退和迁移边界已记录。

## 发布状态

待完成发布前的 CHANGELOG、验收测试和公开制品复核；版本文档已完成收口，延期项已明确记录。
