# v0.59.0：Resource Table 实验性 API

## 状态

**规划中。** 详细范围由 [S-95](../plans/S-95-0.59.0-resource-table-experimental-api.md) 定义。

## 计划交付

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| S-95 Resource Table 实验性 API | Resource Table C/C++ API、Vulkan 实验实现、WebGPU 回退、Shader 变体和 Tutorial 13 | 新增明确标记为 Experimental 的可选 API；不改变 Bind Group 默认路径 |

## 版本边界

- Resource Table 是实验性跨后端抽象，不等同于所有设备都支持 Vulkan Bindless；
- Vulkan 使用现有 Bindless 原型，WebGPU 按能力选择受限实现或 Bind Group/Buffer Table 回退；
- 不新增 Vulkan 公共类型，不实现 SVT、纹理驻留、预算、VFS 或任务调度；
- 旧 Tutorial 和 Model Viewer 保持 Bind Group 默认路径，新增 Tutorial 13 验证实验 API；
- 变体只按绑定模型和必要的静态布局差异生成，控制变体数量和资产膨胀。

## 发布门槛

- 公共 API/ABI、安装 SDK、句柄生命周期和负向行为测试通过；
- Vulkan Validation、Resource Table/Bind Group 像素一致性和真实压力对照通过；
- Chrome WebGPU 支持级别、回退和不支持错误路径通过；
- Tutorial 13 通过，Tutorial 01～12 和 Model Viewer 默认回归通过；
- 变体数量、构建时间、资产大小和 CPU/GPU 数据满足计划上限；
- 实验性 API 的删除、回退和迁移边界已记录。
