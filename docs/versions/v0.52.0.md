# v0.52.0：真实绑定压力与 Resource Table 闸门

## 状态

**已发布（2026-10-07）。** 本版本通过 [S-88](../plans/S-88-0.52.0-binding-pressure-and-resource-table-gate.md)
完成真实 Shader 采样绑定压力基线，发布制品见
[GitHub Release v0.52.0](https://github.com/synchronized/granit/releases/tag/v0.52.0)，验收证据见
[S-88 记录](../records/2026-10-07-s88-binding-pressure-baseline.md)。

## 固定范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| [S-88 真实绑定压力与 Resource Table 闸门](../plans/S-88-0.52.0-binding-pressure-and-resource-table-gate.md) | 压力 Consumer、传统路径基线、能力闸门和可选内部原型 | 默认不新增公共 ABI |

## 不进入本版本

- 默认 Bindless、SVT/纹理驻留、VFS、任务调度和 Gneiss 资源系统；
- Descriptor Buffer、Ray Tracing、Mesh Shader 和 Clustered Forward；
- Vulkan 原生公共接口或 Vulkan SDK/驱动分发。

## 最终结论

- `pbr_textured` 片元 Shader 实际采样五类材质纹理，并完成 8/64/512 材质规模的绑定压力基线；
- 传统 Bind Group 继续作为默认路径，未新增公共 ABI；
- 当前数据不足以证明 Resource Table 或 Bindless 能解决主要瓶颈，因此本版本不进入 Resource Table
  原型，后续仍需以真实产品负载和跨设备数据重新评估。
