# v0.52.0：真实绑定压力与 Resource Table 闸门

## 状态

**实施中。** S-88A 和 Windows Vulkan 基线已完成，详细范围由 [S-88](../plans/S-88-0.52.0-binding-pressure-and-resource-table-gate.md) 定义。
本版本优先补齐真实 Shader 采样证据；是否实现 Resource Table 由验收数据决定。

## 固定范围

| 任务 | 计划交付 | 公共 SDK 影响 |
|---|---|---|
| [S-88 真实绑定压力与 Resource Table 闸门](../plans/S-88-0.52.0-binding-pressure-and-resource-table-gate.md) | 压力 Consumer、传统路径基线、能力闸门和可选内部原型 | 默认不新增公共 ABI |

## 不进入本版本

- 默认 Bindless、SVT/纹理驻留、VFS、任务调度和 Gneiss 资源系统；
- Descriptor Buffer、Ray Tracing、Mesh Shader 和 Clustered Forward；
- Vulkan 原生公共接口或 Vulkan SDK/驱动分发。
