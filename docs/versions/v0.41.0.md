# v0.41.0：标准 PBR 材质正确性

## 状态

**发布候选已通过验收。** 本版本承接真实 glTF 场景和负缩放 GPU 复现形成的标准 PBR 缺口，
详细设计见 [S-76](../plans/S-76-0.41.0-pbr-material-correctness.md)，结果见
[S-76 验收记录](../records/2026-09-29-s76-pbr-material-correctness-acceptance.md)。

## 版本目标

让标准 PBR 对透明、镂空、双面、逐贴图 UV/Sampler、负缩放切线手性和顶点色提供完整、明确、
跨后端一致的公共契约，使上层引擎无需分叉内置 Shader 或自行修正后端差异。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| [S-76 标准 PBR 材质正确性](../plans/S-76-0.41.0-pbr-material-correctness.md) | TBN 与反射实例修复、OPAQUE/MASK/BLEND、双面、逐槽 UV/Sampler、顶点色和透明 HDR Pass | 更新 PBR Schema、标准 Material 资产、Scene 分类及 RenderPipeline 行为 |

## 不进入本版本

- 折射、透射、体积材质、透明阴影和 OIT；
- `KHR_texture_transform` 或其他 glTF 材质扩展；
- Render Graph、Bindless 或通用材质节点系统重构；
- 历史 0.x PBR 资产和 API 兼容入口。

## 发布门槛

- 五项 PBR 契约均有 CPU 行为测试和必要的 GPU 像素回归；
- Vulkan 与浏览器 WebGPU 使用同一材质语义并通过 Validation；
- 正负缩放、MASK、双面、UV1、异构 Sampler、顶点色和稳定透明排序组合通过；
- Windows、Linux、Emscripten、安装 SDK Consumer、文档检查和共享 SDK 工作流通过；
- 用户可见变化与破坏性迁移写入 Changelog 和迁移指南后再发布 `v0.41.0`。

以上发布门槛均已通过；标准 PBR 资产升级步骤见
[0.40 → 0.41 迁移指南](../guides/migrate-0.40-to-0.41.md)。
