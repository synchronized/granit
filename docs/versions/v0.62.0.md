# v0.62.0：交互式图形特性教程

## 状态

**实施中。** 09、10、11 的核心示例已完成 Windows Clang Debug 验证；跨平台收口和发布门禁尚未完成。
详细设计和实施顺序见 [S-98](../plans/S-98-0.62.0-interactive-feature-tutorials.md)。

## 版本目标

把 Tutorial 09～11 从最小能力探针升级为能够解释实际渲染效果的交互式示例，同时保留固定参数
Smoke 路径，继续服务于 Vulkan、WebGPU 和 CI 回归。

## 计划交付

| 任务 | 交付内容 | 公共 SDK 影响 |
|---|---|---|
| S-98A 基础契约 | 固定 Smoke 参数、交互指标、截图/像素和浏览器验收边界 | 无 |
| S-98B Particle Generator | 球体/立方体/长方体粒子、运动参数、生命周期、实例化、面板和 Gizmo | 无，优先复用现有 API |
| S-98C Transparency Gallery | 轨道相机、多种透明模型、深度边界、对象级排序和限制说明 | 无 |
| S-98D Capabilities Inspector | Format、Mip、Sampler、Indirect 和 Renderer limits 的实际探测 | 无；API 缺口单独记录 |
| S-98E 跨平台收口 | Windows Vulkan、Linux Lavapipe、Chrome WebGPU、Emscripten 和安装构建验收 | 无 |
| S-98F 文档与发布 | 教程索引、能力矩阵、验收记录、版本文档和 CHANGELOG | 无 |

## 版本边界

- 不新增公共 Particle、Emitter、透明材质或能力缓存 API；
- 不实现 GPU 粒子模拟、OIT、逐三角形透明排序、透明阴影、折射或 SVT；
- 不复制 Model Viewer，不修改资产格式，不引入许可证不明确的外部资产；
- 交互参数与 Smoke 参数分离，保证示例可视化增强不会破坏自动回归。

## 发布门槛

- 09、10、11 均具备清晰的可视化结果和可复现的交互路径；
- 三个教程的 Smoke 在 Windows Vulkan、Linux Lavapipe 和 Chrome WebGPU 通过；
- 09 覆盖三种粒子形状、Storage Buffer、实例化、生命周期和 Alpha Blend；
- 10 覆盖 Opaque、Mask、Blend、深度测试、对象排序、轨道相机和 Resize；
- 11 对实际探测项显示支持状态和结果码，不再让文档超出源码覆盖范围；
- Vulkan Validation Layer、浏览器 Validation、安装 SDK 和 CMake 文档测试通过；
- 版本文档、实施计划、验收记录和 CHANGELOG 收口后才创建 `v0.62.0` Release。
