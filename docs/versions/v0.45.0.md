# v0.45.0：教程能力矩阵与图形特性探针

## 状态

**规划中。** 本版本通过 [S-82](../plans/S-82-0.45.0-tutorial-capability-matrix.md) 参考 bgfx 的
单项示例组织方式，验证 Granit 已有公共接口并记录真实缺口，不预先承诺新增公共 API。

## 固定范围

| 任务 | 本版本交付 | 公共 SDK 影响 |
|---|---|---|
| [S-82 教程能力矩阵](../plans/S-82-0.45.0-tutorial-capability-matrix.md) | 三个能力探针与最终能力报告 | 默认无；缺口另立计划 |

## 不进入本版本

- Stencil State、OIT、透明阴影、折射和 GPU-driven 多批次；
- SVT/虚拟纹理、资源驻留预算和 Gneiss 专用加载调度；
- 为教程抽取第二套运行时或引入新的第三方依赖。

## 发布门槛

- 新教程在 Vulkan 与 WebGPU 使用同一份 C++ 主体并通过 Smoke/浏览器验收；
- 正向/负向能力测试、Resize、安装 Consumer 和文档检查通过；
- 能力报告完成责任分类，未将教程需求直接写成公共 API；
- 若发现通用缺口，另有独立设计和跨后端验收，不以临时后端分支掩盖。
