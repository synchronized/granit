## 验证结果

- 功能 PR 的 Windows MSVC shared/static、Linux Clang/GCC shared/static、Linux integration、
  Emscripten WebGPU、安装 Consumer、Documentation 和 WebGPU 编译门禁全部通过。
- 浏览器 Model Viewer、Runtime、Platform Smoke、ImGui 与 Tutorial 01～05 全部通过；可用硬件
  Chrome 完成 MRT、Storage Texture 与异步 Readback 像素验收。
- Linux CI 软件 WebGPU 的异步 Pipeline 回退会使外部 Instance 失效；该环境验收同步 Pipeline、
  生命周期和正常渲染，不在同一实例继续执行异步像素读回。
- 版本 PR 的 Quick Check 通过，包含版本一致性、原生构建测试、文档检查和变更范围分类。
- Release 在 Windows 与 Linux 完成 shared SDK 构建、测试、安装审计、独立 Consumer 验证和
  打包；工作流生成校验文件、创建 Release，并从公开地址重新下载全部附件复验。
- 公开附件集合精确包含：
