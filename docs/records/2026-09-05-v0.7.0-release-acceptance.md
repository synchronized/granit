# 2026-09-05 Granit 0.7.0 发布验收

## 结论

Granit 0.7.0 已正式发布。标签指向已验收的 `main` 合并提交，Windows/Linux 共享与静态
SDK、浏览器 WebGPU、校验文件和公开 Release 均已验证。

## 验收结果

- 本地 Windows Clang 共享构建的 75 个测试与静态构建的 65 个测试全部通过。
- 实际安装的共享与静态 SDK 均通过包版本、component 隔离和依赖关系检查；两种链接模式各
  7 个 C11/C++20 Consumer 测试全部通过。
- Windows、Linux、Emscripten、Documentation 与候选 Release Actions 全部通过。
- Emscripten 无头 Chrome 首次遇到托管 Runner 的 Dawn 外部 Instance 瞬态丢失；工作流仅重跑
  失败作业后通过，未放宽错误判定或跳过测试。
- 标签触发的正式工作流通过版本检查、Windows/Linux 共享与静态构建、测试、安装审计、归档和
  校验文件生成，并成功创建非草稿、非预发布的公开 Release。
- 从公开 Release 重新下载 Windows 共享与静态 SDK，SHA-256 分别为
  `352c8347ff8fa6442882c8822bb707debc2215cbcd642eeb125299e58a056adf` 和
  `d881b00e82e4042a1fffd1179477e57ecf930bad16a3bc5a1c74df341aed39e7`，均与
  `SHA256SUMS` 一致。
- 公开 Windows 共享与静态 SDK 均可独立配置、构建并运行 Core、RenderPipeline、Window 与
  Input Consumer；两种链接模式各 7 个测试，合计 14 个测试全部通过。

Linux SDK 的构建、测试和安装 Consumer 由正式 Release 工作流的隔离 Linux Runner 验证；本地
Windows 发布后复验未重复运行 Linux 二进制。
