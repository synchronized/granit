# Granit v0.54.0 发布验收

## 结论

Granit v0.54.0 已完成发布并通过公开 Release 复验。本版本完成 Vulkan Bindless 的内部准入验证，
不新增公共 Bindless ABI，WebGPU/Emscripten 继续使用传统 Bind Group。

## 验证结果

- Vulkan sampled texture/sampler 索引采样、显式 Shader/Pipeline 变体和 GPU 安全回收测试通过；
- Windows Vulkan Validation 下 Bindless 后端测试通过 62 个断言；
- Windows/Linux SDK 构建、测试、安装和打包通过；
- Windows/Linux Vulkan Runtime Bundle 构建和上传通过；
- checksums 生成、待发布产物校验和公开 Release 下载复验通过；
- 公开 Release 包含 Windows/Linux shared SDK、Windows/Linux Runtime Bundle 和 `SHA256SUMS`。
