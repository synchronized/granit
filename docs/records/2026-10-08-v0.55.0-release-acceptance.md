## 版本结论

- Vulkan Bindless 保留为内部实验和验证路径；
- 传统 Bind Group 继续默认，WebGPU/Emscripten 不模拟 Vulkan Bindless；
- 本版本不新增公共 Bindless ABI，不进入 Descriptor Buffer 或 SVT；
- Linux Bindless 专项因锁定 CI 容器缺少 `glslc` 明确 skip，未将其写成 GPU 性能通过；
- Windows 本地 Vulkan Validation 下完成压力、GPU timestamp、readback、生命周期和容量耗尽验证。
