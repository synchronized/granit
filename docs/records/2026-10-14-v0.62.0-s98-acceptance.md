## 已验证

| 范围 | 结果 | 证据 |
|---|---|---|
| Tutorial 09 Smoke | 通过 | `granit.tutorial.09_particles` |

| Tutorial 11 Smoke | 通过 | `granit.tutorial.11_capabilities` |
| 代码质量 | 通过 | `git diff --check` |

Tutorial 10 当前包含共享立方体法线、方向光和环境光；方向光方向及环境光强度可通过面板调整，
并使用默认开启的 Gizmo 显示光源参考平面与传播箭头，用于观察不同透明模式下的受光面、背面和深度关系。
`Normal debug` 可直接显示片元法线颜色，用于排查索引绕序和法线映射。
`Diffuse debug` 可直接显示法线与灯光方向点积，排除材质颜色造成的判断偏差。
`Opaque only debug` 可强制所有对象走不透明深度路径，用于排查 Mask/Blend 与深度问题的边界。

验证环境为 Windows Clang Debug，三个测试均实际运行并通过。
