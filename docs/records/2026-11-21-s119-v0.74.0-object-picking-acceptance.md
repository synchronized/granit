# S-119 v0.74.0 对象 ID 输出与异步像素拾取验收

## 变更

- RenderPipeline 增加可选 `object_id_view` 输出；标准 Opaque/MASK 实例写入 `R32_UINT` 对象 ID。
- ReadbackBatch 增加 Texture View 异步回读入口，保留原始整数像素值。
- 修复 ObjectConstants 绑定组仅声明顶点阶段可见，导致片元 object ID 读取未定义的问题。

## 验证环境

- Windows 10 x64
- Clang + Ninja，`windows-clang-debug`
- Vulkan 硬件设备

## 验证结果

- `cmake --build --preset windows-clang-debug --target granit_pipeline_test`：通过；
- `granit.pipeline.api`：通过，真实 GPU 中心像素返回 `0x12345678`；
- `ctest --preset windows-clang-debug --output-on-failure`：119/119 通过；
- `git diff --check`：通过；
- 覆盖无对象 ID 输出路径、对象 ID 输出、背景清零、遮挡深度和资源生命周期回归。

## 未验证项与限制

- 本地未运行 Linux、Emscripten/Chrome、静态库和真实交换链硬件矩阵；由发布工作流继续验证。
- 首期不支持 MSAA ID resolve、透明物体、UI/debug 绘制和自定义 record 路径自动注入。
