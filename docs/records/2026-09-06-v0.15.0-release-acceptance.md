# 2026-09-06 Granit 0.15.0 发布验收

## 结论

S-30 的异步回读、Pipeline 预热、能力查询和迁移文档已经完成。Windows、Linux、Emscripten、
安装 Consumer、文档和 Release 预验证全部通过，0.15.0 达到合并与正式发布条件。

- Windows VS2022 Debug 静态库完整构建通过，CTest 68/68 通过。

## 已确认边界

- Readback Batch 复用统一异步操作状态机，结果由 Granit 持有到调用方显式复制，不跨帧持有调用方
  输出指针。
- Texture 回读公开实际行距和层距，并允许调用方选择紧密布局或后端原始布局。
- Pipeline 预热提供稳定缓存键和逐项结果；单项失败不会使 Renderer 或同批其他条目失效。
- Vulkan 与 WebGPU 均支持分批预热，但当前单条 Pipeline 编译不承诺严格非阻塞；能力位会明确
  报告这一限制。
- 文件写入、图片编码、资产调度、任务线程和公共线程池继续由上游负责。
