# 2026-09-14 Granit 0.23.0 发布验收

## 结果

Granit 0.23.0 已从 `main@496a298c` 正式发布。标签 `v0.23.0` 指向该合并提交；发布工作流复用同

  `granit-0.23.0-linux-x64-shared.tar.gz`、`granit-0.23.0-linux-x64-static.tar.gz`、
