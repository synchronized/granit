# v0.72.0 CMake IDE 目标父目录验收

## 状态

**本地实现完成，待发布候选验收，2026-11-17。** 当前未创建 v0.72.0 tag 或 Release。

## 变更范围

- 新增 `GRANIT_CMAKE_TARGET_FOLDER` 缓存字符串变量，默认为空；
- 将已有 `FOLDER` 分类作为子路径挂到配置的父目录下；
- 未分类的 `granit_*` 目标进入父目录；
- 非 `granit_*` 目标保持原有 `FOLDER`；
- 不改变 target 名称、安装导出、构建输出路径、公共 API 或 ABI。
