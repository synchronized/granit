# v0.70.0 发布验收记录

## 状态

v0.70.0 的实现与本地验收已完成，远端发布候选验收待版本提交合入 `main` 后执行。

## 发布状态

当前尚未创建 tag 或 GitHub Release。发布脚本要求版本准备提交进入 `origin/main`，并通过 Windows、
Linux 和 Emscripten 的最终候选验证后再创建公开制品。

## 验收清单

- [x] Window 不再链接或依赖 Renderer；
- [x] 旧的 Window Surface 创建 API 和 presentation 头文件已移除；
- [x] 原生窗口快照覆盖 Win32、XCB、Wayland、Emscripten 和 SDL3；
- [x] 示例、Model Viewer、Smoke、Window 测试和安装 Consumer 已迁移；
- [x] Windows Clang 相关构建、ABI、Window、文档和打包测试通过；
- [ ] 最终 main 提交的 Windows/Linux/Emscripten CI 通过；
- [ ] 公开 Release 制品下载、校验和与 manifest 复核完成。

## 本地验证证据

- 提交：`65a8aa18` 及其之前的 Window native API 修复提交；
- Windows Clang：示例、Window 平台/Renderer、ABI、文档链接和打包 Consumer 通过；
- Emscripten：Window ABI 契约构建及 native ABI 选择测试通过。
