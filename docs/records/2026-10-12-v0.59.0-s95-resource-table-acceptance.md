# S-95：Resource Table 实验性 API 验收记录

## 范围

v0.59.0 交付公共 Resource Table C/C++ 契约、能力查询、槽位更新、Vulkan descriptor 更新、
Pipeline Layout/Command Recorder 绑定和 Tutorial 12 验证。Bind Group 继续是默认路径。

## 已验证

- Windows Clang Debug 下 Granit、renderer test、C header test、C++ header test 编译通过；
- `granit.renderer.compute`、`granit.renderer.resources`、`granit.renderer.renderdoc_bridge` 和
  `granit.renderer.lifecycle_diagnostic` 全部通过；
- `granit_tutorial_12_resource_table --smoke-test` 通过；
- Resource Table 覆盖容量、类型、跨 Renderer、批量更新原子性和 Pipeline Layout 声明校验；
- Vulkan Resource Table 绑定使用 Pipeline Layout 的最后一个 descriptor set，WebGPU 显式原生
  绑定返回不支持，不产生非法后端调用。

## 未纳入本版本

- `explicit_bindings`/`resource_table` Shader 与 Material 变体及 SPIR-V/WGSL 资产生成；
- Linux Vulkan/Lavapipe、Chrome WebGPU 的真实 Shader 变体与像素一致性；
- 多材质、多纹理真实压力、GPU 时间和资源占用对照；
- Resource Table 在 GPU 在途期间更新的完成点保护。

上述内容已转入 v0.60.0 计划，不作为 v0.59.0 的发布承诺。

## 发布状态

待完成文档门禁、`git diff --check`、完整 Windows Debug 测试和公开制品复核后发布 v0.59.0。
