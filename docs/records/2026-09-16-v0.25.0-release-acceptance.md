# 2026-09-16 Granit 0.25.0 发布验收

## 结果

Granit 0.25.0 已从 `main@89f7692d` 正式发布。标签 `v0.25.0` 解引用后指向该合并提交；发布
工作流复用同提交、同标签的不可变候选产物，并在公开 Release 创建后重新下载和校验全部文件。

## 验证

- [最终 Release Candidate](https://github.com/synchronized/granit/actions/runs/35048259220)：
  Windows/Linux 的 shared/static 四套 SDK、安装审计、测试、`SHA256SUMS` 和候选 manifest 通过。
- [标签发布与公开产物复验](https://github.com/synchronized/granit/actions/runs/35048913282)：候选提交与
  标签匹配，GitHub Release 创建成功；四套 SDK 的摘要与公开下载均通过检查。
- [Granit 0.25.0 Release](https://github.com/synchronized/granit/releases/tag/v0.25.0) 包含：
  `granit-0.25.0-linux-x64-shared.tar.gz`、`granit-0.25.0-linux-x64-static.tar.gz`、
  `granit-0.25.0-windows-x64-shared.zip`、`granit-0.25.0-windows-x64-static.zip` 和 `SHA256SUMS`。

本版本完成 Window/Input 生命周期与源码布局收敛、Window 直接创建 Surface、原生平台头隔离，
并以 `presentation_mode` 统一交换链呈现模式选择。
