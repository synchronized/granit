# 2026-09-06 Granit 0.17.0 发布验收

## 结论

0.17.0 的 WebGPU 原生异步 Pipeline 预热、Vulkan/WebGPU 私有 HAL 契约、资源生命周期、
浏览器 Model Viewer、安装 Consumer 和 Release 产物预验证全部通过，达到合并与正式发布条件。

## 验证结果

- 本地 Emscripten Debug/Release 构建通过；Chrome 完成多帧渲染、质量切换、输入、Resize、资产
  Fetch、上传取消、错误诊断和资源释放验证。
- [Documentation](https://github.com/synchronized/granit/actions/runs/34038576232)、
  [Emscripten](https://github.com/synchronized/granit/actions/runs/34038444343)、
  [Linux](https://github.com/synchronized/granit/actions/runs/34038571507) 和
  [Windows](https://github.com/synchronized/granit/actions/runs/34038573999) 均通过。
- [Release v0.17.0 预验证](https://github.com/synchronized/granit/actions/runs/34038579491)通过四套
  SDK 构建、测试、安装导出审计和打包。

## 能力边界

- Vulkan 使用私有后台任务，WebGPU 使用原生 Render/Compute Pipeline Future；二者通过同一私有
  HAL 完成对象向公共异步状态机报告结果。
- 浏览器按 animation frame 零超时轮询 Future，不阻塞主线程，也不使用 Asyncify 同步等待。
- Linux CI 的软件 WebGPU 适配器会对异步 Pipeline 编译返回内部错误；Model Viewer 明确报告
  降级并按需同步创建，真实硬件上的原生异步成功路径保持不变。
- 异步操作在完成或销毁前保留 Shader、Pipeline Layout、描述数据和 WebGPU Instance 引用。
