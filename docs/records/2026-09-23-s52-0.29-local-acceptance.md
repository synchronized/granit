# 2026-09-23 S-52 0.29.0 本地验收

仍为已发布的 0.28.1；版本号、README 发布链接和 Changelog 版本标题留给 `release/0.29.0` 分支。

- Clang Debug shared：完整构建，CTest 99/99 通过。

链接，两个 MSVC Pipeline 回归已包含在完整矩阵中。
