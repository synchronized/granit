# 2026-09-23 S-52 0.29.0 本地验收

## 范围

本次验收覆盖 0.29.0 教程、Model Viewer、Mesh 录制入口和 Shader Library 逻辑名称改造。工程版本
仍为已发布的 0.28.1；版本号、README 发布链接和 Changelog 版本标题留给 `release/0.29.0` 分支。

## Windows

- Clang Debug shared：完整构建，CTest 99/99 通过。
- MSVC Debug shared：从干净配置完整构建，CTest 93/93 通过。
- MSVC Debug static：从干净配置完整构建，CTest 88/88 通过。
- shared/static 安装导出审计、component 与版本选择矩阵通过。
- shared/static 独立 C/C++ Consumer 各 7/7 通过，覆盖 Core、RenderPipeline 与 Window。

此前 Material 创建返回 `GRANIT_ERROR_NOT_READY` 的原因是测试 Material 与运行时 Library 使用了
不同来源的 Shader Object，内容 ID 不一致。测试 PBR/Unlit Library 现由当前构建实际使用的 Object
链接，两个 MSVC Pipeline 回归已包含在完整矩阵中。
