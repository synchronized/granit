# 2026-09-07 Granit 0.18.0 发布验收

## 结论

Granit 0.18.0 已正式发布。压缩纹理格式、块布局、设备能力查询及 Vulkan/浏览器 WebGPU 上传
链路均通过验收，标签指向已生成不可变候选的 `main` 合并提交。

## 验证结果

- Windows VS2022 Debug 共享库 78/78、静态库 68/68 测试通过，覆盖能力查询、块布局、错位区域、
  边缘块、即时写入、Upload Batch、ABI、C/C++ 头与构建树 Consumer。
- Emscripten Debug WebGPU 平台 Smoke 编译通过，覆盖 Provider 压缩 feature 与格式映射。
- [Quick Check](https://github.com/synchronized/granit/actions/runs/34049504589)、
  [Documentation](https://github.com/synchronized/granit/actions/runs/34049209686)、
  [Linux](https://github.com/synchronized/granit/actions/runs/34049502205)、
  [Windows](https://github.com/synchronized/granit/actions/runs/34049082983) 和
  [Emscripten](https://github.com/synchronized/granit/actions/runs/34049211749) 均通过。
- [Release Candidate](https://github.com/synchronized/granit/actions/runs/34049796350) 在提交
  `c012c15368140303ed0f84702d214de526590507` 上通过四套 SDK 构建、测试、安装审计、打包和
  SHA-256 manifest 校验。
- [v0.18.0 正式发布](https://github.com/synchronized/granit/releases/tag/v0.18.0)通过不可变候选
  身份校验与公开产物复验；Windows/Linux 共享与静态 SDK 及 `SHA256SUMS` 均已公开。

## 能力边界

- Granit 接收已经转码的 GPU 块数据，不解析 KTX2/DDS，也不内置 Basis 转码器。
- 格式支持来自运行时设备查询；缺少 BC、ETC2 或 ASTC feature 时不会静默回退。
- 压缩纹理读回与运行时 Mipmap 生成返回 `GRANIT_ERROR_UNSUPPORTED`。
