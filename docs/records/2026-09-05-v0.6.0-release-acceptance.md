# 2026-09-05 Granit 0.6.0 发布验收

## 结论

Granit 0.6.0 已正式发布。标签指向已验收的 `main` 合并提交，Windows/Linux 共享与静态 SDK、
浏览器 WebGPU、校验文件和公开 Release 均已验证。

## 验收结果

- 本地 Windows Clang 完整构建和 75 个测试全部通过；安装包精确版本、兼容版本和未知 component
  检查通过。
- Windows、Linux、Emscripten、Documentation 与候选 Release Actions 全部通过。
- Emscripten 无头 Chrome 偶发丢失软件 WebGPU 设备；CI 只在 Chromium 明确报告外部 Instance
  丢失时重启浏览器测试，其他错误仍立即失败。
- 标签触发的正式工作流通过版本检查、Windows/Linux 共享与静态构建、测试、安装审计、归档和
  校验文件生成，并成功创建公开 Release。
- 从公开 Release 重新下载四个 SDK，全部 SHA-256 与 `SHA256SUMS` 一致；Release 不是草稿或
  预发布版本。
- Windows 共享与静态 SDK 均可独立配置和构建 C11、C++20、RenderPipeline、Window 与 Input
  Consumer；两种链接模式各 7 个测试，合计 14 个测试全部通过。

Linux SDK 的构建、测试和安装 Consumer 由正式 Release 工作流的隔离 Linux Runner 验证；本地
Windows 发布后复验未重复运行 Linux 二进制。
