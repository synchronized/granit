# 2026-09-06 Granit 0.16.0 发布验收

## 结论

0.16.0 的传输背压、严格非阻塞 Pipeline 预热、共享/静态构建、浏览器 Model Viewer、安装
Consumer 和 Release 产物预验证全部通过，达到合并与正式发布条件。

## 验证结果

- 本地 Windows VS2022 Debug：共享库 78/78、静态库 68/68 测试通过。
- 本地 Emscripten Debug：WebGPU 平台 Smoke 与浏览器 Model Viewer 构建成功。
- [Documentation](https://github.com/synchronized/granit/actions/runs/34030248264)、
  [Emscripten](https://github.com/synchronized/granit/actions/runs/34030250149)、
  [Linux](https://github.com/synchronized/granit/actions/runs/34030252277) 和
  [Windows](https://github.com/synchronized/granit/actions/runs/34030253914) 均通过。
- [Release v0.16.0 预验证](https://github.com/synchronized/granit/actions/runs/34030256419)通过四套
  SDK 构建、测试、安装导出审计和打包。

## 能力边界

- Vulkan 报告严格非阻塞 Pipeline Warmup，并通过私有后台任务执行冷创建。
- WebGPU 继续提供分步预热，但在原生异步 Pipeline 回调接入前不报告严格能力。
- `NOT_READY` 是可重试背压；不会清空 Upload/Readback Batch 或遗留异步操作。
