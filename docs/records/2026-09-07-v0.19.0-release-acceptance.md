# 2026-09-07 Granit 0.19.0 发布验收

## 结论

Granit 0.19.0 已正式发布。Texture Asset Manifest v1、确定性编码、设备能力选择及逐 mip
Upload Batch 链路已完成跨平台验收，标签指向生成不可变候选的 `main` 合并提交。

  7/7 通过。

  Texture Asset 编码与检查链路。

## 能力边界

- Manifest 只承载运行时选择所需元数据，不替代 KTX2、DDS、PNG、JPEG 或 glTF 容器。
- Granit 不读取文件、不访问网络、不运行压缩或转码，也不隐式生成缺失的 RGBA8 回退。
- 逐 mip 接口只负责把已验证数据加入空 Upload Batch；资源替换、缓存和加载调度由上游负责。
