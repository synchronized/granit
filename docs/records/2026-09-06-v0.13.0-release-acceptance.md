# 2026-09-06 Granit 0.13.0 发布验收

## 结论

S-28 的后端无关异步操作、Vulkan/WebGPU Timestamp、浏览器分阶段加载和跨后端一致性测试已经
完成。Windows、Linux、Emscripten、安装 Consumer、文档和 Release 预验证全部通过，0.13.0 达到
合并与正式发布条件。

- Windows VS2022 Debug 共享库完整构建通过，CTest 78/78 通过。
- Windows VS2022 Debug 静态库完整构建通过，CTest 68/68 通过。
- 安装 SDK 的导出与 component 选包检查通过，独立 C11/C++20 Consumer 7/7 通过。

  Resize、像素探针和关闭前资源归零。
- 文档检查通过，共检查 179 个 Markdown 文件。

## 已确认边界

- 异步操作第一阶段服务 GPU 结果读取，不接管线程池、文件系统、网络或 glTF 任务调度。
- 取消是请求；已经提交的 GPU 工作允许安全排空，调用方仍须销毁操作句柄。
- WebGPU Timestamp 取决于 Adapter/Device 的实际 `timestamp-query` 能力，不提供 CPU 时间降级值。
- 浏览器 Model Viewer 的分阶段调度保留在示例层，公共 API 只提供可复用的 GPU 异步契约。
