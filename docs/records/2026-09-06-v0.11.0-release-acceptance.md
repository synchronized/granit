# 2026-09-06 Granit 0.11.0 发布验收

## 结论

S-26 的 WebGPU 可移植传输、Mipmap、Renderer Timestamp 能力报告及正式浏览器 Model Viewer 已完成。
Windows、Linux、Emscripten 与文档发布前门禁均通过，0.11.0 达到合并和打标签条件。

## 本地验证

- Windows VS2022 Debug 完整构建通过，CTest 76/76 通过。
- Emscripten 5.0.6 Release 完整构建通过。
- Chrome WebGPU Fixture 通过多帧渲染、传输、Mipmap、质量切换、输入、Resize、错误资产诊断与资源
  归零检查。
- 正式 `granit_model_viewer_web` 通过远程 Flight Helmet 加载、材质纹理、交互和质量切换检查，未
  产生 WebGPU Validation Error。
- 文档检查通过，共检查 172 个 Markdown 文件。

## 远端验证

- [Documentation](https://github.com/synchronized/granit/actions/runs/33981037029)：通过。
- [Emscripten](https://github.com/synchronized/granit/actions/runs/33981042287)：通过。
- [Linux](https://github.com/synchronized/granit/actions/runs/33981048129)：GCC/Clang、共享/静态和
  Integration Runtime 全部通过。
- [Windows](https://github.com/synchronized/granit/actions/runs/33981054885)：Shader Toolchain、共享与
  静态安装 Consumer 全部通过。

## 已确认限制

- 浏览器 WebGPU 不模拟 Vulkan 的同步 Timestamp 结果读取；能力位为关闭且查询创建返回
  `GRANIT_ERROR_UNSUPPORTED`。后续若引入异步查询，应单独设计公共完成与读回契约。
- 正式浏览器 Model Viewer 默认从 Khronos 下载 Flight Helmet，离线部署需要自行托管模型及其外部
  资源，并配置允许访问的跨域响应头。
