# 2026-09-15 Granit 0.24.0 发布验收

## 结果

Granit 0.24.0 已从 `main@85f67281` 正式发布。标签 `v0.24.0` 指向该合并提交；发布工作流复用
同提交、同标签的不可变候选产物，并在公开 Release 创建后重新下载和校验全部文件。

## 验证

- [最终 Release Candidate](https://github.com/synchronized/granit/actions/runs/34946431712)：
  Windows/Linux 的 shared/static 四套 SDK、安装审计、测试、`SHA256SUMS` 和候选 manifest 通过。
- [标签发布与公开产物复验](https://github.com/synchronized/granit/actions/runs/34948115101)：候选提交与
  标签匹配，GitHub Release 创建成功；四套 SDK 的摘要与公开下载均通过检查。
- [Granit 0.24.0 Release](https://github.com/synchronized/granit/releases/tag/v0.24.0) 包含：
  `granit-0.24.0-linux-x64-shared.tar.gz`、`granit-0.24.0-linux-x64-static.tar.gz`、
  `granit-0.24.0-windows-x64-shared.zip`、`granit-0.24.0-windows-x64-static.zip` 和 `SHA256SUMS`。

本版本完成测试架构与 AssetTools 源码布局收敛、AssetTools 句柄类型安全，以及 Web ImGui 和
Shader Library 关闭诊断修复。详细跨平台结果见
[0.24.0 跨平台验收](2026-09-15-v0.24.0-cross-platform-acceptance.md)。
