# v0.68.0 发布验收记录

## 状态

v0.68.0 已完成源码、缓存、测试框架 target 隔离、跨平台构建和公开制品复核。

## 发布状态

v0.68.0 已正式发布：
[GitHub Release v0.68.0](https://github.com/synchronized/granit/releases/tag/v0.68.0)。

## 验收清单

- [x] Catch2、Unity 使用统一源码缓存、SHA-256 校验和 CMake 进程锁；
- [x] 缓存回归覆盖首次填充、复用、离线、损坏归档拒绝和并发填充；
- [x] 测试和示例统一使用 `granit_test_*` 私有 target，不依赖父项目同名 alias；
- [x] Windows Clang shared Release 构建通过；
- [x] Windows Clang static Release 构建通过；
- [x] 完全缓存、禁止网络的配置通过；
- [x] 静态构建 CTest 通过，发布版本文档入口已补齐；
- [x] 文档链接检查、依赖缓存回归检查通过；
- [x] Linux/Windows Release Actions 构建、测试、打包和 SHA-256 校验通过；
- [x] 公开 Release 制品重新下载校验通过。
