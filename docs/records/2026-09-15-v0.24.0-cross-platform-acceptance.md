# 2026-09-15 Granit 0.24.0 跨平台验收

## 结果

Granit 0.24.0 在提交 `c9b616b1` 上完成发布前跨平台验收。Quick Check、Windows、Linux、
Emscripten 与 Documentation 全部通过；Release Candidate 和正式发布仍待分支合并后执行。

## 验收期间修复

- AssetTools 测试迁移后，Pipeline、Material 与 Renderer 测试改从新的构建目录读取 Shader
  Fixture，避免本机旧产物掩盖路径错误。
- Windows、Linux 与 Shader Toolchain 工作流改用迁移后的 HLSL API 测试目标名。
- Web ImGui 浏览器验收将无错误日志的初始化超时纳入既有三次重试，保留最终失败语义。

## 本地验证

- 全新 Windows Clang 构建目录中的 Pipeline、Material 与 Renderer 三项 GPU 测试通过。
- Windows Clang 共享库 Debug 91/91、静态库 Debug 81/81 测试通过。
- 0.24.0 发布身份、文档以及安装包版本和 component 选择矩阵通过。

## 远端验证

- [Quick Check](https://github.com/synchronized/granit/actions/runs/34944392118)：日常单元测试与两个
  核心 Smoke 通过。
- [Windows](https://github.com/synchronized/granit/actions/runs/34944395301)：MSVC 共享/静态构建、
  安装审计、独立 Consumer 与锁定 Shader Toolchain 通过。
- [Linux](https://github.com/synchronized/granit/actions/runs/34944399701)：GCC/Clang、共享/静态、
  Runtime 集成、安装 Consumer 与锁定 Shader Toolchain 通过。
- [Emscripten](https://github.com/synchronized/granit/actions/runs/34944402823)：Web 构建、独立 Consumer、
  平台 Smoke、Model Viewer 与 ImGui 浏览器验收通过。
- [Documentation](https://github.com/synchronized/granit/actions/runs/34944410195)：文档结构和链接检查通过。

本记录不将 Release Candidate、合并、标签或公开 Release 标记为完成。
