# Granit v0.44.0 发布验收

## 结论

Granit v0.44.0 已完成本地验收、发布分支合并和正式 Release。版本范围为 S-81 独立纹理变体
上传；Gneiss 的驻留预算、变体选择和 CPU 负载生命周期仍不属于 Granit。

## 验证结果

- Windows Clang Debug 完整构建通过，CTest 105/105 通过。
- Linux 与 Windows shared SDK、校验和及安装 Consumer 发布检查通过。
- 正式 Release 发布脚本通过：校验、打包、发布和公开 Release 复验均成功。
- Release 资产包含 Linux x64 shared、Windows x64 shared 和 `SHA256SUMS`。
- v0.44.0 为非草稿、非预发布版本，标签与 Release 均可公开访问。
