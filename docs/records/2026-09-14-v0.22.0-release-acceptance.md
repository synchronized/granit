# 2026-09-14 Granit 0.22.0 发布验收

## 结果

Granit 0.22.0 已从 `main@c92884dc` 正式发布。标签 `v0.22.0` 指向该合并提交；发布工作流复用同
提交、同标签的不可变候选产物，并在公开 Release 创建后重新下载和校验全部文件。

## 验证

- [最终 Release Candidate](https://github.com/synchronized/granit/actions/runs/34769529680)：
  Windows/Linux 的 shared/static 四套 SDK、安装审计、测试、`SHA256SUMS` 和候选 manifest 通过。
- [标签发布与公开产物复验](https://github.com/synchronized/granit/actions/runs/34769709296)：候选提交与
  标签匹配，GitHub Release 创建成功；四套 SDK 的摘要、归档根目录和公开下载均通过检查。
- [Granit 0.22.0 Release](https://github.com/synchronized/granit/releases/tag/v0.22.0) 包含：
  `granit-0.22.0-linux-x64-shared.tar.gz`、`granit-0.22.0-linux-x64-static.tar.gz`、
  `granit-0.22.0-windows-x64-shared.zip`、`granit-0.22.0-windows-x64-static.zip` 和 `SHA256SUMS`。

本次发布不重新打包 DXC/Tint。Shader Toolchain 继续通过独立的锁定 Release 获取，AssetTools
安装包只携带版本身份、下载逻辑和校验规则。
