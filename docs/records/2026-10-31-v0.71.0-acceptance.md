# v0.71.0 发布验收记录

## 状态

v0.71.0 已完成首期公共 Render Graph 实现和本地 Windows 验证，当前进入最终候选收口，
尚未发布公开制品。

## 发布状态

当前尚未创建 tag 或 GitHub Release。远端 Windows、Linux 和 Emscripten 候选验证以及发布提交
合入 `main` 后，才允许触发 Release 工作流。

## 验收清单

- [x] RenderGraph 为独立 CMake component，仅依赖核心 Renderer；
- [x] C11 `types.h`/`graph.h` 与 C++20 `types.hpp`/`graph.hpp` 安装入口完成；
- [x] 外部资源导入、临时资源、Pass 访问声明和显式依赖可构建执行；
- [x] 未初始化读取、循环依赖、无效资源和执行阶段错误可定位；
- [x] 失败清理、重复执行、尺寸更新和提交后临时资源回收有回归测试；
- [x] 安装 SDK 外部 Consumer 构建并执行 Shadow → Scene → Tone Mapping；
- [x] Windows Clang 头文件、Render Graph、文档和 API 稳定性测试通过；
- [ ] 最终候选的 Windows/Linux/Emscripten CI 通过；
- [ ] 公开 Release 制品下载、校验和与 manifest 复核完成。

## 本地验证证据

- Render Graph 命名和头文件拆分提交：`dd5ce43a`、`20eeb37f`；
- Windows Clang 相关 CTest：`granit.contracts.api_stability`、
  `granit.documentation.links`、`granit.render_graph.compiler` 通过；
- 安装到临时前缀后的外部 Consumer 配置、编译通过。

## 已知限制

- 当前仅完成 Windows 本地验证，Linux/Emscripten 尚未在本地执行；
- Render Graph 仍为实验性 API，不承诺跨版本 ABI 稳定；
- 不自动合并 Vulkan Subpass，也不提供 input attachment 抽象。
