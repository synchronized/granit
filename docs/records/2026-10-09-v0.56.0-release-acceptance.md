# Granit v0.56.0 发布验收

## 范围

本版本完成 S-92：内部 Frame Trace、Vulkan Debug Label、可选 RenderDoc 动态桥接、WebGPU
调试标记与诊断协作，以及 Model Viewer 和 CI 失败路径的最小接入。公共 C ABI 不新增
RenderDoc、Vulkan、Dawn 或平台句柄依赖。

## 本地验证

- Windows Clang Debug 的 RenderDoc bridge CTest 通过；测试使用无 GPU 依赖的内部桥接测试程序和
  RenderDoc 动态替身，验证 `TriggerCapture` 标记、Frame Trace 基线和逐行 JSONL 校验；
- Emscripten `granit` 目标构建通过；
- PBR Trace 生成 182 条有效记录，Render Pipeline Trace 生成 75 条有效记录，均通过校验器；
- Model Viewer 桌面参数、相关 Renderer、生命周期、PBR 和 Pipeline 测试通过；
- `git diff --check`、C++ 格式检查和公共头 Vulkan/RenderDoc/Dawn/WGPU 泄漏审计通过。

## 发布验证

Linux、Windows、Emscripten、Quick Check、Documentation 和 Release 工作流以本记录对应的
`v0.56.0` 发布提交为准；工作流完成后在此补充公开运行链接、资产摘要和 Runtime Bundle
复验结果。

## 限制

本版本不把 RenderDoc 或浏览器调试工具作为 SDK/Runtime Bundle 依赖；Frame Trace 是 0.x
开发期 JSONL 格式，不承诺跨版本持久化兼容。真实浏览器 GPU 调试仍由浏览器工具完成，Granit
只提供跨后端结构化诊断数据。
