# 2026-08-26 S-09E 0.3.0 验收

## 结论

S-09 与 0.3.0 开发范围已完成验收。公共 C 导出没有删除或改名；兼容新增、Canvas 描述变化和错误
分类变化已进入 CHANGELOG 与 0.2→0.3 迁移指南。Windows/Linux 的共享与静态 Release 安装包、
测试、安装审计和校验和均由手动 Release 预验证成功生成。

本次验收不创建 `v0.3.0` 标签或公开 Release，也不宣布 1.0 级 ABI 稳定。

## ABI 与迁移审计

- Core 兼容新增 Buffer flush、Frame Context 和帧槽查询导出。
- RenderPipeline 兼容新增 Canvas 批量追加导出。
- 0.2.0 的公共 C 导出、CMake component 和目标名称均未删除或改名。
- `granit_canvas_draw_list_desc` 正式使用一个原保留字段作为 `frame_slot_count`；
  `granit_canvas_record_desc` 新增 `frame_slot` 并扩大当前 V1 尺寸，使用者必须重新编译。
- 空父资源、失效句柄和跨对象归属错误统一改为 `GRANIT_ERROR_INVALID_HANDLE`；程序应比较结果码，
  诊断文本只用于日志定位。
- 迁移步骤的权威入口为[从 0.2 迁移到 0.3](../guides/migrate-0.2-to-0.3.md)。

## 剩余边界

- 正式发布仍需在 PR 合并后根据发布决定创建并推送 `v0.3.0` 标签；该动作不属于本次预验证。
- `actions/checkout@v4` 出现 Node.js 20 弃用提示，但 GitHub 当前强制使用 Node.js 24 执行且任务成功；
  后续应单独升级 Action 主版本，不阻塞 0.3.0。
- 0.4.0 多后端与 WebGPU 工作由 S-10 独立规划，不进入 0.3.0 分支范围。
