# v0.60.0 Resource Table 验收记录

## 范围

本版本完成 Resource Table 的实验性绑定模型契约、Material 公共入口接线、Vulkan 原生绑定、
WebGPU Bind Group 回退、在途更新保护，以及 `12_resource_table_scene` 的 Suzanne/多纹理场景和
64 表压力入口。默认 Bind Group 路径保持不变。

后端分化的 Resource Table 数组 Shader 实际采样不属于本版本；对应工作已记录到 S-96 的后续项，
避免把旧显式绑定 Shader 误报为 Resource Table Shader。

## 验收结果

| 项目 | 结果 |
|---|---|
| Windows Clang 全量 CTest | 112/112 通过 |
| Material、Compute、Resource Table 回归 | 4/4 通过 |
| Tutorial 12 smoke | 通过，Suzanne 场景和压力入口可构建/运行 |
| Emscripten Tutorial 12 目标构建 | 通过，生成 `granit_tutorial_12_resource_table_scene.html` |
| 公共材质 Resource Table 接线 | 通过，native 表创建、实例槽位更新和绘制绑定已接通 |
| 不支持 Resource Table 后端 | 通过，回退到 Bind Group，不声明 bindless 能力 |
| 在途 Resource Table 更新保护 | 通过，未完成 GPU 序列时拒绝更新 |

## 未验证项与风险

- 当前主机没有 Linux/Lavapipe 运行环境，未提交该平台运行时证据；
- 当前主机未执行 Chrome WebGPU 浏览器运行时 E2E，只完成 Emscripten 目标构建；
- 真正的 PBR Resource Table 数组 Shader 采样需要下一版本扩展 Shader 资产格式和后端定义隔离。
