# 2026-09-06 Granit 0.14.0 发布验收

## 结论

S-29 的异步管线指标、有界资源流送、异步上传批次和 Model Viewer 异步上传已经完成。
Windows、Linux、Emscripten、安装 Consumer、文档和 Release 预验证全部通过，0.14.0 达到合并与
正式发布条件。

## 已确认边界

- Render Pipeline 的 GPU 指标在内部异步读取，不改变既有指标快照接口和非阻塞查询方式。
- 上传批次容量在复制暂存数据前实施背压；单次操作过大和批次容量不足使用不同结果码。
- 异步上传接受提交后允许立即复用批次；销毁公开操作句柄不会提前释放仍被 GPU 使用的资源。
- Model Viewer 的资源准备调度仍属于示例层，公共 API 只提供后端无关的异步上传契约。
- `async_operation_count` 只统计公开异步操作；内部管线指标操作不会污染使用者可见的资源统计。
