# 2026-09-13 Granit 0.21.0 发布验收

## 结论

Granit 0.21.0 已正式发布。Shader 运行时交付已收敛为确定性 `.grshlib`，Material 通过内容 ID
引用后端无关 Shader，离线作者入口统一为 HLSL-first。标签指向生成不可变候选的 `main` 合并提交。

## 兼容性与范围

- Core、RenderPipeline、Window、Input 与 ShaderTools 继续处于 0.x 未冻结状态；使用者应重新
  编译并把 CMake 请求版本更新为 0.21。
- 平台 Surface 创建统一为 `granit_surface_desc` 与 `granit_surface_create`，旧平台专用入口已删除。
- `.grshader`、SPIR-V/WGSL sidecar 和 Material shader resolver 已退出运行时交付；应用应加载
  `.grshlib`，Material 和直接 Shader 创建通过 Library 内容 ID 取得后端载荷。
- ShaderTools 作者入口只接受 HLSL；`.grshaderobj` 是工具私有缓存，不进入安装与发布资产。
- `.grmat` 升级到 v5，并显式记录绑定组契约。完整改动见
  [0.20 到 0.21 迁移指南](../guides/migrate-0.20-to-0.21.md)。
