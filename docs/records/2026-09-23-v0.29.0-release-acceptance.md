## 候选构建与测试

Release 工作流从发布提交重新构建并验证以下候选，不复用功能分支产物：

- Windows x64 shared；
- Windows x64 static；
- Linux x64 shared；
- Linux x64 static。

四组任务均完成配置、构建、CTest、安装、打包和 Actions 制品上传。发布前还验证了 manifest 中的
标签、提交和工作流编号，并用 `SHA256SUMS` 校验全部四个归档。

## 正式发布制品

- `granit-0.29.0-linux-x64-shared.tar.gz`
- `granit-0.29.0-linux-x64-static.tar.gz`
- `granit-0.29.0-windows-x64-shared.zip`
- `granit-0.29.0-windows-x64-static.zip`
- `SHA256SUMS`

正式 Release 创建后，独立的 `verify-public-release` 任务从公开发布页重新下载上述文件，验证四个
归档的 SHA-256 和单一顶层目录结构，全部通过。

## 已知限制

本次正式候选覆盖 Windows 与 Linux SDK。Emscripten 安装 Consumer 和 Chrome WebGPU 浏览器测试
已在功能 PR 的同一功能提交上通过；Web 产物仍按项目现有方式由源码构建，不作为本次 Release 的
预编译 SDK 附件。
