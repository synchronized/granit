# 2026-09-06 Granit 0.12.0 发布验收

## 结论

S-27 的公共 Shader Asset 检查、标准 PBR Schema/Material，以及三种 CMake 消费模式的统一资产目录
已经完成。Windows、Linux、Emscripten、安装 Consumer 与文档门禁均通过，0.12.0 达到合并和发布
条件。

## 本地验证

- Windows VS2022 Debug 共享库完整构建通过，CTest 77/77 通过。
- Windows VS2022 Debug 静态库完整构建通过，CTest 67/67 通过。
- 安装 SDK 的 component 选包检查通过，独立 C11/C++20 Consumer 7/7 通过。
- Emscripten 5.0.6 Release 完整构建通过，包含正式浏览器 Model Viewer。
- 公共 PBR 材质由权威 JSON 确定性生成，内容哈希及 Shader 引用测试通过。
- 文档检查通过，共检查 175 个 Markdown 文件。

## 远端验证

- [Documentation](https://github.com/synchronized/granit/actions/runs/34007715334)：通过。
- [Emscripten](https://github.com/synchronized/granit/actions/runs/34007716616)：通过。
- [Linux](https://github.com/synchronized/granit/actions/runs/34007706783)：GCC/Clang、共享/静态、安装

  Shader Toolchain 全部通过。

## 已确认边界

- Granit 公开 GPU 材质契约，不接管 Gneiss 的产品材质语义、资产身份、文件系统或热重载策略。
- Shader Asset 检查消费内存字节，不执行文件 I/O，也不持有调用方输入或输出内存。
- `granit_RENDER_PIPELINE_ASSET_DIR` 只定位公共资产；上游自行决定读取、嵌入、缓存和异步加载方式。
