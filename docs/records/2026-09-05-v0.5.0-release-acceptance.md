# 2026-09-05 Granit 0.5.0 发布验收

## 结论

Granit 0.5.0 已正式发布。标签指向已验收的 `main` 合并提交，Windows/Linux 共享与静态 SDK、
校验文件和公开 Release 均已验证。

## 发布身份

- 标签：`v0.5.0`
- 提交：`9a2184d94f602a37d26d8b5bcfc9d21b14deb47e`
- Release：<https://github.com/synchronized/granit/releases/tag/v0.5.0>
- Pull Request：<https://github.com/synchronized/granit/pull/39>
- 候选预验证：
  [Release #33903187997](https://github.com/synchronized/granit/actions/runs/33903187997)
- 正式工作流：
  [Release #33903696593](https://github.com/synchronized/granit/actions/runs/33903696593)

## 验收结果

- 合并前 Documentation、Windows、Linux 和 Emscripten 手动 Actions 全部通过。
- 候选预验证和标签触发的正式工作流均通过版本检查、Windows/Linux 共享与静态构建、测试、
  安装审计、校验文件生成；正式工作流成功创建 Release。
- 公开 Release 包含四个 SDK 压缩包和 `SHA256SUMS`，不是草稿或预发布版本。
- 从公开 Release 重新下载四个 SDK 后，全部 SHA-256 与 `SHA256SUMS` 一致。
- 四个压缩包均可读取，并且各自只有一个包含版本、平台和链接模式的顶层目录。
- 使用公开 Windows 共享与静态 SDK 分别构建并运行 C11、C++20、RenderPipeline、Window 和 Input
  Consumer；两种链接模式各 7 个测试，合计 14 个测试全部通过。

Linux SDK 的构建、测试和安装 Consumer 由正式 Release 工作流的隔离 Linux Runner 验证；本地
Windows 发布后复验未重复运行 Linux 二进制。
