## 首轮远端验收与兼容修正

候选 `87d1426b` 的 Quick Check、Windows、Emscripten 与 Documentation 通过；兼容矩阵
16 项中 14 项通过，包含 Linux ASan+UBSan 与独立 TSan。远端结果不替代本地 Arch 驱动下
八项泄漏失败的定位，也不代表真实 GPU 长测完成。

首轮失败及处理范围：

- Clang 18 使用了要求 Clang 19 以上的 MSVC 14.44 标准库；矩阵改为显式选择 14.38，
  所有 Windows 行固定工具集，并校验、归档实际工具集环境。
- MSVC 14.38 在 `std::optional<directional_shadow_pass_desc>` 的标准库实现中报告 C4324
  对齐填充警告；将 MSVC 自身的 include 目录标记为外部头，不更改自有代码的 `/W4 /WX`。
- Linux 常规 GCC 构建因 ImGui 内部头文件的转换警告失败；依赖包装将 ImGui 目录声明为
  `SYSTEM PUBLIC`，不修改第三方源码，自有代码继续启用转换警告与警告即错误。

上述修正仍需在同一个 PR 中重新执行远端验收，不将首次失败记为通过。
本地 MSVC 14.42 Release 完整构建通过，ImGui 与 Lighting 相关 8 项 CTest 全部通过；
CI 契约、Actions 静态检查及 447 份文档检查通过。本机未安装 MSVC 14.38，
目标边界组合及 Ubuntu GCC 13 的实际编译结果由下一轮远端验收确认。

## 验收发现与修复

- 最小 CPU 探针证实 generation 完整回绕后旧句柄与新句柄相等并重新可查找；
  资源表与共享表改为耗尽后退役槽位，两个真实完整 generation 空间回归在 Clang 18 下通过。
  GPU 长测同时保留最早销毁的 Buffer 身份，防止只检查上一代句柄遗漏历史复活。


- Shader 逻辑名称的十六进制缓存文件名会随名称长度翻倍，在静态构建目录触发 Windows 路径限制；
  改为固定 SHA-256 文件名，新增长名称构建和缓存命中回归。
- 静态 Tutorial 11/12 的全局 Application 资源晚于注册表析构；在 Renderer 关闭前主动释放
  Frame Context、Resource Table 和 Sampler。优化构建调试栈定位后，两个原有 Smoke 均通过。
- MSVC 严格警告发现 Bindless 测试局部变量遮蔽，重命名局部变量，保留警告级别。
- Unlit 精确像素测试的 0.5 输入落在 UNORM 舍入边界；改用目标码值除以 255，保留精确相等断言。
- Windows Clang 资源重编译时，当前工具链把 GNU 行标记交给 SDK rc.exe 而失败并阻塞输出；
  同一预处理文件由 llvm-rc 成功编译，最小 CMake DLL 资源构建通过。preset 显式选择 llvm-rc，
  完整项目的 RC 步骤与 Clang 22 共享库构建已通过，最终完整回归待执行。
- 普通 test preset 默认排除 `stress`；显式长测入口覆盖排除规则，防止启用后误跑长测。

### 软件驱动差异与 Sanitizer 缺口

系统 Mesa 26.2.4 的 Pipeline Cache 往返测试失败。独立 Vulkan 探针同样得到
查询 32 字节、导出返回 20 字节，而头部长度仍为 32；不依赖 Granit 即可复现。
[对应 Mesa 上游代码](https://chromium.googlesource.com/external/gitlab.freedesktop.org/mesa/mesa/+/ec071eb25d7fd923e836569277da6c5e81030444/src/gallium/frontends/lavapipe/lvp_pipeline_cache.c)
包含该返回长度逻辑，未放宽 Granit 的导入校验。

对照验收使用 Arch 官方归档的 Mesa 26.2.3 与 LLVM 22.1.8，均已校验软件包签名，
只解包到虚拟机的 `build/driver-probe/`。通过进程级 `VK_DRIVER_FILES` 与
`LD_LIBRARY_PATH` 选择，不降级系统软件、不修改第三方源码。对照驱动正确返回 32 字节，
上述 Linux 原生完整与安装验收均在该环境通过。26.2.4 的失败报告仍保留。

完整 ASan+UBSan 的八个失败均包含小块泄漏报告。独立 `vkcube --c 3` 在相同驱动、
预载 ASan Runtime 的环境也报告 112 字节、两次分配泄漏，证明存在外部环境复现路径，
尚不能据此排除 Granit 自身泄漏。诊断性地预载驻留驱动时，单项离屏 Smoke 和随后完整
95 项测试均通过；但这改变模块卸载与扫描可达性边界，不作为原配置通过证据。
未设置泄漏抑制规则，未关闭 ASan、UBSan 或 LeakSanitizer，也未过滤失败用例。
