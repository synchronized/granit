# Granit v0.57.0 发布验收

## 范围

本版本完成 S-93：Frame Trace schema 与顺序校验、跨后端诊断回归、统一 CI 失败附件以及
RenderDoc 可选路径验收边界。公共 C ABI 不新增诊断、RenderDoc、Vulkan、Dawn 或 Bindless
依赖。

## 本地与 Pull Request 验证

- Windows Clang Debug 的 Frame Trace validator 契约测试、PBR 和 Render Pipeline 回归通过；
- Emscripten release tutorial-06 构建通过，浏览器多帧、特性状态、Resize 和命令缓冲有效性验证通过；
- PR #135 的 native、文档、Linux/Windows shared/static consumer、Model Viewer、platform smoke、
  tutorial-01～07 全部通过；
- RenderDoc bridge 替身测试、Frame Trace schema 校验和 CI YAML 静态检查通过；
- `git diff --check`、公共头依赖边界和安装 Consumer 门禁通过。

## 发布验证

- [Release 工作流 37827397974](https://github.com/synchronized/granit/actions/runs/37827397974)
  在提交 `392f77ae` 上通过 validate、Windows/Linux SDK、Windows/Linux Runtime Bundle、checksums、
  publish 和 verify-public-release；
- [公开 Release v0.57.0](https://github.com/synchronized/granit/releases/tag/v0.57.0) 已发布，
  包含 Windows/Linux x64 SDK、Vulkan Runtime Bundle 和 `SHA256SUMS`；公开下载复验通过。
- 当前 Windows 主机的 Intel UHD 630 Vulkan 硬件补验通过：Model Viewer Suzanne smoke、Vulkan
  Validation、Frame Trace validator 和 RenderDoc CLI 均成功；生成的单帧捕获为
  `build/windows-clang-debug/diagnostics/intel-uhd630-capture_frame1.rdc`（约 6.6 MiB）。

## 边界与未完成项

- Frame Trace 继续是默认关闭的 0.x 内部 JSONL 格式，不承诺跨版本持久化兼容；
- RenderDoc 不随 Granit SDK 或 Runtime Bundle 发布，缺失时动态 no-op；
- 本记录首次发布时尚未连接 Windows Vulkan 硬件；后续已在 Intel UHD 630 上完成实际 RenderDoc
  一帧 capture，Linux 和 Emscripten 的平台差异仍按原计划分别验证；
- Bind Group 继续是默认资源绑定模型，Bindless、SVT 和纹理驻留不进入本版本。
