# 2026-09-10 Granit 0.20.0 发布验收

## 结论

Granit 0.20.0 已正式发布。示例框架、Model Viewer 交互、生成式 Shader 资产和统一 Frame
信息查询已经完成跨平台验收，标签指向生成不可变候选的 `main` 合并提交。

## 验证结果

- Windows Clang Debug 共享库 83/83、静态库 72/72 测试通过；安装导出及 C11/C++20 Consumer
  通过。
- [Quick Check](https://github.com/synchronized/granit/actions/runs/34410022959)、
  [Windows](https://github.com/synchronized/granit/actions/runs/34410024949)、
  [Linux](https://github.com/synchronized/granit/actions/runs/34410026736)、
  [Emscripten](https://github.com/synchronized/granit/actions/runs/34410028477)和
  [Documentation](https://github.com/synchronized/granit/actions/runs/34410030399)均在发布提交上通过；
  详细边界见
  [S-36 跨平台验收](2026-09-10-s36-cross-platform-acceptance.md)。
- [Release Candidate](https://github.com/synchronized/granit/actions/runs/34410478501) 在提交
  `ccb2bd32118292732c0477b41a1389fa3a846245` 上通过四套 SDK 构建、测试、安装审计、打包、
  manifest 和 SHA-256 清单校验。
- [v0.20.0 正式发布](https://github.com/synchronized/granit/releases/tag/v0.20.0)复用同提交候选，
  [发布流水线](https://github.com/synchronized/granit/actions/runs/34411051421)已从公开 Release
  重新下载并校验；Windows/Linux 共享及静态 SDK 均已公开。

## 兼容性与范围

- Core、RenderPipeline、Window 和 Input 继续处于 0.x 未冻结状态；IntegrationSDL3、
  IntegrationImGui 与 ShaderTools 仍为实验性 component。
- Frame C API 改为 `granit_frame_get_info(renderer, frame, info)`，并删除临时导出
  `granit_frame_get_slot_info`；0.19 Consumer 必须按[迁移指南](../guides/migrate-0.19-to-0.20.md)
  修改并重新编译。
- 示例框架、glTF 加载器、线程执行器和浏览器壳层均为仓库私有实现，不进入安装 SDK。
