# 2026-09-10 Granit 0.20.0 发布验收

## 结论

Granit 0.20.0 功能与平台矩阵已经通过，正式发布等待不可变 Release Candidate 晋级。示例框架、
Model Viewer 交互、生成式 Shader 资产和统一 Frame 信息查询已经完成验收。

## 验证结果

- Windows Clang Debug 共享库 83/83、静态库 72/72 测试通过；安装导出及 C11/C++20 Consumer
  通过。
- [Windows](https://github.com/synchronized/granit/actions/runs/34376406135)、
  [Linux](https://github.com/synchronized/granit/actions/runs/34376886643)、
  [Emscripten](https://github.com/synchronized/granit/actions/runs/34409267972)、
  [Quick Check](https://github.com/synchronized/granit/actions/runs/34376400312)和
  [Documentation](https://github.com/synchronized/granit/actions/runs/34376420390)均通过；详细边界见
  [S-36 跨平台验收](2026-09-10-s36-cross-platform-acceptance.md)。

## 兼容性与范围

- Core、RenderPipeline、Window 和 Input 继续处于 0.x 未冻结状态；IntegrationSDL3、
  IntegrationImGui 与 ShaderTools 仍为实验性 component。
- Frame C API 改为 `granit_frame_get_info(renderer, frame, info)`，并删除临时导出
  `granit_frame_get_slot_info`；0.19 Consumer 必须按[迁移指南](../guides/migrate-0.19-to-0.20.md)
  修改并重新编译。
- 示例框架、glTF 加载器、线程执行器和浏览器壳层均为仓库私有实现，不进入安装 SDK。
- 正式标签将在同一 `main` 提交的 Release Candidate 完成四套 SDK、安装审计、manifest 和
  SHA-256 校验后创建。
