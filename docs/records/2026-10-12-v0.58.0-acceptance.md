# Granit v0.58.0 发布验收

## 范围

本版本完成 S-94：WebGPU Pass 生命周期回归、Timestamp“不支持”契约、Vulkan Validation/诊断
边界和 RenderDoc CLI/no-op 验收。不新增公共 ABI、RenderDoc、Vulkan、Dawn、Bindless、SVT 或
纹理驻留能力。

## 验证结果

- Windows Clang Debug 全量 CTest：112/112 通过；包含 Renderer、Vulkan、Model Viewer、教程、
  安装 Consumer、Runtime Bundle、ABI、文档和发布门禁；
- 当前 Intel UHD 630 Vulkan 主机开启 Khronos Validation，backend、renderer、Model Viewer 和
  RenderDoc bridge 测试通过，未出现新增 VUID；
- Chrome 155 WebGPU platform smoke 通过：多帧、MRT、Storage Texture、Readback、输入、资源
  释放、异步 Pipeline、取消回滚和缺失 Buffer 诊断；
- tutorial-06 Marching Cubes 浏览器测试通过：多帧、能力状态和 Resize；
- WebGPU Timestamp 按设计返回 `GRANIT_ERROR_UNSUPPORTED`，不伪装成已实现能力；
- WebGPU Render Pass 未显式结束时直接销毁 recorder 的回归通过；销毁路径现在先 End 再 Release；
- RenderDoc CLI 生成 Windows Intel Vulkan `.rdc`，RenderDoc 路径缺失时 Model Viewer 仍以退出码
  0 完成，Frame Trace validator 通过；
- `git diff --check` 和 Documentation links 通过。

## 未纳入范围

- WebGPU Timestamp 不实现；Vulkan Timestamp 保持现有支持；
- Emscripten/WebGPU 不生成 RenderDoc `.rdc`；
- RenderDoc `.rdc` 仅为本地诊断产物，不进入 SDK、Runtime Bundle 或仓库；
- Compute Pass 没有公共“未结束后销毁”录制入口，正常路径由 tutorial-06 覆盖，内部销毁逻辑与
  Render Pass 保持对称。
