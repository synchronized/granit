# 路线图

路线图表达当前方向，不构成版本承诺。

## 阶段一：工程与 ABI 基础

- 建立 C ABI、C++20 包装和导出规则。
- 完善结果码和诊断信息，设计分配器及日志回调。
- 扩展已实现的 64 位资源句柄表，并随 renderer 生命周期确定最终同步策略。
- 持续验证动态库、静态库、安装包和 C/C++ consumer。

## 阶段二：Vulkan 后端基础

- 扩展已实现的 renderer 公共生命周期，加入设备信息查询和日志回调。
- 扩展物理设备选择策略，支持公共设备偏好配置。
- 建立能力查询、设备选择和队列管理。
- 接入调试消息和错误映射。
- 完成 buffer、texture、sampler 和 shader 资源生命周期。

## 阶段三：渲染提交

- 设计命令记录与批量提交接口。
- 实现 pipeline、资源绑定、同步和状态转换。
- 接入平台 surface 与 swapchain。
- 提供最小三角形和离屏渲染示例。

## 阶段四：可用性与稳定性

- 完善多线程、资源上传和帧生命周期。
- 建立 ABI 兼容测试、性能基准和后端验证层测试。
- 明确公共 API/ABI 版本策略。
- 评估独立的高级 Vulkan 互操作接口。
