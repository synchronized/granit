# 任务编号：S-111：0.69 后续硬件与驱动验收

## 状态与依赖

**待环境，P1。** 承接 [S-110](S-110-0.69.0-local-soak-tests.md) 的未覆盖环境，
不阻塞调整范围后的 v0.69.0 开发收口，也不计为已通过的验证。

## 实施步骤

1. 获得 Linux 原生真实 Vulkan GPU 或具备真实设备直通的环境；确认设备类型和驱动身份，
   VMware 软件 Vulkan 不能替代。记录源码提交、工具链、ICD、验证层与窗口后端。
2. 使用现有 `dev.sh` 的显式 stress 入口，各执行资源生命周期、窗口重建和持续渲染一小时。
   使用固定种子，保持验证层与失败退出码，归档 JUnit、环境、日志和二进制摘要。
3. 在 Windows 真实 GPU 上补充窗口重建和持续渲染各一小时；八小时与多厂商是扩展项，
   不由已有短测或资源长测推定通过。
4. 对 Arch 软件驱动的 LeakSanitizer 外部分配诊断保留原失败证据，使用后续驱动版本正常
   加载、卸载复验。未解决前不声称该环境完整 Sanitizer 通过，不关闭检查或添加抑制规则。

## 验收门槛

- [ ] Linux 真实 GPU 三类一小时长测均通过，记录设备、驱动和窗口后端。
- [ ] Windows 窗口重建与持续渲染一小时通过。
- [ ] Arch 驱动更新后的原配置泄漏复验与原失败对照已记录。
- [ ] 证据进入验收记录，更新未覆盖范围；无设备、跳过和失败均不记为通过。

命令与参数以 [CI 指南](../guides/ci.md)为准；前序环境与原始结果见
[v0.69.0 验收记录](../records/2026-10-24-v0.69.0-validation.md)。
