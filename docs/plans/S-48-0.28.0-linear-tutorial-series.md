# S-48：0.28.0 线性入门教程与配套示例

## 状态

**实施中，P1。** 0.28.0 聚焦从空项目到完整可交互渲染程序的连续学习路径，不新增与教程无关的
公共能力。

## 背景与目标

现有教程按 Renderer、资源、Pipeline、窗口和 Model Viewer 主题排列，章节之间虽然互相引用，但
读者不能从第一章持续扩展同一个程序并在每一步得到可见结果。部分教程还以内部测试代替使用者示例，
模糊了 Tutorial、Example 和 Test 的职责。

本版本建立一条以窗口应用为起点的 C++20 教程系列。每章只引入一个主要概念，以上一章为前置，
并对应一份可编译、可运行、可验证的完整源码快照：

```text
Window → Triangle → Texture → Depth/Camera → Mesh
       → Material/Lighting → Render Pipeline → ImGui
```

## 非目标

- 不同时维护旧教程和新教程两套学习路径。
- 不把单元测试、错误路径或平台探测程序包装成示例。
- 不复制 Model Viewer 的完整实现到教程源码。
- 不为教程暴露 Vulkan、WebGPU、Win32、XCB 或 Wayland 原生类型。
- 不在 0.28.0 承诺 C11 与 C++20 双轨教程；教程使用 C++20 包装。
- 不为了教程方便创建与现有公共抽象重叠的第二套运行时接口。

Tutorial 解释目标、增量、关键代码、结果和排错；`examples/tutorials` 保存每章结束时的完整源码。
`examples/samples` 继续保存 ImGui 和 Model Viewer 等综合应用。相邻章节允许少量教学性重复，跨章节
稳定且非教学重点的窗口启动、文件读取和错误报告逻辑进入 `examples/tutorials/common`。

### 教程顺序

1. **Window**：安装包接入、Renderer、Window System、Window、Surface、Swapchain、清屏和退出。
2. **Triangle**：HLSL-first Shader Library、Graphics Pipeline 与第一个 Draw。
3. **Texture**：Texture、View、Sampler、上传、Bind Group 和纹理采样。
4. **Depth and Camera**：Vertex/Index Buffer、深度附件、Uniform、变换和相机。
5. **Mesh**：把几何资源收敛为 Mesh，并加载一个仓库内可再分发的最小模型。
6. **Material and Lighting**：`.grmat`、材质参数、方向光和基础 PBR。
7. **Render Pipeline**：Scene Snapshot、Draw Binding、Shadow、HDR 与 Tone Mapping。
8. **ImGui**：输入事件、Canvas、Texture ID、Resize 和调试面板。

### 平台与 Shader

- 教程只使用 `granit::window` 创建窗口和 Surface，不暴露原生平台 API。
- Shader 源统一使用 HLSL，由 AssetTools 在构建期生成跨后端 Shader Library。
- 01～07 首先保证 Windows/Linux Vulkan；08 复用相同内容验证 Emscripten WebGPU。
- 平台差异只留在构建和事件循环壳层，不复制渲染业务逻辑。

## 测试与验收

- 八章按顺序阅读时不要求读者预先理解后续章节概念。
- 每章包含目标、相对上一章的增量、关键代码、完整源码入口、运行命令、预期结果、排错和下一章。
- 每个 `examples/tutorials/<step>` 目标能独立构建，源码不包含 Granit 私有头或后端原生类型。
- 每章至少有一个自动验证：进程退出、中心像素、固定区域颜色、资源状态或浏览器帧推进。
- Windows/Linux 覆盖桌面教程；最终 ImGui 内容同时覆盖 Vulkan 与浏览器 WebGPU。
- 文档链接检查禁止重新引用已删除的旧教程文件。
- 运行 Documentation、相关 Example Smoke、Windows/Linux 完整矩阵和 Emscripten 浏览器验证。

## 风险与未决问题

- 当前 Triangle 示例尚未进入顶层构建，需要先确认其资产生成与跨平台构建状态。
- 逐章完整快照会产生少量代码重复；只有遮蔽教学目标的稳定代码才抽入 `common`。
- 教程所需 Bind Group、顶点布局或动态 Uniform 若暴露公共 API 缺口，应先记录并评审最小补充，
  不能在示例中绕过公共边界。
- Model Viewer 原教程包含仍有价值的运行说明，删除前应迁移到独立 Guide，而不是丢失内容。
