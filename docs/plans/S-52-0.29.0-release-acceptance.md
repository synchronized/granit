# S-52：0.29.0 版本收口与发布验收

- 目标版本：0.29.0
- 实现状态：实施中
- 优先级：P1

## 目标

0.29.0 收口线性教程、Model Viewer 迁移和 Shader Library 逻辑名称三项工作。本阶段不再增加
公共能力，只补齐迁移说明、版本一致性、跨平台验证和候选包证据，随后进入 release 分支。

## 范围

- 确认 S-50、S-51 的公共 C API、C++ 包装、工具参数、资产格式和文档一致。
- 为 Shader Library schema 2、删除 Shader 索引及相关 API 提供 0.28→0.29 迁移指南。
- 固化 0.29.0 Core、RenderPipeline 与 AssetTools 导出符号快照。
- 验证 Windows shared/static、Linux shared/static、Emscripten、浏览器 WebGPU 和安装 Consumer。
- 在功能分支通过验收后合并到 `main`；版本号只在 `release/0.29.0` 分支通过发布脚本修改。

## 非目标

- 不把示例私有 glTF Loader、GPU Scene 或 Model Viewer 状态机加入安装 SDK。
- 不增加新的渲染特性、资产类型或平台后端。
- 不在功能分支提前创建标签、Release 或修改已发布版本记录。

## 功能完成条件

- [x] 教程 01～10 形成连续路径，Model Viewer 只保留 Tutorial 10 入口。
- [x] Shader Library 支持逻辑名称，Material Builder 直接读取 `.grshlib`。
- [x] 公共 C API、C++ 包装、所有权和生命周期说明已同步。
- [x] 破坏性变化已写入 Changelog 和 0.28→0.29 迁移指南。

## 验证矩阵

- [x] Windows MSVC shared/static 完整矩阵。
- [x] Linux Clang/GCC shared/static。
- [x] C11/C++20 公共头、0.29.0 ABI 快照和 Build Tree Consumer。

- [x] Chrome WebGPU 平台、Tutorial 08 与 Model Viewer 验收。

## 发布条件

- [ ] 功能分支通过所需 Actions 并合并到 `main`。
- [ ] `release/0.29.0` 从最新 `main` 创建，发布脚本只修改版本文件、README 与 Changelog。
- [ ] 版本提交经 Pull Request 合并，`main` 与 `origin/main` 完全一致。
- [ ] Release 工作流基于该提交构建并验证候选，然后创建 `v0.29.0` 与正式 Release。
- [ ] 发布验收记录列出全部验证结果、未覆盖项和已知限制。
