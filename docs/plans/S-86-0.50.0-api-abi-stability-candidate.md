# S-86：0.50.0 公共 API/ABI 稳定候选审计

## 状态

**规划中。** v0.49.0 已完成回读契约和跨平台发布验收。当前没有新的 Gneiss 上游缺口，下一步
先审计 Granit 已公开的 C ABI、C++ 包装和 component 边界，再决定哪些接口可以进入稳定候选。

## 目标

1. 为 Core、Renderer、RenderPipeline、Window、AssetTools 建立按 component 的稳定等级；
2. 审计结构体布局、枚举、结果码、句柄生命周期、符号导出和 C++ move/RAII 语义；
3. 通过安装 SDK 的 C11/C++20 Consumer、共享/静态构建和负向测试验证长期契约；
4. 明确 ABI 尚未冻结的接口，避免在稳定之前引入隐式兼容负担。

## 固定边界

- 本版本不冻结整个 Granit ABI，只形成稳定候选清单和退出条件；
- 不新增 Vulkan 原生公共接口，不把 Vulkan SDK 头文件带入公共头；
- 不实现 Bindless、Clustered Forward、Cascaded Shadow Maps 或 Android；
- 不把 Gneiss 的 SVT、纹理驻留、预算和任务调度下沉到 Granit；
- 新功能只有在稳定性审计证明现有抽象无法表达时才建立独立计划。

## 实施顺序

1. **S-86A 公共面清单**：按 component 记录头文件、符号、结构体、结果码、句柄和依赖边界，
   标记 stable-candidate、experimental、internal。
2. **S-86B ABI/生命周期门禁**：扩展 C11/C++20 Consumer、布局/符号快照、错误路径、generation、
   跨 Renderer、重复销毁和 Renderer 级联清理测试。
3. **S-86C 兼容策略**：补充版本策略、破坏性变更规则、结构体扩展方式、C++ 包装迁移和安装包
   复现文档；不为 0.x 旧布局保留平行运行时路径。
4. **S-86D 能力缺口复评**：以现有 Tutorial、Gneiss 接入和 Consumer 证据评估 Bindless、
   Clustered Forward、CSM、公共 glTF/Scene SDK 是否满足恢复条件。
5. **S-86E 发布验收**：完成 Linux/Windows/Emscripten、shared/static、C/C++ Consumer 和公开
   制品复验后发布 v0.50.0。

## 验收门槛

- 每个公开 component 都有明确稳定等级、所有权、线程安全、错误和生命周期契约；
- C ABI 布局、导出符号和 C++ wrapper 行为具备自动化回归；
- 安装 SDK 不依赖源码树、Vulkan 公共头或开发机全局路径；
- 暂缓的大型功能都有基于真实负载的恢复条件，而不是凭感觉扩展 ABI；
- Granit 与 Gneiss 的职责边界保持不变。
