# 任务编号：S-112：0.70.0 Window 原生句柄与 Surface 解耦

## 状态

**已完成，待版本发布。**

## 背景与目标

Window 组件此前直接依赖 Renderer，并提供 Window 到 Surface 的创建入口，导致平台窗口管理、渲染器
生命周期和 SDL3 特殊处理耦合在一起。本任务将 Window 收敛为窗口、事件和原生句柄快照管理，Surface
由调用方使用 Renderer 创建。

## 非目标

- 不向公共 API 暴露 Vulkan 类型；
- 不改变 Renderer、Surface 或 Swapchain 的所有权语义；
- 不为 Window 增加跨线程调用模型；
- 不冻结 0.x 的公共 ABI。

## 已确认决策

- 删除 `granit_window_create_surface`、`window::create_surface` 和 Window presentation 头文件；
- 通过 `granit_window_get_native` 返回带后端标签的原生窗口快照；
- SDL3 返回借用的 `SDL_Window*`，Surface 创建由 SDL3 集成层完成；
- 示例、测试和安装 Consumer 在上层完成 native handle 到 Surface 的转换。

## 实施顺序

1. 扩展 Window native C/C++ API，补充 SDL3 原生窗口快照；
2. 移除 Window 对 Renderer 的链接和 Surface 创建实现；
3. 迁移公共示例、Model Viewer、Smoke、Window 测试和安装 Consumer；
4. 更新 ABI 快照、迁移指南、参考文档和版本记录。

## 测试与验收

- [x] Windows Clang 相关示例、Window 平台与 Renderer 测试通过；
- [x] Window ABI 导出快照通过；
- [x] Emscripten Window ABI 契约构建通过；
- [x] 文档链接检查和安装打包 Consumer 通过；
- [ ] Windows/Linux/Emscripten 发布候选 CI 在最终 main 提交上通过。

## 风险与未决问题

这是 0.x 阶段的公共 API/ABI 破坏性变更，必须通过迁移指南说明。SDL3 原生窗口指针为借用值，不能
脱离 Window 生命周期保存或跨线程使用。
