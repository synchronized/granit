# S-104：0.66.1 Linux Runtime 缓存恢复修复

## 状态

**已完成，2026-10-19。** 修复 Release workflow 在 Linux 容器中精确缓存键恢复不稳定的问题，
并通过 v0.66.1 首轮构建和重复运行验证。

## 背景与目标

v0.66.0 首次 Release 能保存 Linux Runtime 缓存，但后续运行出现“缓存未找到、收尾保存时键已被占用”
的服务端竞态。Windows 路径已稳定命中。本任务只调整 CI 缓存恢复判断，不改变 Runtime 内容、公共 API
或 ABI。

## 实施内容

- Windows/Linux Runtime 缓存增加同一平台和同一组三个 Khronos 提交的恢复前缀；
- 构建步骤改为检查目标归档是否已恢复，而不只依赖 `cache-hit` 精确键输出；
- 保留完整源码构建、Runtime manifest、SHA-256 和公开下载校验作为未命中回退；
- v0.66.1 首轮完整构建后，重复运行确认两端均跳过 Runtime 源码构建。

## 验收

- Release workflow 首轮构建通过；
- 重复 Release 的 Windows/Linux Runtime 均命中归档并跳过构建；
- 公开 Release 产物、SHA-256 和内容清单复核通过；
- 文档链接检查通过。
