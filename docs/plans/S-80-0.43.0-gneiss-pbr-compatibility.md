# S-80：0.43.0 Gneiss PBR 兼容性审计

## 状态

- 文档状态：已确认
- 实施状态：修复中
- 目标版本：v0.43.0
- 需求来源：Gneiss `feat/0.43-pbr-pipeline` 的 `UPSTREAM-043`

## 背景与目标

Gneiss 的上游需求文件已确认，Granit v0.42.0 已包含透明 PBR、镂空与双面、逐贴图 UV/采样器、
负缩放切线手性和顶点色五项基础能力。v0.43.0 不重复实现这些功能，而是核对 Granit 的公开契约、
测试证据和 Gneiss 接入结果，避免把上游已经完成的能力误列为新的 Granit 缺口。

## 非目标

- 不修改 Gneiss 的资产格式、RID、导入器、缓存、调度器或场景系统；
- 不重新实现 v0.41.0 已完成的五项标准 PBR 能力；
- 不新增折射、透射、体积材质、透明阴影、OIT 或 `KHR_texture_transform`；
- 不为单一上游需求新增重复的公共 API 或第二套材质状态。

## 当前审计结论

| Gneiss 需求 | Granit 结论 | 主要证据 |
| --- | --- | --- |
| U43-01 透明 PBR | 已支持基础对象级透明阶段 | [S-76 计划](S-76-0.41.0-pbr-material-correctness.md)、[Render Pipeline 参考](../reference/render-pipeline.md) |
| U43-02 镂空与双面 | 已支持 OPAQUE/MASK、cutoff 与双面语义 | [Material 参考](../reference/material.md)、[S-76 验收记录](../records/2026-09-29-s76-pbr-material-correctness-acceptance.md) |
| U43-03 逐贴图 UV/采样器 | 已支持五槽 UV0/UV1 与独立 Sampler | [S-76 计划](S-76-0.41.0-pbr-material-correctness.md)、PBR API 测试 |
| U43-04 负缩放切线手性 | 已支持实例级反射符号与正面判定 | [S-76 计划](S-76-0.41.0-pbr-material-correctness.md)、GPU 回归证据 |
| U43-05 顶点色 | 已支持可选 `COLOR_0`，缺失时使用白色 | [Material 参考](../reference/material.md)、[S-76 验收记录](../records/2026-09-29-s76-pbr-material-correctness-acceptance.md) |
| U43-06 MASK 阴影常量可见性 | 已修复；MaterialConstants 对顶点/片元阶段一致可见 | `shadow_depth.hlsl` MASK 变体、Vulkan VUID-07988 复现 |
| U43-07 Demote 设备特性契约 | 已修复；查询并启用 `shaderDemoteToHelperInvocation`，不支持设备不可选 | Vulkan VUID-08740 复现、物理设备选择测试 |

这些能力仍有明确边界：透明只做对象级远近排序，不解决相交 Mesh 内部排序；不包含透明阴影、OIT、
折射或 `KHR_texture_transform`。这些边界不是本版本的遗漏，除非 Gneiss 提供新的通用需求和独立验收证据，
否则不应扩大 Granit 范围。

## 实施顺序

1. 以 Gneiss `UPSTREAM-043` 逐项核对 Granit 当前 Reference、Schema、CPU 测试和 GPU 证据；
2. 将真实失败按“Granit 公共契约缺口 / Gneiss 接入问题 / 测试环境问题”分类；
3. 只有确认属于 Granit 的通用缺口时，才创建最小代码修复和对应回归测试；
4. 修复 U43-06/U43-07，并在校验层和 GPU 回归中验证 MASK + UV1/顶点色路径；
5. 完成 Windows、Linux、Emscripten 和安装 SDK 相关验证后，再决定是否发布 v0.43.0。

## Granit 与 Gneiss 的责任边界

Granit 负责公共 GPU 材质契约、渲染阶段、资源生命周期和跨后端行为。Gneiss 负责 glTF 导入、材质
序列化、依赖与缓存、纹理解码、场景身份和上层调度。Gneiss 的完整 4K 驻留预算、Linux 专项崩溃和
资产导入诊断不能直接转化为 Granit 的公共 API 需求。

## 验收

- Granit 五项 PBR 契约的现有 CPU/GPU 测试继续通过；
- MASK + UV1/顶点色阴影创建、绘制和回收无 Vulkan validation error；
- Vulkan 设备只在已查询并启用 Demote 特性时接受包含该指令的标准 Shader；
- Linux Lavapipe 不再因 U43-06/U43-07 触发崩溃或校验错误；
- Reference、Plan、Changelog 和版本状态不再把已发布能力写成“暂缓”或“待实现”；
- 不新增 Granit 对 Gneiss 私有类型或仓库路径的依赖；
- 若无 Granit 侧缺口，形成审计记录并以维护性版本收口。

## 风险与未决问题

- Gneiss 的 Linux 像素测试崩溃和完整 4K 内存预算属于 Gneiss 当前验收问题，需由 Gneiss 单独诊断；
- 若 Gneiss 需要透明阴影、OIT 或纹理变换，必须另立 Granit 计划，不得隐含加入本版本；
- H-09B 是历史评估草案，已由 S-76 承接基础透明 PBR；当前行为以 Render Pipeline 参考为准。
