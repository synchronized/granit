# S-120：对象 ID Pipeline 生命周期修复

## 状态

**已完成，目标版本为 `v0.74.1`。**

## 背景与目标

Gneiss 使用 v0.74.0 对象 ID 输出后，RenderPipeline 销毁路径遗漏释放缓存的 object-ID graphics
pipeline，导致 Renderer 关闭前仍有 GPU 资源存活。本补丁只修复该通用生命周期缺陷，不改变对象 ID
输出、回读格式或命中规则。

## 实施与验收

- RenderPipeline 销毁时释放并清空 object-ID graphics pipeline 缓存；
- 同步释放 object-ID shader 包装；
- 增加资源统计回归，确认销毁后 graphics pipeline 数量下降；
- Windows Clang Debug `granit.pipeline.api` 通过。

## 非目标

不改变 Gneiss 接入逻辑、拾取请求协议、R32_UINT 格式、透明物体规则或异步回读接口。
