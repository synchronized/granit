# S-76：0.41.0 标准 PBR 材质正确性

## 状态

- 文档状态：已确认
- 实现状态：实施中
- 目标版本：v0.41.0
- 外部证据：Gneiss 的负缩放 GPU 像素复现和 Sponza 导入缺口

## 背景与目标

现有标准 PBR 路径只覆盖单 UV、共享 Sampler、单面不透明材质。法线贴图切线空间也只保留
`tangent.w` 的 UV 手性，没有合入实例变换的反射符号。真实 glTF 场景因此无法完整表达透明、
镂空、双面、逐贴图采样、顶点色和负缩放实例。

本任务把这些输入收敛到同一套标准 PBR 材质契约，并保持 Vulkan 与 WebGPU 行为一致。上层引擎
只提交材质和场景语义，不复制 Granit 私有 Shader 布局或按后端修正数据。

## 非目标

- 不实现折射、透射、体积吸收、透明阴影、OIT 或逐三角形透明排序。
- 不实现 `KHR_texture_transform`；本版本只处理 glTF 核心的 UV 集选择和 Sampler 状态。
- 不为旧 PBR 模板、资产 Schema 或公共结构保留 0.x 兼容分支。
- 不把 Gneiss 的 RID、序列化格式或场景类型引入 Granit。

## 已确认决策

### 负缩放和切线空间

- 标准 PBR 将网格切线的 UV 手性与 `model` 线性部分的行列式符号逐实例相乘。
- 插值后的切线相对几何法线重新正交化，再通过交叉乘积重建副切线。
- 同一 Mesh 可由正缩放和负缩放实例共享，不修改 Mesh 中持久化的 `tangent.w`。
- 奇异模型变换不进入标准 PBR 绘制；场景提交返回明确参数错误。
- 反射变换造成的绕序翻转由 Granit 选择对应正面 Pipeline 变体，调用方不反转共享索引。

### Alpha 与双面

- 标准材质显式声明 `opaque`、`mask` 或 `blend`，不根据运行时 Alpha 值自动切换队列。
- `mask` 保持深度写入，基础色因子、纹理和顶点色的 Alpha 组合后只执行一次阈值测试。
- 双面材质关闭剔除，并使用面朝向修正背面法线及其切线基。
- 阴影 Pass 对 `mask` 使用相同遮罩；首版 `blend` 不投射透明阴影。

### 逐贴图输入和顶点色

- 五个标准纹理槽分别选择 UV0 或 UV1，并分别绑定 Sampler；默认值保持 UV0 和共享默认
  Sampler 的简洁路径。
- 使用 UV1 的材质要求 Mesh 提供对应属性，缺失时返回明确布局错误。
- 可选 `COLOR_0` 为线性 RGBA，与基础色因子和基础色纹理相乘；缺失时等价于白色。
- Shader 与 Material 变体由公开 feature 组合确定，上层不依赖生成后的私有 variant key。

### 透明阶段

- 透明 PBR 位于不透明 PBR 之后、Tone Mapping 之前，写入同一线性 HDR 目标。
- 深度测试开启、深度写入关闭，输出预乘 Alpha，并使用预乘 Alpha 混合。
- RenderPipeline 按 View 对透明对象稳定地从远到近排序；相同深度依次使用显式排序键、对象 ID
  和提交序号。
- 排序后的相邻兼容 Draw 可以合批，但不得为了合批改变合成顺序。
- 相交对象和单个 Mesh 内部的排序限制写入正式参考文档。

## 实施顺序

1. 修复负缩放 TBN 手性、切线正交化、奇异变换和反射实例的正面判定，建立 CPU 与 GPU 回归。
2. 扩展标准材质 Alpha 模式、Cutoff、双面 Pipeline 与阴影遮罩契约。
3. 扩展逐纹理 UV/Sampler Schema、布局验证、资产构建和默认资源路径。**已完成。** 五槽分别
   绑定 Sampler，`uv1_mask` 保存精确选择，顶点变体只区分是否包含 UV1；glTF 导入与 Model Viewer
   GPU Scene 已接通 UV1 和异构 Sampler。
4. 增加可选顶点色输入，并覆盖无顶点色的默认变体。
5. 实现透明对象分类、逐 View 稳定排序、HDR 透明 Pass、指标和生命周期处理。
6. 更新 PBR、RenderPipeline、能力矩阵和 glTF 接入参考，完成跨后端发布验收。

每个步骤完成相关测试后创建独立提交；步骤 1 可先由上层项目接入验证，其余步骤继续在同一版本
分支推进。

## 测试与验收

- TBN：同 Mesh 正负缩放、镜像 UV、双反射、非均匀缩放加旋转和非平法线贴图。
- 正面判定：正负缩放实例在开启背面剔除时均可见，调用方不复制或反转索引。
- Alpha：阈值两侧、因子/纹理/顶点色组合、正反面照明、深度写入和阴影轮廓。
- 纹理输入：UV0/UV1 混用、逐槽 repeat/clamp/mirror、过滤模式、缺失 UV1 和默认值。
- 顶点色：RGB、Alpha、插值、无属性默认，以及三种 Alpha 模式下只组合一次。
- 透明：两层和八层、等深度、多 View、Alpha 0/1、不透明遮挡、IBL 与一致曝光。
- Vulkan 与浏览器 WebGPU 运行相同 Shader 源和材质语义；Validation 无错误。
- Windows、Linux、Emscripten、安装 SDK Consumer、文档检查和发布工作流通过。

## 风险与未决问题

- 逐纹理独立 Sampler 会增加绑定数；先使用固定五槽布局，只有真实压力证明需要时再评估
  Sampler 去重或 Bindless。
- 透明对象级排序不能解决相交 Mesh 内部顺序，首版接受该限制并提供确定性结果。
- 双面法线方向和负缩放反射会共同影响 TBN，二者必须使用组合测试，不能分别通过后即假定组合正确。
- 标准 PBR 模板和生成资产会改变，发布前必须重新生成仓库内置资产并验证安装包。
