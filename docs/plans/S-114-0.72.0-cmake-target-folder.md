# S-114：CMake IDE 目标父目录

## 状态

**已完成实现，待 v0.72.0 发布候选验收，2026-11-17。** 目标是为父项目提供可选的 Granit IDE 目标父目录，
不改变目标名称、链接关系或安装导出。

## 背景与目标

Granit 当前已有 `Modules`、`Tests/Smoke`、`Examples` 和 `Benchmarks` 等 `FOLDER` 分类，但被父项目通过
`add_subdirectory` 引入时，这些目标仍可能与父项目目标混在一起。需要一个不污染父项目全局 CMake 状态的配置入口。

新增缓存变量 `GRANIT_CMAKE_TARGET_FOLDER`：

- 默认为空，保持现有 IDE 目标布局；
- 非空时作为所有 Granit 自有 `granit_*` 目标的父目录；
- 目标已有的 `FOLDER` 作为子路径保留；
- 没有 `FOLDER` 的目标直接放在该父目录下；
- 非 `granit_*` 目标不处理。

## 非目标

- 不重命名 CMake target；
- 不修改安装导出、组件选择、链接依赖或运行时行为；
- 不改变第三方目标自身的文件夹属性；
- 不新增公共 C/C++ API 或 ABI。

## 实施顺序

1. 在 `granit_options.cmake` 增加空字符串缓存变量和中文说明。
2. 在通用 CMake 工具中递归收集已创建的 Granit 目标，应用父目录前缀并避免重复前缀。
3. 在顶层构建完成后统一调用，覆盖可选模块、测试、示例、工具和 benchmark。
4. 增加独立 CMake fixture，验证默认配置、带父目录配置、已有子路径、未归类目标和外部目标。
5. 更新构建指南、CMake 目录说明、版本规划和 Changelog。

## 测试与验收

- [x] 默认 `GRANIT_CMAKE_TARGET_FOLDER` 为空，现有 `FOLDER` 不发生变化；
- [x] 指定 `Granit` 后，`Tests/Smoke` 变为 `Granit/Tests/Smoke`；
- [x] 没有既有 `FOLDER` 的 `granit_*` 目标进入 `Granit`；
- [x] 非 `granit_*` 目标保持原 `FOLDER`；
- [x] Windows Clang 配置、增量构建和相关 CTest 通过；
- [x] 文档链接和 `git diff --check` 通过。

## 风险与未决问题

该变量只影响生成器的 IDE 分组，不影响 Ninja 构建路径和安装包。若父项目需要更细粒度的分类，仍可在
父项目侧对自有目标设置独立 `FOLDER`。
