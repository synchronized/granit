# 任务编号：S-107：0.68.1 独立 Consumer 与发布文档修复

## 状态

**已完成。**

## 背景与目标

v0.68.0 发布后的回归验证发现，独立 Emscripten Web Consumer 直接加载测试依赖模块时没有继承根项目的
依赖策略和源码缓存目录，导致 Unity 策略为空而无法配置。本补丁版本修复独立 Consumer 的依赖配置，
并收口测试依赖 CMake 迁移后的文档状态。

## 非目标

- 不新增公共 C/C++ API 或 ABI；
- 不改变运行时渲染行为和生产库传递依赖；
- 不改变 Catch2、Unity 的锁定源码版本和许可证边界；
- 不重新设计第三方依赖获取策略。

## 实施内容

- 将 Catch2、Unity 的测试依赖集成入口统一到 `cmake/`；
- 删除 `3rd/` 中已迁移的测试框架源码副本；
- 让独立 Web Consumer 显式使用 `vendor/cache`、锁定依赖和离线模式；
- 补齐文档索引、路线图和 v0.68.1 发布记录。

## 验收门槛

- [x] Linux/Windows 相关 CI 通过；
- [x] Emscripten WebGPU 构建、独立 Consumer 和浏览器示例矩阵通过；
- [x] 文档链接检查通过；
- [x] 工作区和 `main` 远程分支保持同步；
- [x] 不新增公共 API、ABI 或生产库传递依赖。
