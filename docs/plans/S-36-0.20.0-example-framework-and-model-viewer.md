# S-36：0.20.0 示例框架与跨平台 Model Viewer 稳定化

## 状态

**实现中。** S-36A～S-36F 已完成交互、帧延迟、示例分层、目录迁移、Web 稳定化和跨平台视觉
验收。Model Viewer
与 ImGui 的内容及平台入口已归入 `examples/samples`，跨示例的 glTF、SDL3、ImGui、视觉比较和
浏览器资源支撑已归入 `examples/common`；旧 `examples/platform`、根 `web` 和 Model Viewer
转发入口均已删除。SDL3 输入适配会统计跨背压合并的输入帧，帧执行器会统计被替换帧的队列滞留
时长，性能面板已显示这两项数据。

Web Model Viewer 已覆盖异步加载、取消、相对 URL、CORS 诊断、Resize、初始化超时、输入捕获和
资源释放；浏览器控件会写入共享 Viewer Core。S-36F 已使用共用固定画面完成 Vulkan 离屏和
浏览器 1×/2× DPI 的区域语义断言，并修复 Canvas 的 WebGPU Y 轴投影和 WGSL 纹理采样。
Windows 的真实窗口 DPI/焦点事件、输入失焦清理和 SDL3 窗口 Smoke 已通过；Linux 的 GCC/Clang、
X11/Wayland 集成及 Emscripten 的正式浏览器目标也已通过。剩余工作是 S-36G 发布收尾，完整结果见
[S-36 跨平台验收记录](../records/2026-09-10-s36-cross-platform-acceptance.md)。

S-36F 已增加共用固定画面、Vulkan 离屏及浏览器 1×/2× DPI 视觉断言，并通过点击验证内容状态和
画面同步变化。截图检查发现并修复 Canvas 的 WebGPU Y 轴投影和 WGSL 纹理采样遗漏。固定语义
区域是稳定基准；整图保留为诊断产物，不以受字体栅格和驱动影响的逐像素结果作为跨平台门禁。
GitHub Hosted Linux Chrome 不暴露 WebGPU Canvas 合成像素时会明确跳过浏览器颜色采样，页面帧
推进、交互状态、Draw Data 和资源关闭仍必须通过，Vulkan 离屏像素继续作为强制视觉门禁。

## 背景与目标

S-36 启动时，Model Viewer 已能在桌面 Vulkan 和浏览器 WebGPU 运行，但桌面渲染线程背压会丢弃
指针增量，ImGui 的全局鼠标捕获也会使视口拖动不稳定。当时的 `examples/platform/web` 与根
`web/` 还分担同一个 Web 示例的输入、资源加载和 Emscripten 生命周期，新增示例容易复制壳层。

本版本完成三个目标：

- 修复 Model Viewer 的旋转、缩放、焦点、窗口缩放和加载交互，使队列饱和时仍保持低延迟。
- 让浏览器 Model Viewer 与桌面版共享同一示例核心和输入语义，并形成稳定的自动化验收。
- 建立类似成熟渲染库的“框架、平台壳层、示例内容”分层，使新示例只实现自身演示逻辑。

## 非目标

- 不把示例执行器、轨道相机、glTF 加载器、文件系统或线程池提升为公共 SDK API。
- 不新增 Android、桌面 Dawn、新渲染后端或新的渲染特性。
- 不为展示数量保留可由单元测试或集成测试替代的三角形、资源创建等琐碎示例。
- 不在本版本建立统一示例启动器；示例数量形成真实需求后再评估。
- 不修改 Gneiss；本版本只修改 Granit 仓库。

## 已确认决策

- 用户级示例保留 `model_viewer` 与 `imgui`；测试性质的程序继续归入 `tests` 或 Smoke。现有
  `sdl3_imgui` 演进为同一内容核心、SDL3 平台输入以及 Vulkan/WebGPU 双入口的 `imgui` 示例。
- `examples/common` 按技术域平坦保存示例私有的生命周期、输入、资源定位、计时和平台桥接；它
  不安装、不导出，也不形成与公共 API 平行的运行时。
- `examples/samples/<name>` 保存示例自身内容、说明和最少平台无关逻辑；桌面与 Web 入口只负责
  窗口、事件循环和平台生命周期。
- 使用统一 CMake 辅助函数声明名称、支持平台、依赖组件和测试方式，两个示例可独立构建。
- Model Viewer 的相机状态在生产侧更新；背压只能跳过昂贵 Frame Packet 构造，不能丢弃输入。
- 输入捕获按一次拖动的起点确定所有权：从视口开始的拖动跨过面板后仍控制相机，从 UI 开始的
  拖动不泄漏给相机。失焦、离开窗口和按钮释放必须恢复稳定状态。
- Web 与桌面复用相同输入归一化和 Model Viewer 核心；平台差异通过窄接口表达，不使用条件编译
  污染示例内容。
- Model Viewer 的桌面工具界面使用 ImGui，Web 工具界面使用 DOM/CSS；两者共享状态、操作、校验
  和统计模型，而不抽象含义不一致的通用 Widget。Web Renderer 创建前也由 DOM 显示进度与错误。
- `imgui` 示例专门验证 SDL3、ImGui Adapter、字体、纹理、裁剪、DPI 和输入在 Vulkan/WebGPU 的
  一致性，不由 Model Viewer 重复承担该目标。

## 实施顺序

1. **S-36A 交互正确性**：修复背压期间指针和滚轮增量丢失、拖动所有权、失焦恢复、HiDPI 与
   Resize；增加跳帧输入回放和捕获边界测试。
2. **S-36B 帧延迟收敛**：相机在主线程持续更新，渲染线程只消费最新不可变快照；合并可替换旧帧，
   增加输入合并、跳过构造和渲染滞后统计，避免用扩大队列掩盖延迟。
3. **S-36C 示例分层**：建立 `common` 与统一 CMake 声明，迁移公共生命周期、输入、资源
   定位、计时和命令行逻辑。
4. **S-36D 示例目录迁移**：迁移 `model_viewer` 与 `imgui`，合并根 `web/` 和现有 Web 平台目录，
   清理重复壳层并保持旧桌面目标名称兼容。
5. **S-36E Web 稳定化**：以 DOM/CSS 补齐 Model Viewer 工具面板，验证异步加载进度与取消、相对
   URL、CORS 诊断、Canvas Resize、设备丢失诊断、初始化超时、输入捕获和资源回收。
6. **S-36F ImGui 双后端验收**：让同一 ImGui 内容通过 SDL3 分别运行于桌面 Vulkan 和浏览器
   WebGPU，验证 Draw Data、纹理、裁剪、字体、DPI、输入和截图容差。
7. **S-36G 示例目录与发布验收**：补齐示例索引、独立构建命令、平台/能力要求、资产许可和故障
   排查；完成桌面与浏览器矩阵后统一更新版本号、Changelog 和发布记录。

## 测试与验收

- 合成输入在连续可提交与间歇背压两种时序下得到相同相机结果；指针和滚轮累计值有界且不突跳。
- 从视口和 UI 分别开始拖动、跨窗口边界、失焦、重新聚焦和释放按钮均有确定行为。
- 桌面 Vulkan Model Viewer 连续拖动时不消费陈旧相机帧，统计能区分输入合并、跳过构造和帧替换。
- 浏览器 Chrome WebGPU 使用正式 Model Viewer 离线 Fixture 完成加载、取消、旋转、缩放、Resize、
  截图像素容差和关闭资源归零测试；三角形 Smoke 不能替代该验收。
- `model_viewer` 与 `imgui` 可分别启用和构建；示例私有依赖不进入安装导出或下游 Consumer。
- Model Viewer Web DOM 与桌面 ImGui 具有相同功能状态和操作结果；`imgui` 示例则使用同一份
  ImGui 内容完成 Vulkan/WebGPU Draw Data 与像素容差回归。
- Windows、Linux 和 Emscripten 构建通过；文档中的桌面与浏览器运行命令可直接复现。
- 发布前通过 Quick Check、Documentation、受影响平台集成和不可变 Release Candidate。

## 风险与未决问题

- 将相机更新移到生产侧时必须保持 Frame Packet 不可变，不能让渲染线程读取实时可变状态。
- 浏览器事件循环不能复用桌面阻塞线程模型；复用边界应是状态机和数据，不是线程实现。
- 示例框架只服务仓库示例。若 Gneiss 等第二个真实 Consumer 需要相同能力，再独立评估公共 API。
- 目录迁移应保留过渡目标别名或同步更新 CI、指南与脚本，避免只移动源码而遗漏发布产物路径。
