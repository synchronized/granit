# S-42：0.24.0 测试架构收敛

## 状态

**本地实现完成，等待远端验收。** S-42A～S-42F 已完成测试标签、目录收敛、共享帧辅助逻辑和
工作流职责选择。`tests/smoke` 只保留两个端到端健康检查，其余测试按模块、GPU 集成、平台集成、
浏览器和安装包表达职责。版本不改变公共 API、ABI、资产格式或运行时行为。详细本地结果见
[S-42 本地验收记录](../records/2026-09-14-s42-local-acceptance.md)。

## 背景与目标

当前 `tests/smoke` 同时包含版本查询、Renderer 初始化、离屏清屏、回读、Graphics、Compute、
Material Hot Reload、PBR、Render Pipeline、Immediate UI 以及多个窗口后端。部分测试只检查返回码，
部分与模块测试重复，多个窗口程序还复制了 acquire、clear、submit、cancel 和 present 循环。

本任务建立按验证边界划分的测试结构：

```text
tests/
├─ core/ renderer/ pipeline/ material/ scene/ lighting/
├─ window/                       # Window component 与 Renderer 接合
├─ integrations/{imgui,sdl3}/   # 第三方集成特有边界
├─ gpu/                          # 真实 GPU/软件 GPU 集成回归
├─ smoke/                        # 两个最短端到端健康检查
├─ web/                          # 浏览器入口矩阵
├─ consumer/ package/
├─ fixtures/
└─ support/                      # 测试私有共享辅助代码
```

目标是减少重复实现和模糊命名，同时保留 Vulkan、WebGPU、Win32、XCB、Wayland、SDL3、Compute、
PBR 和安装 SDK 的独立失败定位能力。

## 非目标

- 不以减少测试数量或 CI 时间作为删除独立后端覆盖的理由。
- 不把 Catch2、测试 Fixture 或测试辅助接口安装到 SDK。
- 不把 SDL3 窗口改由 Granit Window component 创建；SDL3 集成必须继续验证外部窗口适配。
- 不合并 Web 平台 Smoke、Model Viewer 和 ImGui 三个不同浏览器入口。
- 不借测试移动重构 Renderer、Render Pipeline、Material 或 Window 的产品实现。
- 不在计划阶段提前修改项目版本号或建立 0.24.0 CHANGELOG 发布条目。

## 已确认决策

### Smoke 只保留两个

`granit.smoke.gpu_offscreen` 验证最短 GPU 闭环：Renderer、Shader Library、Graphics Pipeline、
离屏 Texture、清屏、三角形、提交、Readback 和像素断言。它取代只验证部分链路的 `version`、
`renderer`、`offscreen_clear`、`texture_readback` 和 `offscreen_triangle` Smoke。

`granit.smoke.render_pipeline_window` 验证最高层窗口闭环：Window、Surface、Swapchain、Frame
Context、空场景、普通场景、Canvas/Overlay、连续提交和 Present。Windows 运行完整可见窗口路径；
平台专属连接由 Window component 集成测试覆盖。

Smoke 不因后端不可用而静默报告已覆盖。允许跳过时必须由 CTest 明确记录 Skip，并由至少一个远端
环境执行成功路径。

### Window component 统一原生平台

扩展现有 `tests/window/window_renderer_test.cpp`，让 Win32、XCB 和 Wayland 都通过公共 Window
component 创建窗口，再执行同一套 Surface 与 Swapchain 验证。公共辅助逻辑负责 Backbuffer、
clear、submit、cancel、present 和多帧循环。

完成后删除手写原生窗口循环 `window_clear.cpp`、`xcb_window_clear.cpp` 和
`wayland_window_clear.cpp`。平台差异只保留在 Window component 实现和创建参数中。

SDL3 继续作为独立集成测试：从 `SDL_Window` 调用 `query_surface_type` 和 `create_surface`，然后
复用相同的 Swapchain 验证辅助逻辑。改用 Window component 会绕过被测 SDL3 adapter，因此不接受。

### 有独立价值的测试重新归类

| 当前 Smoke | 目标位置或处理 |
|---|---|
| `version.cpp`、`renderer.cpp` | 删除，由模块测试和 GPU Smoke 覆盖 |
| `offscreen_clear.cpp`、`texture_readback.cpp`、`offscreen_triangle.cpp` | 合入 GPU Smoke |
| `compute.cpp` | `tests/gpu/compute_test.cpp`，增加逐值断言 |
| `material_hot_reload.cpp` | 合入 `tests/material/material_hot_reload_test.cpp` |
| `immediate_ui_adapter.cpp` | 合入 Canvas 或 ImGui 集成测试 |
| `pbr_offscreen.cpp` | `tests/gpu/pbr_render_test.cpp` |
| `render_pipeline_offscreen.cpp` | `tests/gpu/render_pipeline_test.cpp` |
| `render_pipeline_window.cpp` | 保留并加强为窗口 Smoke |
| `window_clear.cpp`、`window_triangle.cpp`、`window_hdr.cpp` | 迁移独有断言后删除 |
| `sdl3_window_clear.cpp` | `tests/integrations/sdl3/surface_test.cpp` |
| `xcb_window_clear.cpp`、`wayland_window_clear.cpp` | 合入 Window component 测试后删除 |

PBR、HDR 和 Render Pipeline 测试必须保留其独有像素或参考结果，不能因为完整管线能够运行就删除
更易定位问题的中层 GPU 回归。

### 测试标签表达执行成本和环境

CTest 使用以下标签，单个测试可以具有多个标签：

| 标签 | 含义 |
|---|---|
| `unit` | 不依赖真实提交或窗口的算法与模块契约 |
| `smoke` | 两个最短端到端健康检查 |
| `gpu` | 需要真实 GPU 或软件 GPU |
| `integration` | 跨两个以上产品模块 |
| `platform` | Win32、XCB、Wayland 或 SDL3 窗口路径 |
| `browser` | Chrome WebGPU 行为与视觉入口 |
| `package` | 安装 SDK、导出与独立 Consumer |
| `release` | 完整发布门禁 |

标签用于选择测试集合，不替代稳定的测试名称，也不让同一行为在多个可执行文件中重复实现。

## 实施顺序

1. **S-42A 基线与标签（已完成）**：记录现有测试名称、平台条件、耗时和覆盖职责；先为现有
   CTest 增加标签，让 Quick Check、平台 CI 和 Release 能按职责选择，但保持执行集合不变。
2. **S-42B GPU Smoke 收敛（已完成）**：建立 `gpu_offscreen.cpp`，合并清屏、三角形和
   Readback，并增加确定像素断言；删除五个被完全覆盖的简单 Smoke。
3. **S-42C Window 与 SDL3 收敛（已完成）**：抽取测试私有 Swapchain 帧辅助逻辑，扩展 Window
   component 的 Win32/XCB/Wayland 测试，并把 SDL3 移入第三方集成目录。
4. **S-42D GPU 集成归位（已完成）**：迁移 Compute、PBR、HDR 和离屏 Render Pipeline；Compute
   增加结果断言，PBR/HDR 保留参考输出语义。
5. **S-42E 模块测试归位（已完成）**：确认 Material Hot Reload 与 ImGui/Canvas 模块测试已覆盖
   对应场景并删除重复程序；窗口 Smoke 覆盖空场景加 Canvas、普通场景和多帧 Present。
6. **S-42F 工作流与发布验收（跨平台完成，等待候选）**：Quick Check 运行 `unit` 与 `smoke`；
   Windows 使用标签排除托管环境无法运行的 GPU/平台测试，Linux 保留完整测试；Emscripten 保留
   三个浏览器入口；Release Candidate 保留完整 Linux GPU 测试及四套安装包门禁。

每个阶段形成一个可独立评审的提交，全部阶段在同一个 0.24.0 特性分支和 Pull Request 中完成。

## 测试与验收

- `tests/smoke` 最终只包含 `gpu_offscreen.cpp` 和 `render_pipeline_window.cpp`。
- GPU Smoke 同时断言清屏、三角形内外区域和 Readback 布局，不只检查返回码。
- Compute 回读的每个元素都有确定预期值。
- Win32、XCB、Wayland 均通过 Window component 完成 Surface、Swapchain 和帧生命周期验证。
- SDL3 测试仍从 `SDL_Window` 进入 Granit adapter，并复用公共帧验证逻辑。
- Web 平台 Smoke、Model Viewer 和 ImGui 继续作为三个独立浏览器任务通过。
- PBR、HDR、空场景、Canvas/Overlay 和普通 Renderable 的独有回归均有唯一权威测试。
- `ctest --show-only=json-v1` 能通过标签清楚区分日常检查、GPU、平台、浏览器和包测试。
- Windows/Linux 共享与静态、Emscripten、安装 Consumer、文档和 Release Candidate 全部通过。

## 风险与未决问题

- 合并 Smoke 时必须先建立覆盖映射；没有等价像素或状态断言的旧测试不能直接删除。
- XCB 与 Wayland CI 需要真实显示服务器环境；环境不可用造成的 Skip 不能算作平台成功验收。
- 共用 Swapchain 辅助代码只属于测试，不应演变为产品层第二套 Frame Loop 抽象。
- 标签迁移期间应比较调整前后的测试清单，防止正则或标签选择意外漏跑测试。
