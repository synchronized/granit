# S-85：0.49.0 异步回读契约与诊断

## 状态

**实施中。** S-85A 已完成：审计现有 `map`、`readback_batch` 和 `async_operation` 契约，补充
Readback Batch Reference，并修复非零结果接受空目标缓冲区的边界错误。Windows 本地回读资源测试、
Linux、Windows 和 Emscripten CI 均已通过。本计划处理此前 `readback`、`map_async` 语义容易混淆的
问题，优先审计并验证现有接口，不预设新增公共 ABI。

## 目标

1. 明确 `buffer::map`、`readback_batch` 和 `async_operation` 的同步、异步、线程和生命周期契约；
2. 在 Vulkan 与 WebGPU 上验证异步回读的状态转换、取消、重复查询、资源销毁和失败清理；
3. 为 GPU 回读、Loader、设备能力和资源生命周期建立可定位的结构化内部诊断；
4. 形成可复现的 Tutorial/测试夹具，避免把后端竞态误判为 Vulkan 驱动问题。

## 固定边界

- 不把 Vulkan 类型、句柄或调试回调暴露到公共 C/C++ API；
- 不为已有 `readback_batch` 另建第二套异步任务系统；
- 不在没有跨后端证据前新增名为 `map_async` 的平行接口；
- 不实现 SVT、纹理驻留预算、VFS、资源回收或 Gneiss 专用调度；
- 不把日志文本作为稳定 ABI，结构化诊断优先服务测试、开发构建和示例。

## 实施顺序

1. **S-85A 契约审计**：整理现有 map/readback 入口、状态码、完成条件、线程约束和所有权，补齐
   Reference 与最小负向测试。
2. **S-85B 异步回读验收**：覆盖 Vulkan/WebGPU 的 Buffer/Texture 回读、未完成查询、重复消费、
   取消、销毁和 Renderer 关闭；记录固定的延迟帧与失败清理行为。
3. **S-85C 诊断管线**：增加内部分级诊断和 request/resource/frame 关联字段，默认不改变 ABI；
   为 Loader、设备能力、提交、回读和生命周期失败提供可搜索上下文。
4. **S-85D Tutorial 与浏览器夹具**：增加最小异步回读示例或扩展现有能力教程，桌面与浏览器使用
   同一确定性断言，不依赖控制台文本或固定时序睡眠。
5. **S-85E 发布验收**：完成 C/C++ Consumer、Windows/Linux Vulkan、Emscripten WebGPU、文档检查、
   Sanitizer/Validation 相关回归后发布 v0.49.0。

## 验收门槛

- 文档能明确回答 `map` 与异步回读的区别，以及何时可以读取结果；
- 未完成、重复查询、重复消费、取消、销毁和关闭路径均有稳定结果码；
- Vulkan 校验层无新的同步或资源生命周期错误，Linux Lavapipe 不崩溃；
- WebGPU 不依赖阻塞式映射或浏览器控制台推断业务状态；
- 公共头文件仍不包含 Vulkan SDK 头文件，默认不增加公共 ABI；
- Granit/Gneiss 职责边界保持不变，UPSTREAM-044 的驻留与预算工作不进入 Granit。
