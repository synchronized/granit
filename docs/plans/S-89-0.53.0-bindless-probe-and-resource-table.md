# S-89：0.53.0 Bindless 能力探针与 Resource Table 原型

## 状态

**已完成并随 v0.53.0 发布。** S-89A、S-89B 和发布验收已完成。本版本承接 v0.52.0 的真实绑定压力结论，建立可验证的资源索引
契约和能力探针；由于后端无关的资源索引写入与 Shader/Pipeline 变体契约尚未稳定，真实 Vulkan
Descriptor 数组采样暂缓，传统 Bind Group 继续是默认路径。

## 目标

1. 建立后端无关的 Bindless 能力与容量描述，不公开 Vulkan 特性名、Descriptor Set 或原生句柄；
2. 完成纯 CPU Resource Table，验证索引、generation、资源类型、Renderer 归属和延迟回收；
3. 完成 Vulkan-only 实验后端的准入设计；真实资源索引采样待契约稳定后实施；
4. 在 WebGPU 和不支持 Descriptor Indexing 的 Vulkan 设备上明确报告不支持并保持传统回退；
5. 只有对照数据证明收益后，才考虑进入材质变体和正式公共 API。

## 固定边界

- 不改变默认 Bind Group 路径，不让材质或 Renderer 初始化依赖 Bindless；
- 不在公共头文件中出现 Vulkan 类型、扩展常量或 Descriptor 语义；
- 不实现 Descriptor Buffer、SVT、纹理驻留、VFS 或 Gneiss 资源生命周期；
- 不承诺资源索引跨 Renderer、跨进程或跨版本持久化；
- WebGPU 只提供能力探针和传统路径回退，不伪造 Bindless 语义。

## 实施阶段

### S-89A：契约与 CPU Resource Table（已完成）

- 定义内部资源表条目、类型标签、generation、容量和延迟回收状态；
- 覆盖成功分配、重复释放、旧索引、类型错误、跨 Renderer 和容量耗尽；
- 使用固定测试时钟/完成点验证 GPU 在途期间不能复用索引。

### S-89B：能力探针与示例骨架（已完成）

- 增加后端无关的 Descriptor Indexing 能力位；
- 新增 `12_bindless_probe`，显示设备前置能力和传统路径回退；
- WebGPU 与不支持设备不伪造 Bindless 语义。

### S-89C：Vulkan 实验准入（延期）

- 暂不创建公共 Vulkan Descriptor 数组接口，也不在教程中直接包含 Vulkan 头文件；
- 等待资源索引写入、Shader/Pipeline 变体选择和 GPU 生命周期契约统一后再实现实际采样；
- 当前只保留设备能力位和探针结果，避免把“设备支持”误报为“Granit 路径可用”。

### S-89D：发布验收（已完成）

- Windows Vulkan 硬件与不支持设备各一条探针结果；
- Linux Vulkan/Lavapipe 明确记录支持或降级结果；
- Emscripten 编译通过并显示 fallback；
- shared/static、C11/C++20 Consumer、文档链接和公开 Release 全部通过。

## 验收门槛

- 不支持 Bindless 的设备仍能完整运行传统教程和 RenderPipeline；
- 旧索引不能访问槽位复用后的新资源；
- Vulkan 实验路径失败时返回明确结果，不静默改变 Shader/Pipeline 布局；
- 公共 ABI 无 Vulkan 泄漏，且没有把实验 API 误写成稳定能力；
- 没有稳定公共契约和可重复的真实收益前，不把 Bindless 接入默认材质路径。
