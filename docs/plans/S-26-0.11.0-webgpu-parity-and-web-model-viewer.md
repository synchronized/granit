# S-26：0.11.0 WebGPU 能力对齐与浏览器 Model Viewer

## 状态

- 路线图任务：S-26
- 目标版本：0.11.0
- 优先级：P1
- 状态：实现中；S-26A 已完成
- 前置依赖：S-12、S-13、S-16、S-24、S-25、R-10

## 背景与目标

0.10.0 已让桌面 Vulkan Model Viewer 使用公共 PBR、Environment Map 和帧构造背压。浏览器
WebGPU 目标也能加载测试 glTF，并通过同一 Model Viewer Core、Render Pipeline 和同步执行器完成
绘制，但当前产物仍是自动化 `granit_web_platform_smoke`，使用简化 Fixture，不能作为完整示例
交付。

WebGPU 后端仍有一部分已经由公共 Command Recorder 表达、但当前返回 `UNSUPPORTED` 的资源传输、
Mipmap 和查询能力。0.11.0 先收敛 Vulkan 与 WebGPU 的可移植公共子集，再把浏览器 Smoke 提升为
可交互、可加载正式资产的 Model Viewer，以同一真实工作负载验收两套后端。

## 非目标

- 不要求 WebGPU 模拟 Vulkan 专属同步、Barrier、持久映射、Pipeline Cache 或原生互操作。
- 不恢复桌面 Dawn，也不新增 WebGPU 动态插件边界。
- 不公开 Model Viewer 的 glTF Loader、执行器、Frame Packet、资产数据库或应用主循环。
- 不引入 Android、TAA、Bindless、Clustered Forward、透明 PBR 或通用任务系统。
- 不承诺所有公开纹理格式和硬件可选特性在两套后端上无条件可用。

## 已确认决策

### 可移植能力矩阵

- 以公共 C/C++ API 为比较边界，不按 Vulkan 函数数量衡量 WebGPU 完成度。
- 每项能力标记为“共同支持、能力受限、平台固有限制、尚未实现”，并记录可查询条件和失败结果。
- 能力可在创建前查询时必须优先查询；设备或浏览器未启用可选 Feature 时返回
  `GRANIT_ERROR_UNSUPPORTED`，不静默降低质量或更换操作。
- Registry 保持后端无关验证；WebGPU Provider 继续防御性校验，不在公共源码中增加
  `wgpu*`、`WebGPU` 或 Emscripten 特判。

### 资源传输与 Mipmap

- 补齐 WebGPU 的 Buffer 到 Buffer、Buffer 到 Texture、Texture 到 Texture 和 Buffer 填充命令；
  Texture 到 Buffer 沿用现有同步回读与行跨度契约。
- 公共复制区域、Usage、对齐、范围、重叠和所属 Renderer 的错误语义与 Vulkan 一致；WebGPU
  特有的 256 字节行对齐由 Provider 内部处理。
- Mipmap 保持同一公共命令。Vulkan 可使用线性 Blit，WebGPU 使用 Render 或 Compute 路径生成，
  不向公共 API 暴露实现算法。
- 不支持过滤写入的格式必须在执行任何子资源修改前失败；多层、Cube、非二次幂和部分 mip 范围
  使用与 R-10C 相同的验收语义。

### Timestamp 与能力差异

- WebGPU 仅在 Adapter/Device 实际启用 `timestamp-query` 时公开 GPU Timestamp；否则现有查询 API
  返回 `UNSUPPORTED`，Model Viewer 隐藏 GPU 时间而不是显示零值。
- Query Set、写入、Resolve 和 Map Read 生命周期封装在 WebGPU 后端；公共 Timestamp Pool、阶段和
  结果单位保持不变。
- LOD Bias、持久映射、显式 Present 和原生 Pipeline Cache 等不可移植差异保留为明确限制，不为
  表面一致建立含义不可靠的模拟层。

### 正式浏览器 Model Viewer

- 保留 `granit_web_platform_smoke` 作为快速自动化门禁，新增面向用户的
  `granit_model_viewer_web`，二者复用相同 Model Viewer Core，不互相冒充。
- 正式目标加载 Flight Helmet、材质纹理和已发布 GRENV 环境资产；网络获取、URL、缓存和取消仍是
  示例平台层职责，Granit 只消费内存字节。
- 浏览器使用同步帧执行器，不引入 pthread；资产解析和 GPU 上传按阶段推进，每帧设定时间或字节
  预算，确保 Canvas、输入和加载界面持续响应。
- 接入 ImGui Canvas 渲染、键鼠/滚轮输入、加载进度、错误信息、渲染质量控制和资源关闭检查；界面
  默认使用可随产物发布的英文文本，不强制引入 CJK 字体包。
- Canvas 根据 CSS 尺寸与设备像素比重建，正确处理零尺寸、页面失焦、隐藏、恢复和 Device Lost。

## 实施顺序

1. **S-26A 能力审计（已完成）**：已经建立公共 API 的 Vulkan/WebGPU 对照表，并给 WebGPU
   `UNSUPPORTED` 路径分类；结论见[能力审计记录](../records/2026-09-06-s26a-webgpu-capability-audit.md)。
2. **S-26B 通用传输**：实现 Buffer/Texture 复制、Buffer 填充和回读边界，复用 R-10 的公共测试，
   增加真实 Chromium WebGPU 用例。
3. **S-26C Mipmap 与资源子集**：实现 WebGPU Mipmap 路径，补齐正式模型需要的格式、数组层、Cube
   和复制组合；资源数组与 Compare Sampler 仅在公共契约完整且真实场景需要时纳入。
4. **S-26D Timestamp 与能力报告**：接通可选 Timestamp Query，完善能力快照、诊断和 Model Viewer
   降级显示。
5. **S-26E 浏览器 Model Viewer**：新增正式目标，接入真实资产、环境、ImGui、输入、加载进度、
   分帧上传、Resize 和恢复路径；保留现有 Smoke 的短反馈周期。
6. **S-26F 0.11.0 验收**：完成双后端截图容差、交互、资源归零、安装 Consumer、Emscripten、文档、
   ABI 快照、迁移指南、变更记录和 Release 候选验证，最后统一提升版本号。

## 测试与验收

- 同一组公共复制测试在 Vulkan 与真实浏览器 WebGPU 上通过，覆盖成功、Usage 错误、越界、重叠、
  对齐、跨 Renderer、失效句柄和失败不产生部分修改。
- WebGPU Mipmap 覆盖线性/sRGB、非二次幂、部分范围、多层与 Cube；采样结果与 Vulkan 在约定容差内
  一致，不通过单层静默降级。
- 支持 Timestamp 的浏览器返回单调且可解释的 GPU 时间；不支持时能力查询和运行结果一致。
- 正式浏览器 Model Viewer 能加载 Flight Helmet、显示完整材质与环境光、响应轨道相机和 ImGui，
  加载期间页面不进入长时间未响应状态。
- Canvas Resize、DPI、失焦恢复和 Device Lost 不泄漏资源；关闭后 Renderer 子资源统计归零。
- `granit_web_platform_smoke` 继续作为快速门禁；正式目标增加 Chromium 截图、输入和质量切换验收。
- Windows/Linux Vulkan 共享与静态矩阵、Emscripten、文档及发布包全部通过。

## 风险与未决问题

- 浏览器对 `timestamp-query` 的暴露受实现、安全策略和启动参数影响，不能成为 Model Viewer 启动
  前置条件。
- WebGPU Mipmap 的 Render 与 Compute 方案在格式覆盖、Shader 数量和性能上不同；S-26C 应先用
  最小原型和真实模型测量决定，不提前形成第二套公共接口。
- Flight Helmet 及环境资产会增加 Web 产物和下载时间；正式示例应使用独立文件和 HTTP Fetch，
  不把全部资产嵌入 Wasm。
- 浏览器主线程不能同步执行大块解析或上传；若分帧预算仍不能满足响应性，再单独评估 Web Worker，
  不在本计划预先引入共享内存和 pthread 约束。
