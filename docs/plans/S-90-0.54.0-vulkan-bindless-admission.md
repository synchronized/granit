# S-90：0.54.0 Vulkan Bindless 准入验证

## 状态

**实施中。** S-90A、S-90B 已完成，S-90C 待完成。本计划承接 S-89，目标是验证 Vulkan Bindless 是否具备进入 Granit 内部渲染路径的
条件，不在本版本冻结公共 Bindless ABI，也不改变 WebGPU 的 Bind Group 模型。

## 背景与目标

S-89 已完成 CPU Resource Table 和设备能力探针，但尚未证明真实 Vulkan Descriptor Indexing
采样能够与 Granit 的 Shader、Pipeline 和资源生命周期协同工作。S-90 需要建立最小可重复的
内部 Vulkan 对照路径，并用数据决定是否进入后续公共设计。

目标：

1. 仅覆盖 sampled texture 和 sampler 的最小 Descriptor Indexing 实验；
2. 明确资源索引写入、Shader/Pipeline 变体选择、generation 和 GPU 延迟回收契约；
3. 对比传统 Bind Group 与实验路径的绑定更新、CPU 录制、GPU 时间和资源占用；
4. 保证能力不足、容量不足或实验失败时继续使用传统 Bind Group；
5. Emscripten/WebGPU 不引入 Vulkan 式 Bindless，继续使用 Bind Group。

## 非目标

- 不新增包含 Vulkan 类型的公共头文件或 C ABI；
- 不让 Bindless 成为 Renderer、Material 或 Pipeline 的默认依赖；
- 不实现 Descriptor Buffer、Ray Tracing、Mesh Shader、SVT、纹理驻留或 Gneiss 调度；
- 不把 Vulkan 实验接口暴露到普通 Tutorial 或 WebGPU 后端；
- 不在缺乏真实收益数据时发布稳定的 Bindless 材质接口。

## 已确认决策

- Granit Resource Table 是资源索引的唯一所有者，Material 只保存经过验证的索引数据；
- 传统 Bind Group 与 Bindless 必须是显式 Shader/Pipeline 变体，禁止根据设备能力静默切换布局；
- Resource Table 的槽位回收必须晚于 GPU 完成点，旧 generation 永远不能访问复用槽位；
- Vulkan 能力探针表示设备前置能力，不表示实验路径已经可用；
- WebGPU 只报告不支持 Vulkan Bindless，并保持现有 Bind Group 回退。

## 实施顺序

### S-90A：内部 Vulkan 最小实验

- 建立仅供内部测试使用的 sampled texture/sampler Descriptor 数组；
- 使用固定纹理索引绘制并执行像素回读，验证索引正确性和资源可见性；
- 覆盖能力不足、容量不足、错误索引和实验关闭时的传统路径回退；
- 不把 Vulkan Descriptor 类型带入公共 API。

### S-90B：Pipeline 与生命周期契约

- 为传统 Bind Group 和实验 Bindless 明确独立的 Shader/Pipeline 变体；
- 将 Resource Table 更新和 GPU 完成点绑定，验证释放、延迟回收、旧 generation 和重复销毁；
- 验证 Renderer/device 归属和跨线程录制边界。

### S-90C：对照测量与准入结论

- 使用同一场景比较两条路径的绑定更新次数、CPU 录制时间、GPU 时间和显存/Descriptor 占用；
- 在 Windows Vulkan 硬件、Linux Vulkan/Lavapipe 和不支持设备上记录结果；
- 只有收益可重复且契约完整，才提出下一版公共后端无关 Bindless API；否则保留内部实验。

## 测试与验收

- Vulkan Validation 无 Descriptor Indexing、Pipeline Layout 或生命周期错误；
- sampled texture/sampler 索引绘制和像素回读结果正确；
- 传统 Bind Group 回归测试继续通过；
- 不支持设备和 WebGPU/Emscripten 构建不崩溃，并明确显示回退；
- 旧索引、错误类型、跨 Renderer 和 GPU 在途资源均不能访问错误资源；
- A/B 数据和结论写入独立实施记录，不把实验结果写成稳定公共能力。

## 风险与未决问题

- 各 Vulkan 驱动对 Descriptor Indexing 特性的支持组合可能不同；
- Lavapipe 可能支持能力位但不代表实验性能有意义；
- Shader 变体会扩大缓存和资产组合，必须先测量再决定是否进入材质包；
- 若 Vulkan 实验不能证明收益，0.54.0 的有效结论应是“保持 Bind Group 默认路径”。
