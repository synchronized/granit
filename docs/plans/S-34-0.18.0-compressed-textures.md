# S-34：0.18.0 压缩纹理与格式能力契约

## 状态

**已完成。** 首批格式、能力查询、布局计算以及 Vulkan/浏览器 WebGPU 上传链路已经落地；压缩
纹理读回和运行时 Mipmap 按计划保持不支持。

## 背景与目标

Granit 已有格式块 Footprint、Mip/层/区域写入和同步/批量/异步上传，但公开格式只有非压缩颜色与
深度格式，内部校验仍按逐像素布局计算。Gneiss 因而能解析 KTX2 和构建 RGBA8 资产，却无法通过
公共契约上传 BC、ETC2 或 ASTC 数据。

0.18.0 建立后端无关的块压缩纹理契约，让资产系统可以携带多个 GPU 格式变体，并在运行时根据
实际设备能力选择兼容变体。Granit 只接收已经转码的块数据，不解析 KTX2 或接管资产构建。

## 非目标

- 不引入 KTX-Software、Basis Universal 或运行时压缩/转码器。
- 不公开 KTX2、DDS、Vulkan、WebGPU 或 Gneiss 的类型和枚举。
- 不新增 D3D12、桌面 Dawn、Android 或其他后端。
- 不承诺压缩格式可作为颜色附件、存储纹理或支持运行时 Mipmap 生成。
- 不让 Granit 决定 Gneiss 的资产缓存、平台包或变体命名规则。

## 已确认方向

- 首批格式覆盖 BC1 RGBA、BC3 RGBA、BC5 RG、BC7 RGBA、ETC2 RGBA8 和 ASTC 4×4；仅为具有
  对应颜色空间语义的格式提供 UNORM/SRGB 成对枚举。
- `granit_texture_format_get_footprint` 继续提供与设备无关的块宽、块高和每块字节数。
- 增加统一紧密布局计算，返回块数量、行字节数、图像跨度和所需总容量，避免每个上游复制向上
  取整及末级 Mip 规则；结果不包含设备专有对齐。
- 增加 Renderer 格式能力查询，至少报告采样、过滤、传输源、传输目标及可用样本数；不支持格式
  返回成功查询和零能力，而不是把设备差异伪装成无效参数。
- 即时写入、Upload Batch、Command Recorder 与异步上传共享同一套块对齐和容量校验。
- Vulkan 与浏览器 WebGPU 根据真实设备 feature/format properties 报告能力；公共层不假设某一类
  GPU 必然支持 BC、ETC2 或 ASTC。

## 实施顺序

1. 扩展 C/C++ 格式枚举、格式分类、Footprint 和紧密布局计算，并补齐纯 CPU 测试。
2. 定义设备格式能力结构和查询 API，接入 Vulkan 与 WebGPU HAL。
3. 统一所有纹理上传入口的块布局验证，覆盖非边缘块对齐、边缘小 Mip、层/切片跨度和容量溢出。
4. 映射首批压缩格式，拒绝设备未启用的格式和不受支持的用途。
5. 增加 Vulkan/WebGPU Mock 一致性测试、真实后端上传采样 Smoke Test 和安装 Consumer 测试。
6. 更新 Texture、Upload Batch、能力查询参考及 0.18.0 发布验收记录。

## 测试与验收

- C11/C++20 公共头、Shared/Static、安装 Consumer 和 ABI 快照通过。
- 所有新增格式返回准确的块尺寸与字节数；1×1、非块倍数尺寸、多 Mip、数组层和 Cube 容量计算
  均有边界测试。
- 错位的非边缘区域、非法 Row Pitch、容量不足、错误用途和设备不支持格式返回稳定结果码。
- 同一压缩纹理 Fixture 在 Vulkan 与浏览器 WebGPU 支持设备上能够上传并采样；缺少对应 feature
  时能力查询为零且创建/上传不会静默回退为 RGBA8。
- Gneiss 可以只依赖公共 API 完成“多变体中选择设备支持格式并逐 Mip 上传”，无需读取 Granit
  私有头或复制块布局公式。

## 风险与未决问题

- WebGPU 的 BC、ETC2 与 ASTC 均受 Adapter feature 控制；浏览器 CI 软件适配器可能无法覆盖真实
  成功路径，需要 Mock 严格覆盖并在具备能力的硬件上保留手动 Smoke Test。
- 压缩 Texture-to-Buffer Readback 是否进入 0.18.0，取决于两套后端能否保持一致布局；若不能，
  本版本仅保证上传和采样，并明确返回 `GRANIT_ERROR_UNSUPPORTED`。
- 离线目标平台只能决定要打包哪些候选格式，不能替代运行时设备查询；上游应保留可移植回退变体。

## 完成摘要

- 公共 C/C++ API 已覆盖 11 个压缩格式枚举、块 Footprint、紧密布局与设备能力查询。
- 即时写入、Upload Batch、异步批次与 Command Recorder 共用块对齐、边缘 mip、跨度和容量校验。
- Vulkan 使用真实 Format Properties，WebGPU 根据 Device 启用的 BC/ETC2/ASTC feature 报告能力。
- Windows Vulkan Renderer 测试及 Emscripten WebGPU 编译通过；发布矩阵结果记录在
  [0.18.0 发布验收](../records/2026-09-07-v0.18.0-release-acceptance.md)。
