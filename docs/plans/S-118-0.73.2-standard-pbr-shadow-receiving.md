# S-118：标准 PBR 阴影接收

## 状态

**已完成，待 v0.73.2 发布，2026-11-20。**

## 目标

让标准 PBR 材质真正读取方向光阴影贴图，使实例级接收阴影开关产生可见结果。

## 实施内容

- 在 `pbr_standard.hlsl` 增加阴影深度纹理、比较采样器和光源视图投影计算；
- 使用现有 `render_flags` 控制实例是否采样阴影；
- 仅衰减直射光，保留环境光和自发光；
- 重新生成匹配的 `pbr_standard.grshlib`、`pbr_standard.grmat` 和内容哈希；
- 发布门禁自动重建并比较标准 PBR 材质快照。
