# S-117：0.73.1 公共 PBR 资产重新同步

## 状态

**已完成，待 v0.73.1 发布，2026-11-20。**

## 目标

重新生成并发布与当前 PBR Shader Library 匹配的公共 `pbr_standard.grshlib` 和
`pbr_standard.grmat`，避免下游引擎使用旧 Material 内容身份。

## 实施内容

- 使用当前 `pbr_standard.grshlib` 与 `pbr_resource_table.grshlib` 重新构建标准材质；
- 更新 `assets/generated/installed/materials/pbr_standard.grmat`；
- 同步 `GRANIT_PBR_MATERIAL_CONTENT_HASH_HEX`；
- 保持 Shader Library 内容不变，并验证公共 PBR 资产、适配器和渲染回归。

- [x] 标准材质归档可由当前两个 Shader Library 重新生成；
- [x] 公共材质内容哈希与归档一致；
- [x] `granit.material.assets` 通过；
- [x] `granit.material.pbr_adapter` 通过；
- [x] `granit.lighting.pbr_render` 通过；
