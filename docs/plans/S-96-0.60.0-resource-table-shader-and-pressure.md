# S-96：0.60.0 Resource Table Shader 变体与真实压力

## 状态

规划中。承接 v0.59.0 已完成的 Resource Table 公共契约和 Vulkan 末尾 descriptor set 绑定。

## 目标

- 增加 `explicit_bindings` 与 `resource_table` Shader/Material 绑定模型变体；
- 让 SPIR-V/WGSL、Material Variant Key 和 Pipeline Layout 选择保持布局一致；
- 验证 WebGPU 受限实现或 Buffer Table 回退，不伪装成 Vulkan Bindless；
- 增加 GPU 完成点保护，禁止 Resource Table 在途更新产生 descriptor 生命周期竞态；
- 用多材质、多纹理、多 Draw 对比 Bind Group 与 Resource Table 的 CPU/GPU/容量数据。

## 验收边界

- Windows Vulkan、Linux Vulkan/Lavapipe、Chrome WebGPU 和不支持设备；
- 变体数量、构建时间、资产大小、绑定更新和 GPU 时间均有可复现记录；
- 没有稳定收益时收缩或删除实验 API，不把其升级为默认路径。
