# S-79：0.42.0 ImGui Integration 教程与验收归位

## 状态

- 文档状态：已确认
- 实现状态：进行中
- 目标版本：v0.42.0
- 前置任务：[S-77 Model Viewer 架构收敛](S-77-0.42.0-model-viewer-convergence.md)

## 背景与目标

`examples/samples/imgui` 同时保存外部 SDL Window 接入示例、桌面性能采样、Vulkan 视觉测试和
浏览器自动化入口。Tutorial 与 Model Viewer 已经使用共享 ImGui 主题、输入和 Canvas 转换，继续把
测试 Fixture 和 Benchmark 留在综合 Sample 中会造成职责重复。

本任务删除 ImGui 综合 Sample，并按使用目的归位：

- `examples/tutorials/08_sdl_imgui` 演示应用拥有 `SDL_Window` 时的 Integration 接入；
- `tests/integrations/imgui` 保存 Draw Data、字体、纹理、裁剪和 DPI 视觉验收；
- `tests/web/imgui` 保存 Emscripten SDL3 + ImGui 生命周期与浏览器视觉验收；
- `benchmarks` 继续作为 ImGui Draw Data 转换性能的唯一入口。

## 非目标

- 不删除 `granit::integration_imgui` 或 `granit::integration_sdl3`；
- 不把 Example 私有 ImGui 辅助提升为公共 SDK；
- 不改变 Tutorial 与 Model Viewer 的界面设计；
- 不保留仅用于旧 Sample 名称的兼容目标。

## 已确认决策

1. 普通 ImGui 使用方式由已有 Tutorial 与 Model Viewer 展示，不再维护第三个综合应用。
2. 外部 `SDL_Window` 所有权场景无法由 Granit Window Backend 代替，以 `08_sdl_imgui` 作为
   第三方宿主集成教程。
3. 固定验证画面、测试纹理和浏览器导出函数属于测试支持，不进入示例目录。
4. 帧阶段和 GPU Timestamp 分析属于 Benchmark；现有 `granit_imgui_benchmarks` 是持续入口。
5. 内部目标可以直接使用新名称，不为 0.x 源码树目标保留转发。

## 实施顺序

1. 建立 `08_sdl_imgui`，以同一套主体演示 Desktop 与 Web 的 SDL3 + ImGui Integration；删除
   Profile、Demo Window 和视觉测试控制。
2. 将 Vulkan 固定画面与资源迁入 `tests/integrations/imgui`。
3. 将 Web 入口、Shell 与 Playwright 验收迁入 `tests/web/imgui`，使用测试目标名称。
4. 删除 `examples/samples/imgui`，更新 CMake、工作流和文档中的目标及路径。
5. 验证 Windows、Emscripten、Linux 工作流契约和文档链接。

## 测试与验收

- `08_sdl_imgui` 完成 SDL3 事件、外部 Surface、ImGui Draw Data、Resize、提交、Present 与清理；
- Vulkan 视觉测试继续覆盖 1×/2× DPI、字体、纹理、裁剪和输入状态；
- 浏览器测试继续覆盖 1×/2× DPI、鼠标、Resize、多帧推进和显式 Shutdown；
- `granit_imgui_benchmarks` 仍可独立构建；
- 仓库中不存在 `examples/samples/imgui` 或旧 Web Sample 目标引用。

## 风险与未决问题

`08_sdl_imgui` 不复用拥有 Granit Window 的 `tutorial_runtime`，只复用不改变宿主所有权的 ImGui
辅助；否则会隐藏本教程需要说明的外部 Window、事件循环与 Surface 边界。Linux X11/Wayland 的外部
SDL Window 验收只能在远端环境完成；本地 Windows 与浏览器测试通过后，仍需运行 Linux Integration
工作流。迁移只改变仓库布局和内部目标，不影响安装 SDK 的 Integration 组件名称。
