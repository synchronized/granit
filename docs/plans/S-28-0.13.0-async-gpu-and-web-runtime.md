# S-28：0.13.0 异步 GPU 操作与 Web 运行时完善

## 状态

- 路线图任务：S-28
- 目标版本：0.13.0
- 优先级：P1
- 状态：已确认
- 前置依赖：S-19、S-25、S-26、S-27

## 背景与目标

浏览器主线程不能通过同步等待取得 GPU 结果，当前同步 Timestamp Query 契约因此只能由 Vulkan
实现。正式 Web Model Viewer 虽已能够加载真实模型，但大模型的解析、纹理上传与 Mipmap 仍缺少
统一的分阶段状态、取消和错误报告。0.13.0 建立后端无关的异步 GPU 操作契约，在设备支持时补齐
WebGPU Timestamp Query，并把浏览器示例、部署产物和跨后端一致性验证收敛为可发布能力。

## 非目标

- 不把线程池、文件系统、网络请求、glTF 解析器或 Model Viewer 任务调度器加入公共 API。
- 不承诺撤销已经提交给 GPU 的工作；取消只阻止尚未开始的阶段，并允许已提交工作安全排空。
- 不增加桌面 Dawn、Android、公共 glTF SDK、TAA、Bindless 或新的渲染后端。
- 不为 WebGPU 模拟 Vulkan 专属同步对象、Pipeline Cache、持久映射或原生互操作。
- 不在异步操作完成后由 Granit 调用未知线程上的用户回调；第一版使用显式轮询。

## 已确认决策

### 后端无关的异步操作

- Core 提供 64 位异步操作句柄，零值无效；句柄校验类型、generation 和所属 Renderer。
- 状态至少区分 `pending`、`running`、`succeeded`、`failed` 和 `cancelled`，并提供非阻塞状态查询、
  取消请求、结果码查询和显式销毁。
- 查询在未完成时返回稳定的未就绪语义；失败结果在操作销毁前保持可查询。
- 取消是请求而非强制中断：尚未提交的工作可以转为 `cancelled`，已经提交的 GPU 工作必须排空，
  最终状态可以是成功或失败。
- Renderer 销毁前排空或终止其操作；操作销毁不得使后端回调访问失效内存。
- C++20 层提供 move-only RAII 包装，不建立第二套状态或后台线程。

### WebGPU Timestamp Query

- 仅在浏览器 Adapter/Device 实际启用 `timestamp-query` 特性时报告支持并允许创建 Query Pool。
- Recorder 的 Reset、Write 与 Resolve 仍使用公共 Timestamp 语义；WebGPU 通过 Resolve Buffer 和
  异步 Map 完成结果读取。
- 读取入口返回异步操作；完成后再复制纳秒结果到调用方缓冲区，不长期持有调用方输出指针。
- 不支持能力时稳定返回 `GRANIT_ERROR_UNSUPPORTED`，不能以 CPU 时间伪装 GPU Timestamp。
- Vulkan 使用同一异步读取入口，即使后端可立即取得结果，也必须满足相同状态和生命周期契约。

### Web Model Viewer 分阶段加载

- 示例层把下载、解析、CPU 图像准备、GPU 上传、Mipmap 和场景切换拆为明确阶段。
- 下载与解析由浏览器/示例拥有；GPU 上传和 Mipmap 使用公共异步操作或每帧有界工作预算。
- 进度来自已完成字节数和工作项，不使用与真实工作无关的计时动画；界面可以平滑显示但必须同时
  保留真实进度。
- 取消后继续驱动事件和渲染，释放未提交 CPU 数据，并让已经提交的 GPU 资源安全退役。
- 错误面板报告阶段、稳定 Granit 结果码和可操作的 URL/CORS/资产诊断。

### 一致性与部署

- 同一套公共异步 API Contract Test 覆盖 Vulkan 与浏览器 WebGPU；能力差异只改变是否支持，不能
  改变句柄、状态、取消、销毁和错误语义。
- Timestamp 结果验证单调性、范围和完成状态，不要求不同 GPU 的绝对数值一致。
- 浏览器发布产物包含 HTML、JavaScript、Wasm、标准 Shader/Material/Environment、离线小型 Fixture
  和启动说明；正式 Flight Helmet 可由相对 URL 或用户配置的自托管地址加载。
- 页面诊断区分 HTTP 错误、相对路径错误、CORS、资产摘要错误、能力不足和 GPU 操作失败。

## 实施顺序

1. **S-28A 异步契约（已完成）**：冻结 C ABI/C++ 包装、状态机、所有权、取消及 Renderer 关闭语义，增加
   纯 CPU 状态机和句柄测试。
2. **S-28B Vulkan 基线（已完成）**：让异步 Timestamp 读取在 Vulkan 上闭环，验证立即完成、延迟完成、失败、
   取消竞态和资源销毁。
3. **S-28C WebGPU Timestamp（已完成）**：实现能力启用、Resolve/Map、回调生命周期和
   Emscripten 自动化。
4. **S-28D Web 加载管线（已完成）**：分阶段加载 Model Viewer，增加真实进度、取消、错误详情和
   资源边界事件循环让出。
5. **S-28E 一致性测试（已完成）**：以同一 Fixture 覆盖两后端的能力、结果码、资源生命周期与
   像素容差。浏览器 Smoke 直接调用与 Vulkan 测试相同的公共 Timestamp API，支持设备验证异步
   完成和结果单调性，不支持设备验证稳定的 `UNSUPPORTED`；两端同时复用 Renderer Fixture 的
   纹理、动态 Uniform 和像素探针，并在关闭前检查公共资源统计归零。
6. **S-28F 部署与发布验收**：验证相对 URL、自托管/CORS 诊断、离线 Fixture、Release 示例产物，
   完成 Windows、Linux、Emscripten、安装 Consumer、文档和发布矩阵。

## 测试与验收

- C11 与 C++20 Consumer 能创建、轮询、请求取消和销毁异步操作，不包含后端原生头文件。
- 操作测试覆盖无效句柄、类型错误、跨 Renderer、generation 失效、重复销毁、取消竞态和 Renderer
  先销毁。
- Vulkan 与支持 `timestamp-query` 的 WebGPU 环境均能异步取得有序纳秒结果；不支持设备返回
  `GRANIT_ERROR_UNSUPPORTED`。
- 浏览器加载期间事件、UI 和已有画面持续驱动，进度不会因单个无界 CPU/GPU 阶段长期停住。
- 加载取消不会泄漏 Buffer、Texture、View、Sampler、Shader、Pipeline 或异步操作句柄。
- 浏览器离线 Fixture 可在 Release 产物中直接运行；自托管模型失败时提供明确路径或 CORS 诊断。
- 共享/静态、C/C++、Windows/Linux 与 Emscripten 验证全部通过后再提升并发布 0.13.0。

## 风险与未决问题

- WebGPU Map 回调可能在 Renderer 关闭后到达，必须由现有回调生命周期门禁保护，不能捕获裸资源
  指针。
- 公共异步操作应先服务 Timestamp；上传是否直接返回相同句柄，需要以 Model Viewer 实现数据决定，
  不在 S-28A 预先泛化所有 GPU 命令。
- Emscripten 浏览器自动化环境未必提供 Timestamp Query；CI 必须同时覆盖支持与明确不支持路径，
  真实能力验收可由具备对应 Adapter 的独立作业完成。
- 粒度过细的上传操作会增加 C ABI 调用和句柄管理成本；Model Viewer 应优先提交有界批次。
