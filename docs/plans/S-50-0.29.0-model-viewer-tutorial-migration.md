# S-50：0.29.0 Model Viewer 教程迁移

## 状态

**实施中，P1。** 已确认把真实模型加载加入线性教程，并在功能与验证完全接管后删除重复的
`examples/samples/model_viewer`。当前正在实施 09 Model Loading。

## 背景与目标

01～08 已从窗口清屏推进到 PBR、Render Pipeline 和 ImGui，但仍使用源码内置立方体。现有 Model
Viewer 已覆盖 glTF/GLB、完整 PBR 纹理、环境光、轨道相机、异步加载、桌面与浏览器运行以及调试
面板；直接把整个应用改名为第 09 章会引入过多同时发生的概念。

0.29.0 把这条能力拆成两个连续阶段：

```text
08 ImGui
  → 09 Model Loading：真实 glTF/GLB → GPU Mesh/Material/Scene
  → 10 Model Viewer：异步桌面/Web 应用、环境光和检查器
```

最终以 Tutorial 10 作为 Model Viewer 的唯一源码入口，`samples` 只保存仍具有独立综合应用职责的
示例。

## 非目标

- 不把示例私有 glTF Loader、图片解码或任务调度加入 Granit 安装 SDK。
- 不新增公共场景资产数据库、RID、缓存、文件系统或网络接口。
- 不在 09 同时讲解异步 Fetch、ImGui 检查器、性能采样和所有错误恢复策略。
- 不复制两份长期维护的 Model Viewer Core。
- 不在功能与测试尚未接管时删除现有 Model Viewer。

## 已确认决策

### 教程边界

09 只建立真实资产到现有公共渲染接口的最短路径：

1. 从文件读取 `.gltf` 或 `.glb`，按模型位置解析外部 Buffer 和 Image。
2. 使用仓库私有 `examples/common/gltf` 解析 CPU Scene。
3. 上传顶点、索引、纹理和材质，建立 Mesh、Material、Scene 与 Draw Binding。
4. 使用 Render Pipeline 显示默认 Scene，并按包围体自动放置相机。
5. 首版使用同步桌面加载，使章节聚焦资产映射和所有权。

10 在 09 的模型路径上增加完整应用能力：

- 桌面文件与浏览器 Fetch 的异步状态机；
- 轨道相机、节点树、材质检查器和纹理预览；
- `.grenv` 环境光、质量选项、性能面板和截图验收；
- Windows/Linux Vulkan 与 Emscripten WebGPU 共用 Application Core。

### 源码迁移

- 迁移期间 `samples/model_viewer` 是行为基准，不从 Tutorial 反向包含 Sample 源码。
- 已被 09 和 Model Viewer 共同使用的稳定私有能力可以进入 `examples/common`。
- 10 以移动和整理现有实现为主，不重新实现第二套 GPU Scene 或异步状态机。
- 旧目标、指南和工作流只在新目标通过同等验证后统一切换。

### 资产与许可

- 自动测试使用仓库内可再分发的小型 Fixture，不能依赖网络。
- 手动完整验收继续使用锁定版本的 Khronos glTF Sample Assets Flight Helmet（CC0-1.0）。
- 外部资产不进入 Granit 安装包；来源、版本、哈希和许可证继续由示例资产清单维护。

## 实施顺序

1. **S-50A 计划与边界（已完成）**：确定 09/10 职责、迁移条件、资产许可和验证矩阵。
2. **S-50B 09 Model Loading（实施中）**：增加同步 glTF/GLB 教程、配套源码、确定性 Fixture 和
   桌面 Smoke；只暴露真实模型到公共 Mesh/Material/Scene 的映射。
3. **S-50C 共享 Core 收敛**：提取 09 与完整查看器共同需要的稳定私有加载和 GPU 上传能力，消除
   Tutorial 对 Sample 目录的依赖及重复实现。
4. **S-50D 10 Model Viewer**：迁移 Application Core、桌面/Web 壳层、环境光、ImGui 检查器、质量
   和性能能力，并保持目标行为。
5. **S-50E 切换与删除**：切换 CMake、工作流和 Guide 链接，删除 `samples/model_viewer`，更新
   Changelog 和目录说明。
6. **S-50F 验收**：运行桌面完整构建与测试、Emscripten 构建、浏览器 Model Viewer、离屏截图和
   文档链接检查，记录最终差异。

每个阶段完成后创建聚焦提交；旧 Sample 只在 S-50E 的接管条件满足后删除。

## 测试与验收

- 09 可独立构建运行，并显示来自 glTF/GLB Fixture 的非内置几何和 PBR 材质。
- 09 覆盖嵌入与外部 Buffer、纹理 URI、缺失资源、无效索引及资源生命周期。
- 教程主路径只使用 Granit 公共 C++20 接口，不包含 Granit 私有 Renderer 头或后端原生类型。
- 10 保持现有桌面/Web 模型、相机、材质编辑、环境光、质量设置和资源释放行为。
- 新 Model Viewer 通过现有单元测试、离屏验收、浏览器帧推进、输入、Resize 和控制台错误检查。
- 删除旧目录后不存在 `samples/model_viewer` 构建、文档或工作流引用。
- Windows/Linux、Emscripten 和 Documentation 验证通过。

## 风险与未决问题

- 当前 GPU Scene 同时承担模型转换、上传和运行时缓存；S-50C 需要按所有权拆分，不能为了教程
  可读性改变公共 API。
- glTF Fixture 必须足够小且覆盖真实外部资源，同时避免把大型验收资产提交进仓库。
- 09 的同步文件 Resolver 不适用于浏览器；跨平台异步语义集中在 10，不在 09 构造伪同步接口。
- Model Viewer 现有桌面和 Web 入口存在重复初始化代码，迁移时应收敛到共享 Application Core，
  但不把平台事件或网络能力放入 Renderer。
