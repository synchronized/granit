# 版本迁移指南

每个发布版本的完整变化以 [Changelog](../../CHANGELOG.md) 为准。只有升级需要修改调用代码、构建
配置、生命周期管理或已有资产时，项目才提供独立迁移指南；没有列出的版本跨度不需要额外的手工
迁移步骤。
