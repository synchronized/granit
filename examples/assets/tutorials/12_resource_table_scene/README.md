# ResourceTableGallery

这是 Tutorial 12 的可控多材质验证资产，由
[`tools/generate_resource_table_gallery.py`](../../../../../tools/generate_resource_table_gallery.py)
使用 Blender 无界面模式生成。

资产包含 16 个对象、16 个材质、16 张 BaseColor 纹理和 16 张 MetallicRoughness 纹理。模型和
纹理均为本仓库生成内容，不依赖外部模型或下载服务。重新生成后，应保持 glTF、BIN 和 PNG 文件
一起更新，并通过 Tutorial 12 smoke test。
